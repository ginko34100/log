1. n제곱근THE n-TH ROOT

먼저 n 이 양의 정수일 때 an 은 a 를 n 번 곱한 것입니다. 그리고 m, n 이 양의 정수면 다음 규칙이 이전과 같이 성립합니다.

am+n = aman
이건 1장 §3의 N11입니다 지수는 몇 번 곱했나를 세는 숫자이므로, 곱셈끼리 붙이면 개수가 더해집니다.

이제 Lang이 새 성질을 하나 가정합니다.

n제곱근 공리 (증명 없이 가정)

a 를 양수, n 을 양의 정수라 하자. 실수의 성질의 일부로서, 다음을 만족하는 유일한 양의 실수 r 이 존재한다고 가정한다.

rn = a

이 r 을 a 의 n제곱근이라 하고 다음과 같이 쓴다.

a1/n   또는   n√a

Lang이 덧붙입니다. n제곱근은 앞 절에서 다룬 제곱근의 존재성과 유일성을 일반화한 것입니다.

§2와 비교하면 §2의 제곱근 공리   a > 0 이면 b2 = a 인 b 가 존재

§3의 n제곱근 공리   a > 0 이면 rn = a 인 r 이 존재

2가 n 으로 바뀐 것뿐입니다. n = 2 로 두면 §2의 내용이 그대로 나옵니다.
내 설명 · 왜 하필 a^(1/n) 이라고 쓰나

n제곱근을 n√a 라고만 쓰면 될 텐데, 왜 a1/n 이라는 지수 표기를 새로 만들까요?

규칙과 아귀가 맞기 때문입니다. 곧 나올 POW 2를 미리 써 보면

확인 (a1/n)n = a(1/n)·n = a1 = a

지수끼리 곱했더니 (1/n) × n = 1 이 되어 a 자기 자신이 나옵니다.

즉 n제곱근이란 n제곱하면 원래로 돌아오는 것인데, 지수 표기로 쓰면 그 성질이 계산으로 저절로 나옵니다.

1장 §6과 같은 발상 곱셈의 역원을 a−1 이라 썼던 것도 같은 이유였습니다. 표기가 규칙을 저절로 지키게 만드는 것이 좋은 표기예요.

2. 정리 1THEOREM 1

THEOREM 1

a, b 가 양의 실수면

(ab)1/n = a1/nb1/n
말로 풀면 곱의 n제곱근은 각각의 n제곱근을 곱한 것입니다.

예를 들어 √(4 × 9) = √4 × √9 = 2 × 3 = 6 입니다. 실제로 √36 = 6 이 맞죠.
PROOF · THEOREM 1
r = a1/n,   s = b1/n 이라 두자
이름 붙이기입니다. 긴 기호를 짧은 문자로 바꿔 다루기 쉽게 만듭니다.

1장 §4에서 계속 쓰던 네 박자의 마지막 단계와 같은 수법이에요.
이 말은 rn = a 이고 sn = b 라는 뜻
n제곱근의 정의를 그대로 풀어 쓴 것입니다.

a1/n 이란 "n제곱하면 a 가 되는 양수"였으니까요.
(rs)n = rnsn = ab
첫 등호는 1장 §3에서 본 (ab)n = anbn 입니다. 곱을 n번 곱하면 각각을 n번 곱한 것과 같죠.

둘째 등호는 앞 줄에서 확인한 rn = a, sn = b 를 대입한 것입니다.
∴ rs 가 ab 의 n제곱근
rs 를 n제곱했더니 ab 가 나왔습니다.

그런데 n제곱근은 유일하다고 가정했으므로, rs 가 곧 (ab)1/n 입니다.

rs = a1/nb1/n 이므로 정리가 증명되었습니다.

증명 끝.
유일성이 없으면 증명이 안 됩니다 마지막 줄에서 "n제곱하면 ab 가 되는 양수는 하나뿐"이라는 사실을 썼습니다.

만약 여러 개라면 rs 가 그중 어느 것인지 알 수 없어 증명이 막힙니다. 공리에 "유일한"이 들어 있는 이유가 이것입니다.

3. 분수 지수와 세 규칙 ★POW 1, POW 2, POW 3

Lang이 이어서 적습니다. n제곱근은 분수 거듭제곱으로 더 일반화될 수 있다. 그리고 다음 성질을 증명 없이 가정합니다.

분수 거듭제곱 (가정)

a 를 양수라 하자. 각 유리수 x 에 대해 양수 ax 를 대응시킬 수 있다.

이것은 x 가 양의 정수 n 일 때는 a 의 n제곱이고, x = 1/n 일 때는 a 의 n제곱근이며, 다음 조건들을 만족한다.

POW 1

모든 유리수 x, y 에 대하여

ax+y = axay
POW 2

모든 유리수 x, y 에 대하여

(ax)y = axy
POW 3

a, b 가 양수면

(ab)x = axbx
내 설명 · 1장 §3과 나란히 놓고 보기

이 셋은 완전히 새로운 규칙이 아닙니다. 1장 §3에서 본 것을 지수 범위만 넓혀 다시 선언한 겁니다.

1장 §3여기 §3차이
더하기N11POW 1m, n 양의 정수 → 유리수
곱하기N12POW 2같음
분배예제로POW 3정식 규칙으로 승격

왜 다시 선언하나가 중요합니다. 1장에서는 지수가 "몇 번 곱했나" 라는 뜻이었어요. 그래서 a3 은 세 번 곱한 것이었죠.

그런데 a2/3 은 몇 번 곱한 걸까요? 세 번의 3분의 2번? 말이 안 됩니다.

그래서 뜻이 바뀝니다 지수가 정수를 벗어나는 순간 "몇 번 곱했나"라는 해석이 무너집니다.

대신 "POW 1, 2, 3을 만족하는 것" 이라고 규칙으로 정의합니다. 뜻이 아니라 규칙이 정체가 되는 겁니다.
이 책이 계속 하는 일 §1에서 실수를 정의할 때도 같았습니다. "실수가 무엇인가"가 아니라 "실수가 무엇을 만족하는가" 로 다뤘죠. 여기서도 같은 방식입니다.

Lang이 적습니다. 이제 이 조건들로부터 따름 결과들을 이끌어내겠다.

4. a⁰ = 1 을 증명하기 ★DERIVING a⁰ = 1

먼저 a0 을 계산합니다.

PROOF · a⁰ = 1
b = a0 이라 두자
이름 붙이기입니다. 아직 a0 이 무엇인지 모르므로, 일단 b 라고 부르고 정체를 밝혀 나갑니다.
a = a1 = a0+1 = a0a1 = a0a
한 걸음씩 봅시다.

a = a1   한 번 곱한 것은 자기 자신
a1 = a0+1   1을 0+1로 바꿔 썼습니다. 값은 같지만 POW 1을 쓸 모양이 됩니다
a0+1 = a0a1   POW 1 적용
a0a1 = a0a   다시 a1 = a

둘째 줄이 핵심 수법입니다. 1장 §3에서 0a = 0 을 증명할 때 a 를 1a 로 바꿔 썼던 것과 똑같아요.
즉 a = ba
b = a0 이라 뒀으므로 a0a 는 ba 입니다.

단순한 이름 바꾸기입니다.
1 = aa−1 = baa−1 = b
양변에 a−1 을 곱했습니다. 1장 §6에서 계속 쓰던 수법이에요.

왼쪽   a · a−1 = 1
오른쪽   ba · a−1 = b(aa−1) = b · 1 = b

따라서 1 = b 입니다.
∴ a0 = 1
b = a0 이었으므로 결론이 나왔습니다.

증명 끝. Lang은 이걸 중요한 공식이라고 부릅니다.
내 설명 · 왜 이게 놀라운 결과인가

학교에서는 a0 = 1 을 그냥 외우라고 배웁니다. 이유를 물으면 "약속"이라고 하죠.

약속이 아닙니다. 증명된 결과입니다.

POW 1을 만족하게 하려면 a0 은 1일 수밖에 없습니다. 다른 값을 주면 규칙이 깨져요.

직관적으로 확인하는 방법 a3 ÷ a3 을 두 가지로 계산해 봅니다.

방법 1 같은 것을 같은 것으로 나누니 1
방법 2 지수끼리 빼면 a3−3 = a0

두 결과가 같아야 하므로 a0 = 1 입니다.

5. 음의 지수 ★NEGATIVE POWERS

Lang이 다음으로 음의 거듭제곱이 어떤 것인지 봅니다. x 를 양의 유리수라 두면

PROOF · a^(−x) = 1/a^x
1 = a0 = ax+(−x) = axa−x
한 걸음씩 봅시다.

1 = a0   방금 증명한 결과
a0 = ax+(−x)   0을 x + (−x) 로 바꿔 썼습니다. 1장 §2의 N2에 의해 값은 0 그대로인데, POW 1을 쓸 모양이 됩니다
ax+(−x) = axa−x   POW 1 적용

또 같은 수법입니다. 값을 안 바꾸면서 규칙을 쓸 수 있는 모양으로 고쳐 쓰는 것.
∴ a−x 는 ax 의 곱셈 역원
ax 와 a−x 를 곱했더니 1이 나왔습니다.

1장 §6에서 곱해서 1이 되면 서로 역원이라고 배웠죠. 그리고 역원은 유일합니다.
a−x = 1 / ax
역원을 분수 표기로 쓴 것입니다.

증명 끝.
Lang이 짚는 중요한 점

이것은 곱셈의 역원을 a−1 이라고 쓰는 표기를 정당화합니다.

내 설명 · 이게 무슨 뜻인가

1장 §6에서 곱셈의 역원을 a−1 이라고 썼습니다. 그때는 그냥 기호였어요. 위첨자 −1 이 지수라는 보장이 없었습니다.

이제 확인됐습니다. 방금 증명한 공식에 x = 1 을 넣으면

확인 a−1 = 1 / a1 = 1/a

지수 −1 로 읽어도 역원이 됩니다. 두 해석이 일치했습니다.

즉 a−1 이라는 표기는 우연이 아니라 지수 법칙과 아귀가 맞는 표기였던 겁니다.

Lang의 예입니다. x = 3 일 때

a−3 = (a3)−1 = 1a3

마찬가지로

2−4 = (24)−1 = 124

Lang의 표현으로, 매우 거칠게 말하면 음의 거듭제곱을 취하는 것은 몫을 취하는 것에 해당합니다.

기억할 한 줄 지수의 마이너스는 "뒤집어라"는 뜻입니다. 분자에 있던 것을 분모로 보내라는 신호예요.

6. 분수 지수를 쪼개기 ★DECOMPOSING a^(m/n)

x = m/n 을 양의 정수 m, n 의 몫으로 표현된 양의 유리수라 하겠습니다. POW 2에 의해

분해 공식
am/n = (am)1/n = (a1/n)m

Lang의 말로, 분수 거듭제곱은 정수 거듭제곱과 n제곱근으로 분해될 수 있습니다.

왜 이렇게 되는지 POW 2로 확인 첫 번째 형태
(am)1/n = am · (1/n) = am/n ✓

두 번째 형태
(a1/n)m = a(1/n) · m = am/n ✓

지수끼리 곱하면 둘 다 m/n 이 되므로 같은 값입니다.
내 설명 · 어느 순서로 계산할까

같은 값이지만 계산 난이도는 하늘과 땅 차이입니다. 82/3 으로 비교해 보겠습니다.

경로 A · 거듭제곱 먼저 (82)1/3 = 641/3

이제 세제곱해서 64가 되는 수를 찾아야 합니다. 큰 수라 암산이 힘듭니다.
경로 B · 근 먼저 (81/3)2 = 22 = 4

세제곱해서 8이 되는 수는 2로 바로 보입니다. 그걸 제곱하면 4. 훨씬 쉽습니다.

규칙으로 정리하면 이렇습니다. 근을 먼저 취해 수를 작게 만든 뒤 거듭제곱하세요.

(21/2)1/4 = 2(1/2)(1/4) = 21/8

8. 무리수 지수IRRATIONAL EXPONENTS

Lang이 다음 단계를 언급합니다. 무리수 지수를 갖는 거듭제곱도 정의하고 싶다. 예를 들어 이런 수를요.

2√2
Lang의 설명

이것은 훨씬 어렵지만, POW 1과 POW 2 두 조건이 만족되도록 할 수는 있다.

우리는 이것이 필요하지 않을 것이므로 체계적인 전개는 더 고급 과정으로 미루겠다. 다만 함수를 다루는 장에서 이 상황에 대해 몇 마디 더 하겠다.

함수를 다루는 장이란 13장 §4 지수함수입니다. 거기서 ax 를 모든 실수 x 에 대해 다루게 됩니다.
내 설명 · 왜 무리수 지수가 어려운가

지금까지의 정의를 되짚어 보세요.

지수뜻
3세 번 곱한다
1/3세제곱해서 원래가 되는 수
2/3위 둘을 조합
√2?

√2 는 분수로 쓸 수 없습니다. 1장 §5 정리 4가 그걸 증명했죠.

분수가 아니면 "몇 번 곱하고 몇 제곱근을 취한다"는 설명이 통하지 않습니다. 그래서 완전히 다른 접근이 필요해요.

대략의 아이디어만 √2 ≈ 1.41421… 이므로, 21.4, 21.41, 21.414, … 를 계산해 나가면 어떤 값에 한없이 가까워집니다. 그 값을 2√2 로 정의합니다.

이 "한없이 가까워진다"를 엄밀하게 다루려면 극한이 필요하고, 그게 미적분의 영역입니다.

9. Lang의 마지막 정책 선언 ★THE POLICY

Lang이 §3을 이렇게 마무리합니다. 실수를 유리수와 구별하는 것에 대한 마지막 언급이라면서요.

Lang의 마무리

덧셈, 곱셈, 양수성의 성질들은 유리수에서도 성립한다.

실수를 유리수와 구별하는 것은 더 많은 수의 존재다. 제곱근, n제곱근, 일반 지수 등등.

이 "등등" 을 정확하게 만드는 것은 더 복잡한 작업이다.

앞의 두 줄은 실수와 유리수를 구별하지 못합니다. 유리수도 다 만족하니까요.

구별하는 것은 뒤의 두 줄, 즉 "그런 수가 존재한다"는 선언들입니다.

이어서 Lang이 질문을 던집니다.

Lang의 질문

(실수가 모든 무한소수로 이루어진다고 말하는 것 말고) 실수의 성질을 표현하는 깔끔한 방법이 있는가? 우리가 직관적으로 존재하기를 바라는 어떤 수든 그 성질 하나만으로 존재가 증명되도록 보장해주는 방법이?

Lang의 답

그렇다. 있다. 하지만 훨씬 더 고급 과정에 속한다.

그 성질의 이름 완비성(completeness) 이라고 부릅니다. 대략 "수직선에 빈틈이 없다" 는 뜻이고, 이 하나만 있으면 제곱근이든 n제곱근이든 존재가 전부 증명됩니다.

Lang이 §1에서 "실수 이론을 체계적으로 전개하는 것은 길고 지루하다"고 했던 그 부분입니다.
★ Lang의 정책

따라서 이 과정 전체와 초급 미적분 전체에서, 어떤 논의를 진행하기 위해 실수가 존재하기를 원할 때마다, 우리의 방침은 그 존재를 가정하고 증명은 더 고급 과정으로 미루는 것이다.

내 설명 · 이 선언을 어떻게 받아들일까

얼핏 얼버무리는 것처럼 들립니다. "증명 안 하고 그냥 있다고 치겠다"니까요.

하지만 이건 정직한 선언입니다. Lang은 두 가지를 분명히 하고 있어요.

① 무엇을 증명했고 무엇을 안 했는지 밝힌다 가정한 것을 가정이라고 명시합니다. 증명한 척하지 않아요.
② 증명이 가능하다는 것도 밝힌다 "할 수 없다"가 아니라 "할 수 있지만 여기서는 안 한다" 입니다. 어디로 가면 되는지도 알려주고요.

1장 §3에서 "가정은 빚" 이라고 했었죠. Lang은 지금 빚 목록을 정확히 공개하고 있는 겁니다.

2번811/4 은 어떤 정수인가?
네제곱해서 81이 되는 양수를 찾습니다.

81 = 3 × 3 × 3 × 3 = 34

요령밑을 소인수분해하면 지수 계산으로 바뀝니다.
3번(√2)6 은 어떤 정수인가?
√2 = 21/2 이므로

(21/2)6 = 2(1/2)·6 = 23 = 8
직접 곱해서 확인 √2 여섯 개를 두 개씩 짝지으면 2 × 2 × 2 = 8 입니다. 같은 답이죠.
4번(√2)5 은 정수인가?
(21/2)5 = 25/2

분해하면 25/2 = 22 + 1/2 = 22 · 21/2 = 4√2
POW 1을 썼습니다. 5/2 = 2 + 1/2 로 쪼갠 것입니다

정수가 아닙니다.

이유 만약 4√2 가 정수 k 라면 √2 = k/4 가 되어 √2 가 유리수가 됩니다.
이는 1장 §5 정리 4에 모순입니다 ∎
지수가 홀수냐 짝수냐 3번은 지수가 짝수라 √2 가 전부 짝지어져 사라졌습니다.

4번은 홀수라 하나가 남습니다. 그 남은 하나가 무리수를 만듭니다.
5번(√2)−5 는 유리수인가? (√2)5 는 유리수인가?
둘 다 유리수가 아닙니다.

(√2)⁵ 부터
4번에서 (√2)5 = 4√2 임을 봤습니다.
유리수라 가정하면 √2 = (유리수)/4 도 유리수가 됩니다. 정리 4에 모순 ∎

(√2)⁻⁵ 는
(√2)−5 = 14√2

유리수라 가정하면, 그 역원인 4√2 도 유리수여야 합니다.
유리수의 역원은 유리수입니다. 분자와 분모를 뒤집으면 되니까요

그런데 방금 4√2 가 유리수가 아님을 봤습니다. 모순 ∎
