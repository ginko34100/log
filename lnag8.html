1. 기초 다지기 : 방정식끼리 더해도 되나 ★WHY WE MAY ADD EQUATIONS

본론에 들어가기 전에 당연해 보이지만 실은 근거가 필요한 것 두 개를 확실히 해두겠습니다. 이걸 모르면 다음 단계가 마법처럼 보입니다.

궁금증 1 : 왜 방정식에 수를 곱해도 되나

2x + y = 1 의 양변에 3을 곱해 6x + 3y = 3 으로 바꿨습니다. 이게 왜 정당할까요?

근거
만약 A = B 이면 kA = kB
왜 그런가 A = B 라는 말은 A 와 B 가 같은 수라는 뜻입니다. 이름만 두 개일 뿐 실체는 하나예요.

같은 수에 k 를 곱하면 당연히 같은 결과가 나옵니다. 그래서 kA 와 kB 도 같은 수입니다.
주의 k = 0 이면 안 됩니다. 양변에 0을 곱하면 0 = 0 이 되어 정보가 통째로 사라집니다. 1장 §6에서 0만 역원이 없었던 것과 같은 이유로, 0을 곱하면 되돌릴 수 없습니다.

궁금증 2 : 왜 두 방정식을 더해도 되나

이게 §2의 핵심 도구입니다. 식 두 개를 통째로 더하는 조작이요.

근거
만약 A = B 이고 C = D 이면 A + C = B + D

증명을 두 걸음으로 나눠 보겠습니다.

PROOF · 방정식끼리 더하기
A + C = B + C
첫 번째 조건 A = B 를 썼습니다.

A 와 B 가 같은 수이므로, 양쪽에 똑같이 C 를 더하면 결과도 같습니다.

1장 §2에서 계속 쓰던 "양변에 같은 수 더하기" 그대로예요.
B + C = B + D
두 번째 조건 C = D 를 썼습니다.

이번엔 C 와 D 가 같은 수이므로, 양쪽에 똑같이 B 를 더하면 결과도 같습니다.

방향만 바뀌었을 뿐 같은 원리입니다.
∴ A + C = B + D
두 줄을 이어 붙였습니다.

A + C 는 B + C 와 같고, B + C 는 B + D 와 같습니다.
따라서 A + C 와 B + D 도 같습니다.

증명 끝.
그래서 실제로는 좌변은 좌변끼리, 우변은 우변끼리 더하면 됩니다. 뺄셈도 마찬가지입니다. 뺄셈은 음수를 더하는 것이니까요(1장 §2의 약속).
내 설명 · 저울 두 개로 보기

저울 하나가 방정식 하나입니다.

저울 A : 왼쪽 접시에 A, 오른쪽 접시에 B. 균형이 맞습니다.
저울 C : 왼쪽 접시에 C, 오른쪽 접시에 D. 역시 균형입니다.

이제 저울 C의 내용물을 통째로 저울 A에 옮겨 담습니다. 왼쪽 것은 왼쪽에, 오른쪽 것은 오른쪽에요.

왼쪽에 C 만큼, 오른쪽에 D 만큼 늘었는데 C 와 D 는 무게가 같으므로 저울은 여전히 균형입니다.

2. 주어진 문제

Lang이 든 예입니다. 다음 세 식을 동시에 만족하는 x, y, z 를 찾습니다.

(1)  3x + 2y + 4z = 1
   −x +  y + 2z = 2
    x − 3y +  z = −1
번호 표기에 대하여 Lang은 이 세 식 묶음 전체를 (1)이라고 부릅니다. 나중에 나오는 (2), (3)은 소거해서 새로 만든 식들이에요. 헷갈리기 쉬우니 이 페이지에서는 원래 세 식을 첫째 식, 둘째 식, 셋째 식이라고 부르겠습니다.

3. 전략 세우기THE PLAN

Lang이 적은 방침은 이렇습니다. 앞에서와 같은 패턴을 따라, x 와 y 를 차례로 소거하고 z 를 구한다. 그리고 소거 순서는 스스로 편하도록 고른다고 덧붙입니다.

전체 흐름

1단계   식 3개에서 x 를 없앤다 → 식 2개가 남는다

2단계   남은 식 2개에서 y 를 없앤다 → 식 1개가 남는다

3단계   그 식으로 z 를 구한다

4단계   거꾸로 올라가며 y, x 를 구한다

1단계에서 자주 하는 실수 x 를 없앨 때 두 번 소거해야 합니다. 식이 셋이니까요.

첫째와 둘째에서 한 번, 둘째와 셋째에서 또 한 번. 그래야 x 없는 식이 두 개 생깁니다. 한 번만 하면 식이 하나뿐이라 미지수 둘을 못 구합니다.

흐름을 그림으로 보면 이렇습니다.

5. 풀이 전체를 글로 다시THE FULL SOLUTION

1단계 앞부분 : 둘째와 셋째를 더해 x 없애기

Lang의 관찰입니다. 둘째 식과 셋째 식을 더하면 이미 x 가 사라진다.

−x +  y + 2z =  2
 x − 3y +  z = −1
왜 그냥 더하면 되나 x 의 계수가 하나는 −1, 다른 하나는 +1 입니다. 부호가 반대이고 크기가 같습니다.

그래서 곱할 필요 없이 그냥 더하면 −x + x = 0 이 되어 사라집니다. 계수를 맞추는 수고가 없으니 가장 편한 경로예요.

실제로 더해 봅니다. 좌변은 좌변끼리, 우변은 우변끼리입니다.

y − 3y + 3z = 2 − 1
이 줄이 어떻게 나왔는지 항별로 x 항   −x + x = 0 이므로 사라짐
y 항   y 와 −3y 를 더해서 y − 3y
z 항   2z 와 z 를 더해서 3z
우변   2 와 −1 을 더해서 2 − 1

이제 좌우변을 정리합니다. y − 3y = −2y 이고 2 − 1 = 1 입니다.

(2)  −2y + 3z = 1

1단계 뒷부분 : 첫째와 둘째로 x 없애기

Lang의 표현대로 다시 (1)로 돌아가 이번엔 첫 두 식에서 x 를 없앱니다. 방법은 둘째 식에 3을 곱해 첫째 식에 더하는 것입니다.

왜 3을 곱하나 첫째 식의 x 계수는 3, 둘째 식은 −1 입니다.

둘째 식에 3을 곱하면 x 계수가 −3 이 됩니다. 첫째 식의 +3 과 부호가 반대이고 크기가 같아지므로 더하면 사라집니다.

먼저 둘째 식에 3을 곱합니다. 모든 항에 곱해야 합니다.

3 × (−x + y + 2z) = 3 × 2
−3x + 3y + 6z = 6
항별로 확인 3 × (−x) = −3x
3 × y = 3y
3 × 2z = 6z
3 × 2 = 6  (우변도 잊지 말 것)

이제 첫째 식과 더합니다.

 3x + 2y + 4z = 1
−3x + 3y + 6z = 6

더하면

2y + 3y + 4z + 6z = 1 + 6
항별로 x 항   3x + (−3x) = 0 이므로 사라짐
y 항   2y + 3y
z 항   4z + 6z
우변   1 + 6

정리하면

(3)  5y + 10z = 7

2단계 : 이제 미지수가 둘이다

Lang이 적습니다. 식 (2)와 (3)은 미지수 두 개짜리 한 쌍을 이루며, 이 장의 §1에서 한 방식으로 풀 수 있다.

(2)  −2y +  3z = 1
(3)   5y + 10z = 7
여기가 이 절의 요점입니다 세 개짜리 문제가 두 개짜리 문제로 바뀌었습니다. 그리고 두 개짜리는 §1에서 이미 풀 줄 압니다.

이렇게 모르는 문제를 아는 문제로 바꾸는 것이 수학의 기본 전략입니다.

Lang의 방법입니다. (2)에 5를 곱하고 (3)에 2를 곱한 뒤 더합니다.

왜 5와 2인가 y 의 계수가 −2 와 5 입니다. 크기를 같게 만들려면 2와 5의 공배수인 10이 필요합니다.

−2 를 −10 으로 만들려면 5를 곱하고, 5 를 10 으로 만들려면 2를 곱합니다. 그러면 −10y 와 +10y 가 되어 더하면 사라집니다.

(2)에 5를 곱하면

5 × (−2y + 3z) = 5 × 1
−10y + 15z = 5

(3)에 2를 곱하면

2 × (5y + 10z) = 2 × 7
10y + 20z = 14

두 식을 더합니다.

15z + 20z = 5 + 14
35z = 19
z = 1935

3단계 : 되돌아가서 y 구하기

Lang이 적습니다. z 값을 찾았으니 (2)나 (3)으로 돌아가 y 값을 찾을 수 있습니다. (2)를 쓰겠습니다.

(2)는 −2y + 3z = 1 입니다. y 만 남기려고 정리하면

−2y = 1 − 3z
 2y = 3z − 1
두 줄 사이에 무슨 일이 첫 줄의 양변에 −1 을 곱했습니다.

좌변   −1 × (−2y) = 2y
우변   −1 × (1 − 3z) = −1 + 3z = 3z − 1

마이너스를 없애 계산을 편하게 만든 것입니다.

이제 z = 1935 를 대입합니다.

2y = 3 · 1935 − 1

오른쪽을 계산합니다. 한 단계씩 보겠습니다.

3 · 1935 = 5735
1 = 3535
5735 − 3535 = 57 − 3535 = 2235
각 줄의 근거 첫 줄   1장 §5의 곱셈 공식입니다. 분자에만 곱합니다. 3 × 19 = 57
둘째 줄   분모를 맞추려고 1을 3535 로 바꿔 썼습니다. 값은 그대로 1입니다
셋째 줄   분모가 같으므로 분자끼리 뺍니다. 1장 §5의 덧셈 규칙입니다

따라서 2y = 2235 입니다. Lang의 표현대로 2로 나누면

y = 1135
2로 나누는 계산 2235 ÷ 2 = 2235 × 12 = 2270

분자와 분모를 2로 약분하면 1135 입니다.

나눗셈이 역원을 곱하는 것이라는 게 1장 §6의 내용이었습니다.

4단계 : 되돌아가서 x 구하기

Lang이 적습니다. 마지막으로 (1)의 세 식 중 아무거나 하나를 써서 x 를 구할 수 있습니다. 셋째 식을 쓰겠습니다.

셋째 식은 x − 3y + z = −1 입니다. x 만 남기면

x = −1 + 3y − z
이항 과정 양변에 3y 를 더하고 z 를 뺐습니다.

x − 3y + z = −1
x = −1 + 3y − z

부호가 바뀌는 이유는 반대 연산을 했기 때문입니다. 1장 §2에서 배운 그대로입니다.

이제 y = 1135 와 z = 1935 를 넣습니다.

x = −1 + 3 · 1135 − 1935

세 항을 전부 분모 35로 맞춥니다.

−1 = −3535
3 · 1135 = 3335
− 1935 는 그대로

이제 분자끼리 계산합니다.

x = −35 + 33 − 1935
분자 계산을 순서대로 −35 + 33 = −2
−2 − 19 = −21
x = −2135

최종 답

x = −2135
y = 1135
z = 1935
기약으로 쓰고 싶다면 −2135 는 분자와 분모가 둘 다 7로 나누어떨어집니다. 약분하면 −35 입니다.

다만 1장 §5에서 Lang이 말했듯 약분하지 않은 형태도 완전히 맞는 답입니다. 세 값의 분모를 35로 통일해 두면 오히려 비교하기 좋습니다.

검산

§1에서 Lang이 강조했듯 구한 값이 실제로 해인지는 따로 확인해야 합니다. 세 식 전부에 넣어 봅니다.

첫째 식 3x + 2y + 4z = 1 인지

3(−21) + 2(11) + 4(19) = −63 + 22 + 76 = 35
3535 = 1 ✓
분자만 계산하는 요령 세 값의 분모가 전부 35로 같으므로, 분자만 계산한 뒤 마지막에 35로 나누면 됩니다. 분수를 매번 쓰지 않아도 돼서 훨씬 빠릅니다.

둘째 식 −x + y + 2z = 2 인지

−(−21) + 11 + 2(19) = 21 + 11 + 38 = 70
7035 = 2 ✓

셋째 식 x − 3y + z = −1 인지

−21 − 3(11) + 19 = −21 − 33 + 19 = −35
−3535 = −1 ✓
세 식 모두 통과 이제 이 값들이 진짜 해임이 확인되었습니다.

6. 소거 순서를 고르는 법CHOOSING THE ORDER

Lang이 스스로 편하도록 순서를 고른다고 했는데, 실전 기준을 정리하면 이렇습니다.

우선순위

1순위   계수가 +1 과 −1 처럼 부호만 반대인 짝. 곱할 필요 없이 바로 더하면 된다

2순위   계수가 1 이나 −1 인 항. 다른 쪽 계수를 그대로 곱하면 된다

3순위   한쪽 계수가 다른 쪽의 배수인 경우

마지막   아무것도 안 맞으면 두 계수의 공배수를 만든다

이 문제에서는 둘째 식과 셋째 식의 x 계수가 −1 과 +1 이었습니다. 1순위 상황이라 Lang이 그걸 먼저 잡은 것입니다.

Lang의 원문 표현이 정확히 이겁니다. 둘째와 셋째 식을 더하면 이미 x 가 사라진다.
내 설명 · 계수가 0인 항을 노려라

연습문제를 풀다 보면 어떤 식에 특정 미지수가 아예 없는 경우를 만납니다. 예를 들어 2x + 3z = 5 처럼 y 가 없는 식이요.

그건 y 의 계수가 0이라는 뜻이고, 이미 절반은 소거된 상태입니다. 그런 식이 보이면 y 를 소거 대상으로 잡으세요. 일이 확 줄어듭니다.

7. 기하적 의미WHAT IT LOOKS LIKE

내 보충 · 교재에는 없는 이야기

§1에서 Lang은 미지수 두 개짜리 식 하나가 직선 하나라고 했습니다. 그리고 동시해는 두 직선의 교점이었죠.

미지수가 셋이 되면 무대가 평면에서 공간으로 올라갑니다.

미지수식 하나가 뜻하는 것동시해
2개평면 위의 직선두 직선의 교점
3개공간 속의 평면세 평면이 만나는 점

3x + 2y + 4z = 1 을 만족하는 점 (x, y, z) 를 공간에 전부 찍으면 평면 한 장이 됩니다.

세 식을 동시에 만족한다는 건 세 평면 위에 동시에 있다는 뜻이고, 보통은 그런 점이 딱 하나입니다.

머릿속에 그리는 법 방의 구석을 보세요. 바닥 한 장, 벽 두 장이 만나는 곳입니다.

세 면이 만나는 지점이 점 하나죠. 그게 미지수 세 개짜리 연립방정식의 해입니다.

해가 없거나 무수히 많은 경우도 §1과 마찬가지로 생깁니다. 세 평면이 책의 페이지처럼 한 직선을 공유하면 해가 무수히 많고, 삼각기둥처럼 서로 어긋나면 해가 없습니다.

이 책에서 다루는 곳 공간 좌표는 이 책에서 본격적으로 다루지 않지만, 판별 기준인 3차 행렬식은 17장 §4에서 나옵니다. §1에서 본 ad − bc 의 3차 버전이에요.

8. 분모 없애기 ★CLEARING DENOMINATORS

Lang이 연습문제 9번 앞에 이렇게 적어둡니다. 다음 문제들에서는 풀기 전에 분모를 없애는 것이 가장 쉬울 것이다.

이 기술을 처음부터 설명하겠습니다.

왜 분모를 없애나

이런 식이 있다고 합시다.

12x + y − 34z = 1

계산은 되지만 분수를 계속 끌고 다녀야 합니다. 소거할 때마다 통분해야 하고, 실수가 늘어납니다.

해결 아이디어 양변에 적당한 수를 곱하면 분모가 전부 사라집니다. 이 조작이 정당한 근거는 이 페이지 맨 앞에서 확인한 A = B ⟹ kA = kB 입니다.

무슨 수를 곱하나

방법

식에 나오는 모든 분모의 최소공배수를 양변에 곱한다

위 식의 분모는 2와 4입니다. 최소공배수는 4입니다.

양변에 4를 곱합니다. 모든 항에 곱해야 합니다.

4 × 12x = 42x = 2x
4 × y = 4y
4 × 34z = 124z = 3z
4 × 1 = 4

따라서 원래 식은 이렇게 바뀝니다.

2x + 4y − 3z = 4
결과 분수가 전부 사라지고 정수 계수만 남았습니다. 이제 §1과 똑같이 다루면 됩니다.
가장 흔한 실수 두 가지 ① 분수가 있는 항에만 곱하고 y 같은 정수 항을 빼먹는 것
② 우변에 곱하는 걸 잊는 것

양변의 모든 항에 빠짐없이 곱해야 합니다.

식마다 곱하는 수가 다를 수 있다

중요 연립방정식에서는 각 식을 따로 처리합니다. 첫째 식의 분모가 2, 4라면 4를 곱하고, 둘째 식의 분모가 3이라면 3을 곱합니다.

세 식에 같은 수를 곱할 필요가 없습니다. 각 식은 독립적인 저울이니까요.
