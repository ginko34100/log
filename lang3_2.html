실수의 양수성

SERGE LANG · BASIC MATHEMATICS · CH.3 §2 · pp.64–70

§2 Real Numbers: Positivity

이 절의 한 문장 : 규칙 두 개를 더 얹어 실수를 특정하고, 드디어 √2 를 손에 넣는다.

1. §1이 남긴 숙제WHAT §1 LEFT UNFINISHED

§1의 Remark를 기억하시나요

§1 마지막에 Lang이 이렇게 말했습니다.

§1 Remark E 와 I 두 개짜리 체계도 덧셈과 곱셈의 기본 성질을 전부 만족한다. 따라서 실수만이 유일한 체계가 아니다.

즉 §1까지의 규칙만으로는 실수를 특정할 수 없습니다. 규칙이 더 필요해요.

그 부족한 규칙이 양수성(positivity) 입니다.

확인해 보면 E 와 I 체계에는 "어느 쪽이 양수인가" 를 정할 방법이 없습니다.

E 는 0 역할이니 후보에서 빠지고, 남은 건 I 뿐입니다. 그런데 I 의 덧셈 역원이 자기 자신이었죠(I + I = E).

그러면 I 와 −I 가 같은 것이 되어, "둘 중 정확히 하나만 양수"라는 조건을 만족시킬 수가 없습니다.

그래서 양수성을 얹는 순간 E·I 체계는 탈락합니다. 실수 쪽으로 한 걸음 좁혀진 거예요.

2. 양수와 두 개의 규칙 ★POS 1 AND POS 2

Lang이 먼저 기하적으로 설명합니다.

양수란

양수란 직선 위에서 0이 아니면서 0의 오른쪽에 놓인 수들이다.

a 가 양수일 때 a > 0 이라고 쓴다.

두 조건이 모두 필요합니다 ① 0이 아닐 것
② 0의 오른쪽에 있을 것

0 자신은 0의 오른쪽이 아니므로 양수가 아닙니다.

이어서 Lang은 양수성의 기본 성질을 나열합니다. 다른 성질들은 이 둘로부터 증명됩니다.

POS 1

a, b 가 양수면, 곱 ab 와 합 a + b 도 양수다.

쉽게 말하면 양수끼리 더해도 양수, 곱해도 양수. 양수의 세계는 닫혀 있습니다.
POS 2

a 가 실수면, 다음 셋 중 정확히 하나가 성립한다.

① a 가 양수    ② a = 0    ③ −a 가 양수

그리고 이 가능성들은 서로 배타적이다.

"서로 배타적" 이 무슨 뜻인가 두 개가 동시에 성립할 수 없다는 뜻입니다.

a 가 양수이면서 동시에 −a 도 양수인 일은 없습니다. 어느 수도 0의 양쪽에 동시에 있을 수 없으니까요.

이 배타성이 뒤에서 모순을 끌어내는 도구가 됩니다.
정의 · 음수

양수도 아니고 0도 아닌 수를 음수(negative) 라고 한다.

POS 2에 의해, a 가 음수면 −a 는 양수다.

아래에서 a 를 움직이며 POS 2의 세 경우를 확인해 보세요.

3. 1이 양수임을 증명하기PROVING 1 > 0

Lang이 이렇게 적습니다. 우리는 이미 1이 양수임을 안다. 하지만 이것은 두 성질과 덧셈·곱셈의 기본 규칙만으로 증명될 수 있다. 그리고 증명이 매우 간단하니 보면 흥미로울 것이라고 덧붙입니다.

내 설명 · 왜 당연한 걸 증명하나

"1이 양수다"는 너무 당연해서 증명할 게 없어 보입니다. 그런데 왜 증명할까요?

규칙 목록에 없기 때문입니다. POS 1과 POS 2 어디에도 "1은 양수다"라는 말이 없어요.

규칙에 없는데 사실이라면, 규칙에서 끌어낼 수 있어야 합니다. 못 끌어내면 규칙을 하나 더 추가해야 하고요.

이 책이 계속 하는 일 가정은 최소로 줄이고, 나머지는 증명한다. 1장 §3에서 "가정은 빚"이라고 했던 그 태도입니다.
PROOF · 1은 양수다
1 또는 −1 중 하나가 양수다
POS 2를 a = 1 에 적용했습니다.

세 경우는 "1이 양수" 또는 "1 = 0" 또는 "−1 이 양수" 입니다.

그런데 1 ≠ 0 이므로 가운데는 탈락합니다. 남은 두 경우 중 하나가 참입니다.
1이 양수가 아니라고 하자. 그러면 −1이 양수다
귀류법을 시작합니다. 보이고 싶은 것의 반대를 가정하고 모순을 찾습니다.

1이 양수가 아니라면, 앞 줄의 두 경우 중 남는 것은 −1 이 양수라는 쪽뿐입니다.
(−1)(−1) 은 양수다
POS 1입니다. 양수끼리 곱하면 양수예요.

−1 이 양수라고 가정했으니, −1 과 −1 을 곱한 것도 양수입니다.
그런데 (−1)(−1) = 1 이다
1장 §3에서 증명한 것입니다. N8과 N4를 써서 (−1)(−1) = −(−1) = 1 을 보였죠.

§1에서 "기본 성질만으로 증명한 것은 실수에서도 유효하다"고 했으므로, 이 결과를 그대로 가져다 쓸 수 있습니다.
∴ 1이 양수다 (모순)
앞 두 줄을 합치면 1이 양수라는 결론이 나옵니다.

그런데 우리는 1이 양수가 아니라고 가정했습니다. 모순입니다.

따라서 가정이 틀렸고, 1은 양수입니다. 그리고 POS 2의 배타성에 의해 −1 은 양수가 아닙니다.

증명 끝.

그다음 자연스럽게

Lang이 이어서 적습니다. POS 1을 쓰면 1 + 1 = 2 가 양수이고, 2 + 1 = 3 이 양수이며, 계속 그렇다고 결론지을 수 있습니다.

1, 2, 3, …

따라서 이들을 양의 정수라고 불러온 것이 POS 1, POS 2 두 규칙과 모순되지 않습니다.

왜 이걸 확인하나 1장에서 우리는 1, 2, 3, … 을 "양의 정수"라고 이름 붙였습니다. 그때는 그냥 이름이었어요.

이제 "양수"라는 개념을 규칙으로 정의했으니, 옛 이름과 새 정의가 어긋나지 않는지 확인해야 합니다. 어긋나면 큰일이니까요.

연습으로 남긴 네 가지

Lang은 나머지 기본 성질들이 두 규칙으로부터 쉽게 증명된다며 연습문제 1, 2, 3번으로 남깁니다.

연습문제로 남긴 것

a 양수, b 음수면 ab 는 음수다

a 음수, b 음수면 ab 는 양수다

a 양수면 1/a 은 양수다

a 음수면 1/a 은 음수다

아래 연습문제에서 전부 풉니다 1번 b·c 와 2번, 3번이 정확히 이 넷입니다.

4. 제곱근 공리 ★ 구멍을 메우는 순간THE SQUARE ROOT AXIOM

여기가 3장 전체에서 가장 중요한 한 줄입니다.

증명 없이 가정하는 성질

모든 양의 실수는 제곱근을 갖는다.

즉 a > 0 이면, b2 = a 를 만족하는 수 b 가 존재한다.

내 설명 · 이 한 줄이 하는 일

1장 §5로 돌아가 봅시다. 거기서 우리가 알아낸 것은 이랬습니다.

§5 정리 4 제곱해서 2가 되는 유리수는 없다

그때 제가 이렇게 적었었죠. "정리 4가 말한 건 유리수 중에는 없다는 것뿐입니다. √2 라는 수가 존재하는지 자체는 아직 증명하지 않았습니다."

이제 그 존재를 선언합니다. 제곱근 공리가 정확히 그 일을 해요.

순서를 정리하면 ① §5 정리 4 : 제곱이 2인 유리수는 없다
② §2 제곱근 공리 : 제곱이 2인 실수는 있다
③ 따라서 그 수는 유리수가 아닌 실수, 즉 무리수다

Lang이 정확히 이 결론을 적습니다.

Lang의 결론

이 성질과 1장 §5의 정리 4에 의해, 우리는 이제 제곱이 2인 수가 무리수이지만 실수로서 존재한다는 것을 알게 되었다.

"공리로 가정한다" 는 말의 무게 Lang은 이걸 증명하지 않고 받아들입니다. 실수를 엄밀하게 구성하면 증명할 수 있지만, §1에서 말했듯 그 과정은 길고 지루하기 때문입니다.

대신 "실수는 이런 성질을 갖는 것" 이라고 규정하고 넘어갑니다.

5. 제곱해서 2가 되는 수는 정확히 둘PRECISELY TWO

Lang이 자연스러운 질문을 던집니다. 주어진 양수에 대해, 제곱이 그 수가 되는 수는 몇 개인가? 예를 들어 x2 = 2 를 만족하는 실수 x 는 전부 무엇인가?

답

정확히 두 개다. 하나는 양수, 다른 하나는 음수다.

PROOF · 해는 정확히 둘
b2 = 2 인 b 를 하나 잡는다
제곱근 공리 덕분에 이런 b 가 존재합니다. 방금 받아들인 성질이에요.

그리고 x 를 x2 = 2 를 만족하는 아무 실수라고 둡니다. x 가 결국 무엇인지 알아내는 게 목표입니다.
x2 − b2 = 0
x2 = 2 이고 b2 = 2 이므로 둘은 같은 수입니다.

한쪽에서 다른 쪽을 빼면 0이 됩니다.
(x + b)(x − b) = 0
1장 §3의 세 번째 암기 공식을 거꾸로 썼습니다.

(a + b)(a − b) = a2 − b2 이었죠. 오른쪽에서 왼쪽으로 읽은 것입니다.

"반드시 외우라"던 그 공식이 여기서 쓰입니다.
x + b = 0  또는  x − b = 0
1장 §6의 정리입니다. 두 수의 곱이 0이면 둘 중 하나가 0이어야 합니다.

§6에서 이 정리를 소개하며 제가 이렇게 적었었죠. "이게 4장 이차방정식 전체를 떠받치는 기둥" 이라고요.

바로 여기서 처음 쓰입니다.
x = −b  또는  x = b
각 식에서 x 를 남겼습니다.

x + b = 0 이면 양변에서 b 를 빼서 x = −b
x − b = 0 이면 양변에 b 를 더해서 x = b
(−b)2 = (−b)(−b) = b2 = 2
확인 단계입니다. −b 도 정말로 해가 맞는지 봐야 합니다.

(−b)(−b) = b2 은 1장 §3의 N10입니다. 음수 곱하기 음수는 양수죠.

그래서 −b 의 제곱도 2입니다. 둘 다 진짜 해입니다.

증명 끝.
이 증명이 보여준 것 ① 해는 b 와 −b 말고는 없다 (앞의 네 줄이 이걸 보였습니다)
② 그 둘은 정말로 해다 (마지막 줄이 이걸 보였습니다)

2장 §1에서 Lang이 강조했던 "후보를 좁히는 것과 진짜인지 확인하는 것은 다르다" 가 여기서도 지켜졌습니다.

6. √ 기호의 약속THE CONVENTION

제곱이 2인 두 수 중 POS 2에 의해 정확히 하나만 양수입니다. 여기서 Lang이 약속을 하나 합니다.

수학 전체에서 통용되는 약속

제곱이 2인 두 수 중 양수인 쪽만 "2의 제곱근"이라 부르기로 한다. 그 양수를 √2 로 나타낸다.

따라서 제곱이 2인 두 수는 이렇게 씁니다.

√2   와   −√2

그리고 √2 > 0 입니다.

왜 이런 약속이 필요한가 해가 둘인데 기호는 하나입니다. 기호가 두 값을 동시에 가리키면 계산이 불가능해집니다.

그래서 양수 쪽 하나만 지목하기로 정한 겁니다. 자연의 법칙이 아니라 사람이 정한 약속이에요.

같은 논증이 임의의 양수 a 에 대해서도 그대로 성립합니다. 앞의 논증에서 2를 a 로 바꾸기만 하면 됩니다.

일반화

√a 는 제곱이 a 인 유일한 양수를 나타낸다.

제곱이 a 인 다른 수는 −√a 이다.

따라서 x2 = a 의 해는

x = ±√a

이라 쓰고, "x는 플러스 마이너스 루트 a" 라고 읽는다.

이걸 다르게 표현하면 이렇습니다.

다른 표현

x, y 가 x2 = y2 을 만족하는 수라면, x = y 이거나 x = −y 이다.

⚠ Lang이 명시한 함정

하지만 x = y 라고 결론지을 수는 없습니다.

구체적으로 32 = 9 이고 (−3)2 = 9 입니다. 제곱이 같죠.

그렇다고 3 = −3 은 아닙니다. 제곱이 같다고 원래 수가 같은 건 아닙니다.

아래에서 a 를 움직이며 두 해가 어떻게 놓이는지 보세요.

7. 절댓값 ★ABSOLUTE VALUE

Lang이 이어서 짚습니다. 임의의 수 x 에 대해, √(x2) 는 0 이상이다.

왜 0 이상인가 √ 기호는 양수 쪽만 가리키기로 약속했기 때문입니다. 방금 정한 그 약속이죠.

Lang의 예입니다.

√((−3)2) = √9 = 3
한 단계씩 ① (−3)2 = 9  (음수의 제곱은 양수)
② √9 = 3  (제곱이 9인 두 수는 3과 −3인데, 약속에 따라 양수 쪽을 취함)

결과가 −3이 아니라 3입니다. 부호가 사라졌어요.
정의 · 절댓값

√(x2) 를 x 의 절댓값(absolute value) 이라 하고 이렇게 쓴다.

|x| = √(x2)

따라서

|−3| = 3      |−5| = 5

물론 양수 a 에 대해서는 |a| = a 입니다. 그래서

|3| = 3      |5| = 5
내 설명 · 절댓값을 세 가지로 보기

① 정의대로 제곱했다가 제곱근을 취하는 것

무슨 일이 벌어지나 제곱하면 부호가 사라집니다. 음수든 양수든 제곱은 양수니까요.

그다음 제곱근을 취하면 크기는 원래대로 돌아오는데, 부호는 돌아오지 않습니다. 약속상 양수만 취하니까요.

결과적으로 부호만 떼어내는 장치가 됩니다.

② 수직선에서 0으로부터의 거리

거리로 보면 −3 은 0에서 왼쪽으로 3칸 떨어져 있습니다. 거리는 3칸이죠. 방향은 거리에 포함되지 않습니다.

그래서 |−3| = 3 입니다.

③ 실용적으로 부호를 떼는 것

계산할 때는 안에 든 것이 양수면 그대로, 음수면 부호를 뗍니다. 그게 전부입니다.
⚠ 가장 흔한 실수

√(x2) = x 라고 쓰면 틀립니다.

x = −3 을 넣어 보세요. 좌변은 3이고 우변은 −3입니다. 다릅니다.

올바른 식은 √(x2) = |x| 입니다.

절댓값 방정식

Lang이 이렇게 적습니다. 이 책에서 절댓값을 많이 다루지는 않을 것이고, 여기서 지나치게 강조하고 싶지도 않다. 다만 가끔 필요하고, −3 의 절댓값이 3이라는 건 알아야 하니, 정의를 확실히 하기 위해 예제를 하나 준다고 합니다.

Lang의 예제

|x + 5| = 2 를 만족하는 모든 x 를 구하라.

SOLUTION
x + 5 = 2  또는  x + 5 = −2
절댓값이 2라는 말은 무슨 뜻인가를 풀어쓴 것입니다.

절댓값은 부호를 뗀 크기입니다. 부호를 떼고 2가 되는 수는 2와 −2 두 개뿐이에요.

그러니 x + 5 라는 덩어리가 2이거나 −2여야 합니다.
x = 2 − 5 = −3
첫 번째 경우입니다. 양변에서 5를 뺐습니다.
x = −5 − 2 = −7
두 번째 경우입니다. x + 5 = −2 에서 양변에서 5를 빼면 x = −2 − 5 = −7 입니다.

답은 두 개입니다. x = −3 과 x = −7.
검산 |−3 + 5| = |2| = 2 ✓
|−7 + 5| = |−2| = 2 ✓

8. 유리화 ★RATIONALIZING

먼저 · 1/√2 = √2/2 인 이유

Lang이 관찰 하나를 던집니다.

1√2 = √22

이유는 2 = √2 · √2 이고, 십자곱에 의해 성립하기 때문입니다.

십자곱으로 확인 좌변 분자 × 우변 분모 = 1 × 2 = 2
우변 분자 × 좌변 분모 = √2 × √2 = 2

양쪽이 같으므로 두 분수는 같은 수입니다. 1장 §5의 십자곱 규칙 그대로예요.

Lang의 의견

Lang의 솔직한 견해

초등 교육에서는 1/√2 같은 몫을 분모에 제곱근이 없는 형태로 바꾸는 것이 전통이다.

하지만 우리로서는 이것이 일반적으로 특별히 유용하지 않다. 특수한 경우에는 유용할 수 있으나, 몫을 다루는 다른 조작들보다 더하지도 덜하지도 않으며, 필요에 따라 그때그때 판단할 일이다.

실제로 많은 경우 제곱근을 분모에 두는 편이 유용하다.

내 설명 · 이 말이 왜 중요한가

학교에서는 "분모에 루트가 있으면 무조건 없애라"고 배웁니다. 그래서 규칙인 줄 알기 쉬워요.

Lang은 그건 규칙이 아니라 관습이라고 말합니다. 필요할 때만 하라는 거예요.

실제로 분자를 유리화하는 게 나은 경우 아래 두 번째 예제가 그렇습니다. 미적분에서는 분모에 루트를 남기는 쪽이 훨씬 유용합니다.

두 예제 모두 1장 §3의 오래된 규칙에 기반합니다.

(x + y)(x − y) = x2 − y2
왜 이 공식인가 이 공식의 오른쪽에는 제곱만 남습니다. 그리고 (√5)2 = 5 처럼 제곱하면 루트가 사라집니다.

그래서 이 공식이 루트를 없애는 도구가 됩니다.

예제 1 · 분모의 유리화

문제

32 + √5 를 분모가 유리수인 몫으로 나타내라.

분자와 분모에 2 − √5 를 곱합니다.

왜 하필 2 − √5 인가 분모가 2 + √5 입니다. 위 공식에서 x = 2, y = √5 로 보면 (x + y) 꼴이에요.

(x − y) 에 해당하는 2 − √5 를 곱하면 x2 − y2 이 되어 루트가 사라집니다.

단계별로 실행해 보세요.

예제 2 · 분자의 유리화

Lang이 이 예제를 소개하며 이렇게 적습니다. 이 예제는 미적분학의 더 고급 과정에서 실제로 등장하는 상황과 같은 표기를 쓴다.

문제

x 와 x + h 가 양수일 때, 다음 몫을 제곱근이 분모에만 나타나도록 쓰라.

√(x+h) − √xh

분자와 분모에 (√(x+h) + √x) 를 곱하면 결과는 이렇습니다.

√(x+h) − √xh = 1√(x+h) + √x
위 실행기에서 "두 번째 예제로" 를 누르면 단계별로 볼 수 있습니다
내 보충 · 이걸 왜 하는가

Lang이 "미적분에서 등장한다"고만 하고 넘어가는데, 왜 유용한지를 알면 훨씬 와닿습니다.

미적분에서는 h 를 0에 한없이 가깝게 보내는 계산을 합니다.

원래 형태에 h = 0 을 넣으면

문제 발생 분자는 √x − √x = 0
분모는 h = 0

0/0 이 되어 계산이 불가능합니다.

유리화한 형태에 넣으면

해결 1√(x+0) + √x = 12√x

깔끔하게 계산됩니다. 분모의 h 가 약분으로 사라졌기 때문입니다.

그래서 여기서는 분모에 루트를 남기는 쪽이 옳습니다. Lang이 "분모에 루트를 두는 게 유용한 경우가 많다"고 한 이유가 이겁니다.

참고 이 결과 12√x 가 바로 √x 의 도함수입니다. 미적분 첫 시간에 만나게 됩니다.

용어

이름

분모의 유리화 : 몫을 같은 값의 다른 몫으로 바꾸되, 분모에 제곱근이 나타나지 않게 하는 것

분자의 유리화 : 같은 방식으로 분자에 제곱근이 나타나지 않게 하는 것

Lang의 말로 둘 다 실전에서 유용합니다.

Lang의 마지막 안내 제곱근은 피타고라스 정리와 8장 §2의 두 점 사이 거리를 다룰 때 쓰이게 됩니다. 지금 그 부분을 찾아봐도 좋다고 권합니다.
