곱셈의 규칙

SERGE LANG · BASIC MATHEMATICS · CH.1 §3 · pp.13–22

§3 Rules for Multiplication

이 절의 한 문장 — 덧셈과 곱셈을 이어주는 다리(분배법칙) 하나를 놓고, 그 위로 나머지를 전부 건넌다.
먼저 · 이 절의 지도

§2에서 덧셈만 다뤘습니다. 이제 곱셈이 들어옵니다. 그런데 곱셈 규칙 자체보다 중요한 게 하나 있어요.

덧셈과 곱셈은 서로 다른 연산입니다. 이 둘이 섞인 식(예: 3(x + 2))을 계산하려면 둘을 연결하는 규칙이 반드시 필요해요. 그게 분배법칙입니다.

§3의 나머지는 거의 전부 분배법칙에서 흘러나옵니다. 음수×음수=양수도, (a+b)2 공식도 전부요. 그러니 분배법칙 한 곳에 힘을 주고 읽으세요.

1. 곱셈에도 교환·결합법칙이 있다COMMUTATIVITY & ASSOCIATIVITY

가정 (증명 안 함)
ab = ba
(ab)c = a(bc)

a, b, c 가 음수든 양수든 0이든 전부 성립합니다

덧셈 때와 똑같은 모양이죠. 순서를 바꿔도 되고(교환), 어느 둘을 먼저 묶어도 됩니다(결합).

내 설명 · 왜 순서를 바꿔도 되나

덧셈은 "걷기"로 봤죠. 곱셈은 "직사각형 넓이"로 보면 됩니다.

3 × 5 는 가로 3칸, 세로 5칸짜리 직사각형의 칸 수입니다. 이 직사각형을 90도 돌리면 가로 5칸, 세로 3칸이 되죠. 돌렸다고 칸이 늘거나 줄지 않으니 3 × 5 = 5 × 3 입니다.

결합법칙은 상자입니다. (3×5)×2 는 "3×5 바닥판을 2층으로 쌓기", 3×(5×2) 는 "3줄 × (5×2짜리 옆면)". 어느 방향으로 세든 같은 상자의 부피예요.

곱셈 표기는 세 가지를 섞어 씁니다.

표기예쓰는 곳
붙여쓰기ab문자끼리 — 가장 흔함
가운뎃점3 · 7 = 21숫자끼리
괄호(3)(7)부호가 섞일 때
⚠ 숫자끼리는 붙여 쓸 수 없다

3 × 7 을 37 이라고 쓰면 삼십칠이 돼버립니다. 그래서 숫자끼리는 반드시 점이나 괄호를 씁니다. 문자는 이런 혼동이 없어서 ab 로 붙여 쓰는 거예요.

2. 1과 0을 곱하면 — N6

N6
1a = a     0a = 0
내 설명

1a = a 는 "a를 한 번만 놓기" 입니다. 한 개 놓았으니 그대로죠. 덧셈에서 0이 했던 역할(N1)을 곱셈에서는 1이 합니다. 아무것도 안 바꾸는 수, 항등원이에요.

0a = 0 은 "a를 한 번도 안 놓기" 입니다. 아무것도 안 놓았으니 0.

재밌는 건 Lang이 이걸 나중에 증명해 버린다는 겁니다. 규칙 목록에 넣어놓고 "사실 이건 다른 규칙들에서 나온다"고 하죠. 아래 4번에서 봅니다.

3. 숫자는 숫자끼리, 문자는 문자끼리

실전에서 계속 쓰는 기술입니다. 교환·결합법칙만으로 이런 정리가 가능해집니다.

EXAMPLE · (2a)(3b) = 6ab
(2a)(3b)
출발. 곱해진 것은 2, a, 3, b 네 개입니다.
= 2(a(3b))
결합법칙. 묶는 방식을 바꿔 2를 맨 앞으로 떼어냈습니다.
= 2((3a)b)
교환법칙. 안쪽의 a(3b) 에서 a 와 3 의 순서를 바꿨습니다. 목표는 숫자 3을 왼쪽으로 끌어오는 것.
= (2 · 3)ab
다시 결합법칙. 이제 숫자 2와 3이 나란히 붙었으니 묶어버립니다.
= 6ab
2 · 3 = 6. 끝.

실제로 계산할 땐 이 과정을 다 쓰지 않고 한 번에 씁니다. 하지만 왜 되는지는 알고 있어야 해요.

식숫자끼리답
(5x)(7y)5 · 7 = 3535xy
(2a)(3b)(5x)2 · 3 · 5 = 3030abx

4. 분배법칙 ★ 이 절의 심장DISTRIBUTIVITY

가정 (증명 안 함)
a(b + c) = ab + ac
(b + c)a = ba + ca

Lang은 이걸 증명하지 않고 가정으로 받습니다. 하지만 "끊임없이 쓰게 될 것"이라고 못박아요.

내 설명 · 직사각형으로 보기

분배법칙은 직사각형을 세로로 한 번 자르는 것입니다.

세로 a, 가로 b + c 인 직사각형이 있어요. 넓이는 a(b+c) 입니다.

이제 가로를 b 와 c 지점에서 싹둑 자릅니다. 조각이 둘 생기죠 — 넓이 ab 짜리와 ac 짜리.

자른다고 넓이가 사라지지 않습니다. 그래서 a(b+c) = ab + ac. 이게 전부예요.

아래에서 직접 잘라보세요.

숫자를 바꿔가며 보세요. 어떤 값을 넣어도 두 넓이가 같습니다. 이 그림 하나가 앞으로 나올 모든 전개 공식의 뿌리입니다.

5. 한쪽만 알면 반대쪽은 공짜

Lang이 작은 관찰을 하나 합니다. 왼쪽 분배법칙과 교환법칙만 있으면 오른쪽 분배법칙은 증명된다는 거예요.

PROOF · 오른쪽 분배법칙
(b + c)a = a(b + c)
곱셈의 교환법칙. (b+c) 를 통째로 하나의 수로 보고 a 와 자리를 바꿨습니다.
= ab + ac
왼쪽 분배법칙(가정한 것)을 그대로 적용.
= ba + ca
다시 교환법칙을 두 번. ab = ba, ac = ca.
증명 끝.
내 설명 · 왜 이런 짓을 하나

수학책이 자꾸 "가정을 최소로 줄이려는" 이유가 있습니다. 가정은 빚이거든요. 증명 없이 받아온 것이니까요.

빚이 적을수록 이론이 튼튼합니다. 그래서 "이건 이미 있는 걸로 만들 수 있네?" 싶으면 가정 목록에서 빼버리는 겁니다.

6. 0a = 0도 사실은 증명된다

N6에 넣어뒀던 0a = 0 을 Lang이 직접 증명해 보입니다. 분배법칙이 도구입니다.

PROOF · 0a = 0
0a + a = 0a + 1a
N6의 1a = a. 오른쪽 a 를 일부러 1a 로 바꿔 썼습니다. 왜냐면 분배법칙을 쓸 모양으로 만들기 위해서예요.
= (0 + 1)a
분배법칙을 거꾸로. (b+c)a = ba + ca 를 오른쪽에서 왼쪽으로 읽은 겁니다. 공통 인수 a 로 묶었어요.
= 1a = a
0 + 1 = 1 (덧셈 N1), 그리고 1a = a (곱셈 N6).
∴ 0a + a = a
여기까지가 1단계. 이제 0a 만 남기면 됩니다.
0a + a − a = a − a = 0
양변에 −a 를 더했습니다. §2 N3에서 배운 그 수법이에요 — 없애고 싶은 놈의 마이너스를 더한다.
0a = 0
왼쪽은 0a + (a − a) = 0a + 0 = 0a 입니다.
증명 끝. 0을 곱하면 0이 되는 게 "당연한 사실"이 아니라 분배법칙의 결과였습니다.

7. N7 — 마이너스 1을 곱하면

N7
(−1)a = −a
내 설명 · 왜 이게 중요한가

−a 와 (−1)a 는 겉보기엔 같아 보이지만 출신이 다릅니다.

−a 는 덧셈 세계의 개념이에요. "a에 더해서 0을 만드는 짝"이었죠(§2 N2). (−1)a 는 곱셈이고요.

N7은 이 둘이 같다는 걸 증명하는 다리입니다. 이게 있어야 "마이너스를 밖으로 빼기" 같은 조작이 정당해집니다.

PROOF · N7
(−1)a + a = (−1)a + 1a
a = 1a (N6). 또 분배법칙 쓸 모양을 만드는 겁니다. 같은 수법이 반복되죠.
= (−1 + 1)a
분배법칙을 거꾸로. 공통 인수 a 로 묶었습니다.
= 0a = 0
−1 + 1 = 0 (§2 N2), 그리고 방금 증명한 0a = 0.
∴ (−1)a = −a
§2의 N3이 "더해서 0이 되면 서로 마이너스"라고 했습니다. (−1)a + a = 0 이 나왔으니, (−1)a 는 a 의 마이너스입니다.
증명 끝.

8. N8·N9 — 마이너스는 어디에 붙어도 같다

N8 · N9
−(ab) = (−a)b = a(−b)

곱셈에서 마이너스 하나는 어디에 붙이든 결과가 같다는 뜻입니다.

PROOF · N8
보일 것: ab + (−a)b = 0
N3 전략입니다. (−a)b 가 ab 의 마이너스임을 보이려면 둘을 더해 0이 나오는 걸 보이면 충분합니다.
ab + (−a)b = (a + (−a))b
분배법칙을 거꾸로. 공통 인수 b 로 묶었습니다.
= 0 · b = 0
괄호 안은 a + (−a) = 0 (§2 N2). 그리고 0b = 0.
증명 끝. N9도 같은 방법으로 나옵니다 — 이건 Lang이 독자 몫으로 남겼어요.

이 규칙 덕분에 아래 변형들이 전부 자유롭습니다.

−(3a) = (−3)a = 3(−a)
식전개
4(a − 5b)4a − 20b
−3(5a − 7b)−15a + 21b
(−2a)(3b)(4c)−24abc
(−4x)(5y)(−3c)60xyc
⚠ 두 번째 줄을 특히 보세요

−3(5a − 7b) 에서 뒤쪽이 +21b 입니다. −3 × (−7b) 이므로 마이너스가 두 개, 즉 플러스예요. −21b 라고 쓰는 게 가장 흔한 실수입니다.

9. 음수 × 음수 = 양수 ★N10

N10
(−a)(−b) = ab

먼저 가장 작은 경우를 Lang의 방식으로 봅시다.

PROOF · (−1)(−1) = 1
(−1)(−1) = −(1 · (−1))
N8입니다. (−a)b = −(ab) 에서 a = 1, b = −1 로 두었어요. 앞에 붙은 마이너스를 괄호 전체 앞으로 끄집어낸 겁니다.
= −(−1)
1 · (−1) = −1 (N6).
= 1
§2의 N4. −(−a) = a. 마이너스 두 번은 제자리.
증명 끝.
내 설명 · 그래도 납득이 안 될 때

증명은 맞는데 "그래서 왜 음수끼리 곱하면 양수야?"가 남죠. 세 가지로 보겠습니다.

① 패턴으로 — 표가 스스로 답한다

식답변화
3 × (−2)−6
2 × (−2)−4+2
1 × (−2)−2+2
0 × (−2)0+2
(−1) × (−2)2+2
(−2) × (−2)4+2

왼쪽 수를 1씩 줄일 때마다 답은 일정하게 2씩 커집니다. 이 규칙성이 0을 지나서도 계속되려면, (−1)×(−2) 는 2일 수밖에 없습니다. 다른 값을 넣으면 패턴이 깨져요.

② 방향 뒤집기로

곱셈에서 −1 을 곱하는 건 수직선에서 방향을 뒤집는 것입니다. 오른쪽을 보고 있었으면 왼쪽을 보게 되죠.

그럼 (−1)(−1) 은? 뒤집고 또 뒤집기. 두 번 돌면 원래 방향입니다. 그래서 1이에요. §2 N4의 "마이너스 두 번은 제자리"와 정확히 같은 이야기입니다.

③ 빚으로

매달 2만원씩 나가는 자동이체가 있습니다. 한 달에 −2만원이죠. 그럼 3개월 전의 잔고는 지금보다 얼마나 많았을까요?

3개월 전은 −3, 매달 −2만원. (−3)×(−2) = +6. 6만원 더 많았습니다. 실제로 맞죠 — 빠져나갈 돈이 아직 안 빠졌으니까요.

부호 규칙을 정리하면 이렇습니다.

곱결과예
양 × 양양3 · 5 = 15
양 × 음음(−4) · 7 = −28
음 × 음양(−3)(−5) = 15

실전 요령: 마이너스 개수를 세세요. 짝수 개면 답은 양수, 홀수 개면 음수입니다. (−4x)(5y)(−3c) 는 마이너스 2개 → 양수 → 60xyc.

10. 거듭제곱POWERS

같은 수를 여러 번 곱할 때 쓰는 줄임 표기입니다.

aa = a2    aaa = a3    aaaa = a4

일반적으로 n 이 양의 정수일 때 an 은 a 를 n 번 곱한 것이고, 이를 a 의 n제곱이라고 읽습니다.

⚠ 곱셈이지 덧셈이 아니다

a3 은 a + a + a 가 아니라 a × a × a 입니다. a = 2 로 확인하면 23 = 8 이지 6이 아니에요.

N11
am+n = aman
내 설명 · 외울 필요가 없습니다

지수는 "몇 번 곱했나"를 세는 숫자일 뿐입니다. 그러니 곱셈끼리 붙이면 개수가 더해질 수밖에 없어요.

a2a3 = (aa)(aaa) — 괄호를 떼면 a 가 몇 개죠? 다섯 개입니다. 그래서 a5.

헷갈리면 지수를 풀어서 세어보세요. 그게 정의니까요.

N12
(am)n = amn
내 설명

(a3)4 은 "a 세 개짜리 묶음"을 네 번 곱하는 겁니다. 묶음당 3개씩 4묶음이니 총 3 × 4 = 12개. 그래서 a12.

N11은 개수를 더하고, N12는 개수를 곱합니다. 이 둘을 헷갈리면 답이 완전히 달라져요.

식풀어보면답

(4x)24x · 4x = 4 · 4 · xx16x2
(7x)(2x)(5x)7 · 2 · 5 · xxx70x3
(ab)na끼리 b끼리 모으면anbn

11. 인구 문제 — 거듭제곱이 쓰이는 곳

Lang이 든 예입니다. 1930년 인구 30만, 20년마다 두 배. 60년 뒤 인구는?

  1. 20년 후 → 2 × 30만
  2. 40년 후 → 또 두 배니까 22 × 30만
  3. 60년 후 → 23 × 30만 = 8 × 30만 = 240만
내 설명 · 푸는 순서를 고정하세요

이 유형은 항상 두 단계입니다.

1단계 — 몇 번 배가 되었나? = (전체 기간) ÷ (배가 주기). 여기서는 60 ÷ 20 = 3번.

2단계 — 처음 값 × (배율)횟수. 여기서는 30만 × 23.

세 배씩 늘면 밑이 2가 아니라 3이 될 뿐, 구조는 같습니다.

12. 반드시 외워야 할 세 공식 ★

Lang이 이례적으로 강한 말을 씁니다 — 소리 내어 읽어 시처럼 외우라고요. 귀로 기억하라는 겁니다.

암기 대상
(a + b)2 = a2 + 2ab + b2
(a − b)2 = a2 − 2ab + b2
(a + b)(a − b) = a2 − b2
내 설명 · 첫 공식을 그림으로

(a+b)2 은 한 변이 a+b 인 정사각형의 넓이입니다.

가로도 a 와 b 로 자르고, 세로도 a 와 b 로 자르면 조각이 네 개 나옵니다.

그중 ab 짜리 직사각형이 두 개라는 게 핵심이에요. 2ab 의 2가 바로 여기서 나옵니다. 이걸 빼먹는 게 가장 흔한 실수입니다.

대수적으로도 확인해 봅시다. 분배법칙만 반복해서 쓰면 나옵니다.

PROOF · (a+b)² = a² + 2ab + b²
(a + b)2 = (a + b)(a + b)
거듭제곱의 정의입니다. 제곱은 자기 자신을 두 번 곱한 것.
= a(a + b) + b(a + b)
오른쪽 분배법칙. 앞의 (a+b) 를 a 와 b 로 쪼개 각각 뒤 괄호에 곱했습니다.
= aa + ab + ba + bb
왼쪽 분배법칙을 두 번. a 를 괄호 안 두 항에, b 를 괄호 안 두 항에 각각 곱했습니다. 여기서 항이 4개 생깁니다 — 정사각형 조각 4개와 정확히 대응해요.
= a2 + ab + ab + b2
aa = a2, bb = b2 (거듭제곱 정의). 그리고 ba = ab (곱셈 교환법칙) — 이 한 걸음 덕분에 두 항이 같은 모양이 됩니다.
= a2 + 2ab + b2
같은 것 두 개는 2배. ab + ab = 2ab.
증명 끝.

두 번째 공식은 b 자리에 −b 를 넣은 것과 같습니다.

(a − b)2 = a2 − 2ab + b2
⚠ 마지막 항의 부호

가운데는 −2ab 로 부호가 바뀌는데 마지막 b2 은 그대로 플러스입니다. (−b)(−b) = +b2 이니까요. 음수 곱하기 음수가 양수라는 걸 여기서 씁니다.

세 번째 공식은 가운데 항이 통째로 사라지는 게 특징입니다.

PROOF · (a+b)(a−b) = a² − b²
= a(a − b) + b(a − b)
오른쪽 분배법칙. 앞 괄호를 쪼갰습니다.
= a2 − ab + ba − b2
왼쪽 분배법칙 두 번. 부호에 주의하세요 — b × (−b) = −b2.
= a2 − ab + ab − b2
교환법칙으로 ba = ab.
= a2 − b2
−ab + ab = 0 (§2 N2). 가운데가 서로 잡아먹었습니다.
증명 끝.
내 설명 · 이 공식이 특히 유용한 이유

암산에 바로 씁니다. 98 × 102 를 계산해 보세요.

98 = 100 − 2, 102 = 100 + 2 이므로 (100−2)(100+2) = 1002 − 22 = 10000 − 4 = 9996.

세로셈보다 훨씬 빠르죠. 공식은 외우기 위한 게 아니라 일을 줄이기 위한 것입니다.

13. 세 개 이상 전개하기

Lang의 예제입니다. (2x + 1)(x − 2)(x + 5). 한 번에 하려 하지 말고 두 개씩 끊으세요.

  1. 앞의 두 개부터: (2x+1)(x−2) = 2x(x−2) + 1(x−2)
  2. 전개하면 2x2 − 4x + x − 2
  3. 같은 항 정리 → 2x2 − 3x − 2
  4. 이제 남은 (x+5) 를 곱합니다: (2x2−3x−2)x + (2x2−3x−2)5
  5. 전개 → 2x3 − 3x2 − 2x + 10x2 − 15x − 10
  6. 정리 → 2x3 + 7x2 − 17x − 10

5단계에서 −3x2 과 +10x2 을 합쳐 +7x2, −2x 와 −15x 를 합쳐 −17x. 차수가 같은 것끼리만 합칩니다.

내 설명 · 검산법

전개가 맞는지 30초 만에 확인하는 법이 있습니다. 양변에 같은 숫자를 넣어보세요.

x = 1 을 넣으면 원식은 (3)(−1)(6) = −18.

답에 넣으면 2 + 7 − 17 − 10 = −18. 일치합니다.

계산 실수를 잡는 데 이만한 게 없어요. x = 0 이나 x = 1 을 쓰면 특히 빠릅니다.

14. 연습 문제

교재 §3 연습문제(21–22쪽)와 같은 유형입니다.

Q1(3a)(4b)(2c) 를 간단히 하세요.
숫자끼리 3·4·2 = 24, 문자끼리 abc → 24abc
Q2−5(2x − 3y) 를 전개하세요.
−5 · 2x = −10x
−5 · (−3y) = +15y ← 마이너스 둘이라 플러스
답: −10x + 15y
Q3(2a2)3 을 계산하세요.
(2a2)3 = 23(a2)3
23 = 8, N12에 의해 (a2)3 = a6
답: 8a6
Q4(x − 3)2 을 전개하세요.
두 번째 공식에 a = x, b = 3
x2 − 2·x·3 + 32 = x2 − 6x + 9
마지막이 +9 입니다. −9 로 쓰면 틀려요.
Q5(2x + 5)(2x − 5) 를 전개하세요.
세 번째 공식, a = 2x, b = 5
(2x)2 − 52 = 4x2 − 25
(2x)² 는 2x를 통째로 제곱하므로 4x² 입니다. 2x² 가 아니에요.
Q6(a + b)3 을 전개하세요. (교재 §3 문제 2번)
(a+b)3 = (a+b)2(a+b) 로 쪼갭니다.
= (a2 + 2ab + b2)(a + b)
= (a2+2ab+b2)a + (a2+2ab+b2)b
= a3 + 2a2b + ab2 + a2b + 2ab2 + b3
같은 항끼리 정리하면
a3 + 3a2b + 3ab2 + b3
계수 1-3-3-1을 기억해두세요. 나중에 이항정리에서 다시 만납니다.
Q7어떤 도시의 1905년 인구가 10만이고 25년마다 두 배가 됩니다. 100년 후 인구는? (교재 §3 문제 31번 유형)
1단계 몇 번 배가 되나? 100 ÷ 25 = 4번
2단계 10만 × 24 = 10만 × 16 = 160만
Q897 × 103 을 암산하세요.
(100−3)(100+3) = 1002 − 32
= 10000 − 9 = 9991
