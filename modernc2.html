Chapter 2: C Fundamentals

2.2 The General Form of a Simple Program (간단한 프로그램의 일반적인 형태)

이제 pun.c를 자세히 살펴보고, 이를 조금 일반화해 보겠습니다. 간단한 C 프로그램은 다음과 같은 형태를 가집니다.

directives (지시어)

int main(void)
{
    statements (명령문)
}

이 템플릿(그리고 이 책의 다른 곳에 있는 유사한 템플릿)에서 Courier 글꼴로 인쇄된 항목은 C 프로그램에 표시된 그대로 나타납니다. 이탤릭체로 된 항목은 프로그래머가 제공해야 하는 텍스트를 나타냅니다.

중괄호가 main이 시작하고 끝나는 위치를 보여주는 방식을 주목하세요. C는 다른 언어에서 begin과 end와 같은 단어를 사용하는 것과 거의 같은 방식으로 {와 }를 사용합니다. 이는 C에 대한 일반적인 점을 보여줍니다. C는 약어와 특수 기호에 크게 의존하며, 이는 C 프로그램이 간결하거나(좋게 말하면) 난해한 이유 중 하나입니다.

가장 간단한 C 프로그램조차도 세 가지 핵심 언어 기능에 의존합니다. 지시어(Directives)(컴파일 전에 프로그램을 수정하는 편집 명령), 함수(Functions)(실행 가능한 코드 블록으로, main이 그 예입니다), 그리고 명령문(Statements)(프로그램이 실행될 때 수행되는 명령)입니다. 이제 이러한 기능들을 자세히 살펴보겠습니다.

Directives (지시어)

C 프로그램이 컴파일되기 전에 먼저 전처리기에 의해 편집됩니다. 전처리기를 위한 명령을 지시어(Directives)라고 합니다. 14장과 15장에서 지시어를 자세히 다룹니다. 지금은 #include 지시어에만 관심이 있습니다.

pun.c 프로그램은 다음과 같은 줄로 시작합니다.

#include <stdio.h>

이 지시어는 <stdio.h>의 정보가 컴파일되기 전에 프로그램에 "포함(include)"되어야 함을 나타냅니다. <stdio.h>에는 C의 표준 I/O 라이브러리에 대한 정보가 포함되어 있습니다. C에는 <stdio.h>와 같은 여러 헤더가 있으며, 각각은 표준 라이브러리의 일부에 대한 정보를 포함합니다. <stdio.h>를 포함하는 이유는 C가 일부 프로그래밍 언어와 달리 내장된 "읽기" 및 "쓰기" 명령이 없기 때문입니다. 대신 입출력을 수행하는 기능은 표준 라이브러리의 함수에 의해 제공됩니다.

지시어는 항상 # 문자로 시작하며, 이는 C 프로그램의 다른 항목과 구별됩니다. 기본적으로 지시어는 한 줄 길이이며, 끝에 세미콜론이나 기타 특수 표시가 없습니다.

Functions (함수)

함수는 다른 프로그래밍 언어의 "프로시저(procedure)"나 "서브루틴(subroutine)"과 같습니다. 함수는 프로그램을 구성하는 빌딩 블록입니다. 실제로 C 프로그램은 함수의 집합에 불과합니다. 함수는 프로그래머가 작성한 함수와 C 구현의 일부로 제공되는 함수의 두 가지 범주로 나뉩니다. 후자는 컴파일러와 함께 제공되는 함수 "라이브러리"에 속하므로 라이브러리 함수(library functions)라고 부르겠습니다.

"함수(function)"라는 용어는 수학에서 유래했으며, 수학에서 함수는 하나 이상의 인수(argument)가 주어졌을 때 값을 계산하는 규칙입니다. C는 "함수"라는 용어를 더 느슨하게 사용합니다. C에서 함수는 단순히 함께 그룹화되고 이름이 지정된 일련의 명령문입니다. 일부 함수는 값을 계산하고, 일부는 계산하지 않습니다. 값을 계산하는 함수는 return 문을 사용하여 "반환(return)"할 값을 지정합니다. 예를 들어, 인수에 1을 더하는 함수는 다음과 같은 명령문을 실행할 수 있습니다.

return x + 1;

반면에 인수의 제곱의 차이를 계산하는 함수는 다음과 같은 명령문을 실행할 수 있습니다.

return y * y - z * z;

C 프로그램은 많은 함수로 구성될 수 있지만 main 함수만 필수입니다. main은 특별합니다. 프로그램이 실행될 때 자동으로 호출됩니다. 다른 함수를 작성하는 방법을 배우게 될 9장까지는 main이 프로그램의 유일한 함수가 될 것입니다.

중요: main이라는 이름은 매우 중요합니다. begin이나 start, 심지어 MAIN도 될 수 없습니다.

만약 main이 함수라면, 값을 반환할까요? 네. 프로그램이 종료될 때 운영체제에 제공되는 상태 코드(status code)를 반환합니다. pun.c 프로그램을 다시 살펴보겠습니다.

#include <stdio.h>

int main(void)
{
    printf("To C, or not to C: that is the question.\n");
    return 0;
}

main 바로 앞의 int라는 단어는 main 함수가 정수(integer) 값을 반환함을 나타냅니다. 괄호 안의 void라는 단어는 main에 인수(argument)가 없음을 나타냅니다.

다음 명령문은 두 가지 효과가 있습니다. main 함수를 종료시키고(따라서 프로그램을 종료함), main 함수가 0의 값을 반환함을 나타냅니다. main의 반환 값에 대해서는 나중 장에서 더 자세히 다룰 것입니다. 지금은 항상 main이 0을 반환하도록 할 것입니다. 이는 정상적인 프로그램 종료를 나타냅니다.

main 함수의 끝에 return 문이 없더라도 프로그램은 여전히 종료됩니다. 그러나 많은 컴파일러는 경고 메시지를 생성할 것입니다. (함수가 정수를 반환해야 하는데 반환하지 않았기 때문입니다.)

Statements (명령문)

명령문(Statement)은 프로그램이 실행될 때 실행되는 명령입니다. 명령문은 나중에(주로 5장과 6장에서) 자세히 살펴볼 것입니다. pun.c 프로그램은 두 종류의 명령문만 사용합니다. 하나는 return 문이고, 다른 하나는 함수 호출(function call)입니다. 함수에게 할당된 작업을 수행하도록 요청하는 것을 함수 호출(calling)이라고 합니다. 예를 들어 pun.c 프로그램은 printf 함수를 호출하여 화면에 문자열을 표시합니다.

printf("To C, or not to C: that is the question.\n");

C는 각 명령문이 세미콜론(;)으로 끝나야 합니다. (좋은 규칙에는 항상 예외가 있듯이, 나중에 보게 될 복합문(compound statement)은 예외입니다.) 세미콜론은 컴파일러에게 명령문이 어디서 끝나는지 보여줍니다. 명령문은 여러 줄에 걸쳐 계속될 수 있기 때문에 끝나는 위치가 항상 명확하지는 않습니다. 반면에 지시어는 보통 한 줄 길이이며 세미콜론으로 끝나지 않습니다.

Printing Strings (문자열 출력)

printf는 3장에서 살펴볼 강력한 함수입니다. 지금까지 우리는 printf를 사용하여 큰따옴표로 둘러싸인 일련의 문자인 문자열 리터럴(string literal)을 표시했습니다. printf가 문자열 리터럴을 표시할 때 따옴표는 표시하지 않습니다.

printf는 출력이 끝났을 때 자동으로 다음 출력 줄로 이동하지 않습니다. printf에게 한 줄 앞으로 이동하라고 지시하려면 인쇄할 문자열에 \n(개행 문자(new-line character))을 포함해야 합니다. 개행 문자를 쓰면 현재 출력 줄이 종료되고, 이후 출력은 다음 줄로 이동합니다. 이 점을 설명하기 위해 다음 명령문을 두 개의 printf 호출로 바꾸면 어떤 효과가 있는지 살펴보겠습니다.

printf("To C, or not to C: ");
printf("that is the question.\n");

첫 번째 printf 호출은 To C, or not to C: 를 씁니다. 두 번째 호출은 that is the question.을 쓰고 다음 줄로 이동합니다. 최종 결과는 원래의 printf와 같으며, 사용자는 차이를 느낄 수 없습니다.

개행 문자는 문자열 리터럴에 두 번 이상 나타날 수 있습니다. 다음 메시지를 표시하려면

Brevity is the soul of wit.
-- Shakespeare

다음과 같이 작성할 수 있습니다.

printf("Brevity is the soul of wit.\n-- Shakespeare\n");

▲ C 프로그램의 기본 구조 (Directives → main 함수 → Statements)

📝 Section 2.2 Summary (써머리)

  • C 프로그램의 기본 형태는 지시어(Directives), main 함수, 그리고 명령문(Statements)으로 구성됩니다.
  • 지시어는 #으로 시작하며, 전처리기가 처리합니다. (#include <stdio.h>는 표준 입출력 라이브러리를 포함시킵니다.)
  • main은 프로그램의 시작점이며, int를 반환하고 void 인수를 받습니다. return 0;은 정상 종료를 의미합니다.
  • 명령문은 세미콜론(;)으로 끝나며, printf는 문자열 리터럴을 출력하는 함수입니다.
  • \n은 개행 문자로, 출력 위치를 다음 줄로 이동시킵니다.
