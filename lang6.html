곱셈의 역원

SERGE LANG · BASIC MATHEMATICS · CH.1 §6 · pp.42–51

§6 Multiplicative Inverses

이 절의 한 문장 — 유리수가 정수보다 딱 하나 더 가진 성질, 그 하나에서 나눗셈·십자곱·방정식 풀이가 전부 흘러나온다.
먼저 · 1장의 마지막 절입니다

§6은 회수의 절입니다. 앞에서 미뤄둔 것들이 여기서 갚아집니다.

§5에서 Lang이 십자곱 규칙을 증명 없이 가정하며 이렇게 적었죠 — "§6에서 곱셈의 역원을 다루는데, 거기서 십자곱이 역원의 성질로부터 실제로 증명될 수 있음을 보게 된다." 그 약속을 여기서 지킵니다.

그리고 §5 연습문제 4번("ab = 1 인 b 가 존재함을 보여라")도 여기서 정식 주제가 됩니다.

구조를 미리 말하면 — 성질 하나(a−1의 존재)를 받고, 거기서 다섯 가지를 뽑아냅니다. 나눗셈의 정의, ab=0 정리, 십자곱, 약분법칙, 그리고 분수 계산 전부.

1. 정수가 못 가진 성질 하나THE ONE PROPERTY

Lang이 §6을 여는 첫 문장입니다. 유리수는 정수가 만족하지 못하는 성질 하나를 만족한다.

성질 (역원의 존재)

a 가 0이 아닌 유리수면, 다음을 만족하는 유리수 a−1 이 존재한다.

a−1a = aa−1 = 1

이 a−1 을 a 의 곱셈의 역원(multiplicative inverse)이라 한다.

실제로 a = m/n 이고 m, n 이 둘 다 0이 아닌 정수라면, a−1 = n/m 입니다. 왜냐하면

mn · nm = mnnm = 1

Lang이 든 예입니다.

aa−1확인
1221 = 212·2 = 1
233266 = 1
−45−542020 = 1
내 설명 · 왜 이게 "하나 더"인가

§2에서 덧셈의 역원을 배웠습니다. a + (−a) = 0. 짝을 만나면 0으로 돌아가는 상대죠.

§6은 같은 이야기의 곱셈판입니다. a · a−1 = 1. 짝을 만나면 1로 돌아갑니다.

덧셈에서 "아무것도 안 하는 수"가 0이었듯, 곱셈에서는 1입니다(§3 N6). 그래서 곱셈의 역원은 1로 되돌리는 짝이에요.

그런데 정수 세계에는 이게 없습니다. 3 · ? = 1 을 만족하는 정수가 있나요? 없습니다. 13 은 정수가 아니거든요.

정수에서 역원을 가진 수는 1과 −1뿐입니다. 그래서 유리수로 넓힌 겁니다. §5·§6이 존재하는 이유가 이 한 줄이에요.

⚠ 0만 예외인 이유

성질에 "0이 아닌" 이 붙어 있습니다. 왜일까요?

0 · ? = 1 을 만족하는 수를 찾아야 하는데, §3에서 0a = 0 을 증명했습니다. 0을 곱하면 무조건 0이에요. 절대 1이 될 수 없습니다.

그래서 0의 역원은 존재하지 않고, 그게 곧 0으로 나눌 수 없는 이유입니다. §5에서 n ≠ 0 을 계속 달던 조건이 여기서 정체를 드러냅니다.

아래에서 역원을 직접 뒤집어 보세요.

2. 역원은 유일하다

관찰

a, b 가 유리수이고 ab = 1 이면 b = a−1 이다.

PROOF
a−1ab = a−1 · 1 = a−1
양변에 a−1 을 곱했습니다. ab = 1 의 양쪽에 같은 것을 곱한 거죠.
오른쪽은 a−1 · 1 = a−1 (§3 N6: 1을 곱하면 그대로).
a−1ab = 1b = b
왼쪽을 결합법칙으로 다시 묶었습니다. (a−1a)b 로 보면 괄호 안이 1이므로 1b = b.
∴ b = a−1
같은 것을 두 가지로 계산했더니 a−1 과 b 가 나왔습니다. 따라서 둘은 같습니다.
증명 끝.

§2와 비교해 보세요. N3이 "a + b = 0 이면 b = −a"였죠. 완전히 같은 모양입니다. 0이 1로, 덧셈이 곱셈으로 바뀌었을 뿐이에요.

3. ab = 0 이면 둘 중 하나는 0 ★

정리

ab = 0 이면 a = 0 이거나 b = 0 이다.

PROOF
a ≠ 0 이라고 하자
경우를 나눕니다. a = 0 이면 결론이 이미 참이니 볼 것이 없어요. 그러니 a ≠ 0 인 경우에 b = 0 임을 보이면 됩니다.
그리고 a ≠ 0 이므로 a−1 이 존재합니다. 이게 이 증명의 유일한 재료예요.
a−1ab = 0a−1 = 0
양변에 a−1 을 곱했습니다. 오른쪽은 0 · a−1 = 0 (§3에서 증명한 0a = 0).
a−1ab = 1b = b
왼쪽을 결합법칙으로 묶으면 (a−1a)b = 1b = b.
∴ b = 0
왼쪽 계산은 b, 오른쪽 계산은 0. 따라서 b = 0.
증명 끝.
★ 이 정리가 나중에 무엇이 되는가

지금은 당연해 보이지만, 이게 4장 이차방정식 전체를 떠받치는 기둥입니다.

x2 + x − 6 = 0 을 풀 때 우리는 이렇게 하죠.

(x − 2)(x + 3) = 0

그리고 "따라서 x = 2 또는 x = −3" 이라고 씁니다. 왜 그렇게 말할 수 있죠?

바로 이 정리 때문입니다. 두 수의 곱이 0이면 둘 중 하나가 0이어야 하니까요. 인수분해로 방정식을 푸는 방법 전체가 이 한 줄 위에 서 있습니다.

그리고 이 정리는 역원이 있는 세계에서만 성립합니다. 역원이 없는 수 체계에서는 ab = 0 인데 둘 다 0이 아닌 일이 실제로 벌어집니다. 시계 산술(§4의 mod)에서 4 × 3 = 12 ≡ 0 (mod 12) 인데 4도 3도 0이 아니죠.

4. 나눗셈은 새 연산이 아니다NOTATION FOR QUOTIENTS

Lang은 정수의 몫에서 쓰던 표기를 유리수의 몫에도 그대로 쓰겠다고 선언합니다.

표기 약속
ab  또는  a/b  는  b−1a  또는  ab−1 의 줄임말
내 설명 · §2와 정확히 같은 구조

§2에서 이런 약속을 했었죠. a − b 는 a + (−b) 의 줄임말이다. 그래서 뺄셈이라는 별도의 연산은 없다고요.

§6은 그 곱셈판입니다. a / b 는 a · b−1 의 줄임말입니다. 그러니 나눗셈이라는 별도의 연산도 없습니다.

덧셈 세계 (§2)곱셈 세계 (§6)
아무 일 안 하는 수01
역원−aa−1
역원 성질a + (−a) = 0a · a−1 = 1
줄임 표기a − ba / b
예외없음0은 역원 없음

거의 완벽한 대칭인데 마지막 줄만 다릅니다. 덧셈에서는 모든 수가 역원을 갖지만, 곱셈에서는 0만 빠져요. 그 한 칸의 차이가 "0으로 나누지 마라"라는 평생 듣는 규칙의 정체입니다.

Lang의 예입니다. a = 34, b = 57 일 때:

3/45/7 = 34(57)−1 = 34 · 75 = 2120

"분수의 나눗셈은 뒤집어서 곱한다"는 초등학교 규칙의 정체가 이겁니다. 뒤집는 건 역원을 취하는 것이고, 나눗셈은 역원을 곱하는 것이니까요. 규칙이 아니라 정의의 결과였습니다.

5. 십자곱 — 약속을 지키다 ★CROSS-MULTIPLICATION, PROVED

§5에서 증명 없이 가정했던 십자곱 규칙을, 이제 덧셈·곱셈·역원의 기본 성질만으로 증명합니다.

CROSS-MULTIPLICATION

a, b, c, d 를 유리수라 하고 b ≠ 0, d ≠ 0 이라 하자.

① ab = cd  이면  ad = bc

② ad = bc  이면  ab = cd

PROOF · ① 정방향
b−1a = d−1c
가정을 표기 약속대로 풀어 쓴 것뿐입니다. ab 는 정의상 b−1a 이고, cd 는 d−1c 입니다.
분수 기호를 벗겨내는 게 첫걸음이에요. 그래야 곱셈 규칙을 쓸 수 있습니다.
dbb−1a = bdd−1c
양변에 db 를 곱했습니다(bd 와 같습니다 — 교환법칙).
왜 하필 db 인가? 왼쪽의 b−1 과 오른쪽의 d−1 을 동시에 없애기 위해서입니다. 각각의 짝을 한꺼번에 데려온 거예요.
da = bc
왼쪽: bb−1a = 1a = a 이므로 da 만 남습니다.
오른쪽: dd−1c = 1c = c 이므로 bc 만 남습니다.
da = ad (교환법칙)이므로 ad = bc. ① 증명 끝.
PROOF · ② 역방향
add−1b−1 = d−1b−1bc
가정 ad = bc 의 양변에 b−1d−1 을 곱했습니다(d−1b−1 과 같습니다).
이번엔 거꾸로입니다. 아까는 역원을 없애려고 db 를 곱했고, 지금은 역원을 만들려고 곱합니다.
ab−1 = d−1c
왼쪽: dd−1 = 1 이므로 ab−1 만 남습니다.
오른쪽: b−1b = 1 이므로 d−1c 만 남습니다.
∴ a/b = c/d
표기 약속을 다시 씌우면 그대로 ab = cd 입니다.
② 증명 끝. ①과 ②를 합치면 "필요충분"이 됩니다.
내 설명 · 증명의 리듬

두 방향 증명이 거울처럼 대칭입니다.

① 분수 → 정수식: 역원을 없애려고 db 를 곱한다
② 정수식 → 분수: 역원을 만들려고 b−1d−1 을 곱한다

§2·§4에서 봤던 "없애고 싶은 놈의 역원을 양변에 곱한다"가 여기서도 그대로입니다. 덧셈판에서는 마이너스를 더했고, 곱셈판에서는 역원을 곱합니다.

그리고 §5의 약속이 지켜졌습니다. 십자곱은 이제 가정이 아니라 정리입니다. 빚 하나를 갚은 셈이에요.

Lang의 예제 두 개입니다.

EXAMPLE · 3/(x−1) = 2
3 = 2(x − 1) = 2x − 2
십자곱입니다. 3x−1 = 21 로 보면 3 · 1 = 2(x−1).
그다음 분배법칙(§3)으로 괄호를 풀었습니다.
3 + 2 = 2x  →  x = 5/2
양변에 2를 더하고, 양변을 2로 나눴습니다.
5 = 2x 이므로 x = 52. 끝.
EXAMPLE · (4+x)/(x/2) = 5
4 + x = 5 · (x/2) = 5x/2
십자곱 1차. 분모 x2 를 오른쪽으로 넘긴 겁니다.
분모 자체가 분수인 경우인데, 십자곱은 유리수에서도 성립하므로(방금 증명) 그대로 씁니다.
2(4 + x) = 5x
십자곱 2차. 아직 남아 있는 분모 2를 털어냅니다. 4+x1 = 5x2 이므로 2(4+x) = 5x.
8 + 2x = 5x  →  x = 8/3
분배법칙으로 풀고, 양변에서 2x 를 뺐습니다. 8 = 3x 이므로 x = 83. 끝.

6. 두 개의 약분 법칙CANCELLATION LAWS

곱셈의 약분 법칙

a 를 0이 아닌 유리수라 하자. ab = ac 이면 b = c 이다.

증명은 한 줄입니다. 양변에 a−1 을 곱하면 a−1ab = a−1ac, 즉 b = c.

⚠ "0이 아닌"을 빼면 무너집니다

a = 0 이면? 0 · 5 = 0 · 7 은 참(양쪽 다 0)이지만 5 = 7 은 거짓입니다.

약분이 되는 이유는 역원이 있기 때문이고, 0은 역원이 없으니 약분할 수 없습니다. 조건을 빼먹으면 아무거나 증명해버릴 수 있어요.

몫의 약분 법칙

a, b, c, d 가 유리수이고 a ≠ 0, c ≠ 0 이면

abac = bc

Lang은 이걸 십자곱으로 확인합니다. (ab)c = b(ac) 즉 abc = bac 인데, 이는 교환법칙과 결합법칙에 의해 참입니다.

그리고 이렇게 정리합니다 — 유리수로 만든 분수도 정수로 만든 분수와 거의 똑같이 다룰 수 있다.

7. 분수 계산 규칙을 다시 유도하기

§5에서 정수의 몫에 대해 세웠던 공식들을, 이제 유리수의 몫에 대해 다시 얻습니다.

통분 — a/b 와 c/d 가 유리수의 몫이면(b ≠ 0, d ≠ 0):

ab = adbd     cd = bcbd

분모가 같을 때의 덧셈 — x, y, b 가 유리수이고 b ≠ 0 이면:

유도 · x/b + y/b
= b−1x + b−1y
표기 약속을 풀어 썼습니다. 분수 기호를 벗기면 역원의 곱입니다.
= b−1(x + y)
분배법칙입니다(§3). Lang이 직접 "by distributivity"라고 적어둔 자리예요.
공통 인수 b−1 로 묶었습니다.
= (x + y)/b
표기 약속을 다시 씌웠습니다(Lang: "by definition").
유도 끝. 분모가 같으면 분자끼리 더하면 된다는 규칙이, 분배법칙 한 줄에서 나왔습니다.

이 둘을 합치면 일반 덧셈 공식이 나옵니다.

일반 덧셈
ab + cd = ad + bcbd

Lang의 말 — 이 공식은 두 유리수의 합을 나타내는 공식과 완전히 유사하다.

Lang의 예제

다음을 보이시오.

1x − y + 1x + y = 2xx2 − y2
PROOF
= [1(x+y) + 1(x−y)] / [(x−y)(x+y)]
방금 유도한 일반 덧셈 공식을 그대로 적용했습니다. a = 1, b = x−y, c = 1, d = x+y.
분자 = x + y + x − y = 2x
+y 와 −y 가 서로 잡아먹습니다(§2 N2). 남는 건 x + x = 2x.
분모 = x2 − y2
§3의 세 번째 암기 공식입니다. (a+b)(a−b) = a2 − b2.
"반드시 외우라"던 그 공식이 여기서 쓰입니다.
따라서 2xx2−y2. 증명 끝.

Lang의 Remark — 위 예제에서 1/(x−y) 와 1/(x+y) 는 x − y = 0 이거나 x + y = 0 이면 말이 되지 않습니다. 그런 경우 x, y 가 x − y ≠ 0 이고 x + y ≠ 0 을 만족한다고 암묵적으로 가정합니다. 앞으로 혼동의 여지가 없으면 이런 조건을 명시하지 않고 넘어가기도 하겠다고 적어둡니다.

EXAMPLE · (3x+1)/(2x−5) = 4
3x + 1 = 4(2x − 5) = 8x − 20
십자곱. 단 조건이 붙습니다 — 2x − 5 ≠ 0, 즉 x ≠ 5/2 인 경우에만 유효합니다.
Lang이 이 조건을 명시적으로 적어둡니다. 분모가 0이 되는 값은 애초에 후보에서 빠져야 하니까요.
8x − 3x = 1 − (−20) = 21
x 항은 오른쪽으로, 상수는 왼쪽으로 모았습니다.
1 − (−20) = 1 + 20 = 21 — §2 N4(마이너스 두 번은 플러스)입니다.
5x = 21  →  x = 21/5
8x − 3x = 5x. 양변을 5로 나누면 끝.
검산: 21/5 ≠ 5/2 이므로 조건을 만족합니다. 유효한 해예요.

8. 물리 세계의 예d = st

Lang이 실제 세계의 예를 하나 가져옵니다. 물체가 직선 위를 일정한 속력으로 움직인다고 하자.

공식

s = 속력, d = 이동 거리, t = 걸린 시간

d = st

물론 수를 붙이려면 시간과 거리의 단위를 먼저 정해야 합니다. Lang의 예 — 거리가 5마일, 시간이 12 시간이면:

s = dt = 51/2 = 2 · 5 = 10 mi/hr
내 설명 · 여기서 역원이 쓰였습니다

51/2 을 계산할 때 무슨 일이 벌어졌나요?

정의에 따라 5 · (12)−1 = 5 · 2 = 10. 분모를 뒤집어 곱한 겁니다.

"30분에 5마일이면 시속 10마일"은 직관적으로도 맞죠. 그 직관의 근거가 역원이었던 겁니다.

Lang의 예제 · 여행

8시간 동안 400마일을 운전했다. 고속도로에서는 평균 시속 60마일, 시내에서는 시속 30마일이었다. 시내를 몇 시간 운전했는가?

  1. x = 시내 운전 시간이라 두면, 고속도로 시간은 8 − x
  2. 시내 이동 거리 = 30x, 고속도로 이동 거리 = 60(8 − x)
  3. 총 거리가 400이므로   30x + 60(8 − x) = 400
  4. 분배법칙   30x + 480 − 60x = 400
  5. 정리하면   80 = 30x
  6. x = 8030 = 83 시간

아래에서 x 를 움직이며 총 거리가 400에 맞는 지점을 찾아보세요.

9. 혼합 문제 ★MIXTURE PROBLEMS

Lang의 예제 · 부동액

자동차 라디에이터에 액체 8쿼트가 들어 있고, 40%가 부동액(나머지는 물)이다. 결과 혼합물이 90% 부동액이 되려면 얼마를 빼내고 부동액으로 채워야 하는가?

  1. x = 빼낼 쿼트 수
  2. 빼내고 나면 8 − x 쿼트가 남고, 그중 40%가 부동액 → 남은 부동액은 40100(8 − x) 쿼트
  3. 여기에 부동액 x 쿼트를 넣으므로, 최종 부동액은 40100(8 − x) + x
  4. 이것이 전체 8쿼트의 90%여야 한다 → 40100(8 − x) + x = 90100 · 8
  5. 정리하면   60100x = 50100 · 8
  6. x = 40060 = 203

Lang은 이것도 정답이라고 하면서, 굳이 기약 형태로 말하자면 623 쿼트를 부동액으로 교체해야 한다고 덧붙입니다.

내 설명 · 혼합 문제의 만능 골격

연습문제 11, 14, 15, 17, 18번이 전부 이 유형입니다. 골격 하나만 외우면 다 풀려요.

핵심 원리 — 순수한 것의 양을 추적하라. 퍼센트를 직접 다루려 하면 반드시 꼬입니다. 실제 양(그램, 쿼트)으로 바꿔서 방정식을 세우세요.

단계할 일
①x 를 정한다 (빼낸 양 / 넣은 양)
②처음 순수량 = 총량 × 처음 농도
③변화 후 순수량 = ② ± 빼거나 더한 순수량
④나중 총량 = 처음 총량 ± 변화량
⑤③ = ④ × 목표 농도  →  풀기

가장 흔한 실수 — 물만 더할 때는 순수량이 안 변한다는 걸 놓치는 겁니다. 소금물에 물을 부으면 소금의 양은 그대로고 전체 무게만 늘어요. 그럼 ③은 그냥 ②와 같습니다.

Lang의 부동액 문제가 유독 까다로운 이유는 빼기와 더하기가 동시에 일어나기 때문입니다. 대부분의 연습문제는 이보다 쉬워요.

2번 bx3 − 1x − 1 = 1 + x + x2 임을 증명하세요.
십자곱으로 갑니다. 보일 것은
x3 − 1 = (x − 1)(1 + x + x2)

오른쪽을 분배법칙으로 전개하면

오른쪽을 전개합니다. x 를 곱한 것과 −1 을 곱한 것을 나란히 쓰면

xn + xn−1 + ⋯ + x2 + x
      − xn−1 − ⋯ − x2 − x − 1

가운데가 전부 상쇄됩니다. 위줄의 xn−1 과 아래줄의 −xn−1, 위줄의 xn−2 와 아래줄의 −xn−2… 이런 식으로요.

양 끝만 남습니다: xn − 1 ∎

알코올 양 = 0.35 × 12 = 4.2 cm³ (고정)

a) x 를 넣을 물의 양이라 하면 총량은 12 + x
4.212 + x = 0.2
십자곱: 4.2 = 0.2(12 + x) = 2.4 + 0.2x
1.8 = 0.2x → x = 9 cm³

b) 4.212 + x = 0.1 → 4.2 = 1.2 + 0.1x
x = 30 cm³
