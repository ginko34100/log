정수와 덧셈의 규칙

SERGE LANG · BASIC MATHEMATICS · CH.1 §1–§2 · pp.5–13

§1 정수 The Integers

이 절의 한 문장 — 수를 개수가 아니라 직선 위의 위치로 보기 시작하자.

1. 세는 데 쓰는 수POSITIVE INTEGERS

가장 흔한 수는 물건을 셀 때 쓰는 수입니다.

1, 2, 3, 4, …

이걸 양의 정수(positive integers)라고 부릅니다. 여기까지는 아무 문제 없죠.

2. 그런데 0이 필요하다ZERO

Lang이 곧바로 지적합니다. 세기만 하는 데도 수가 하나 더 필요하다고요. 바로 0입니다.

왜냐? 100문제짜리 시험을 생각해 보세요.

  1. 100점을 받았다 → 전부 맞혔다는 뜻
  2. 0점을 받았다 → 맞힌 게 하나도 없다는 뜻

"하나도 없음"도 셈의 결과입니다. 그러니 0이 없으면 셈이 완결되지 않아요.

3. 직선 위에 올리기THE NUMBER LINE

이제 이 수들을 자(ruler)를 만들듯이 직선 위에 올립니다. 순서가 중요합니다.

  1. 직선을 하나 긋는다
  2. 단위 길이를 하나 정한다. 예를 들어 1인치. 이게 "한 칸"의 길이가 됩니다
  3. 기준점 하나를 찍고 거기를 0이라 한다
  4. 오른쪽으로 한 칸 가서 1, 또 한 칸 가서 2, … 계속 찍는다

2단계를 그냥 지나치지 마세요. 단위를 정하기 전까지 수직선은 존재할 수 없습니다. 1이 1cm인지 1km인지 정해야 2가 어디인지 정해지니까요.

정의

자연수(natural numbers) = 양의 정수 + 0

그래서 0도 자연수, 2도 자연수, 124,521도 자연수입니다.

원점(origin) = 0이 찍힌 그 점

⚠ 함정 — 책마다 다릅니다

Lang은 0을 자연수에 포함시킵니다. 한국 교과서를 비롯한 많은 책은 자연수를 1부터 시작해요. 어느 쪽이 맞고 틀린 게 아니라 정의를 어떻게 잡느냐의 문제입니다. 이 책을 읽는 동안은 Lang의 정의를 따르세요.

4. 0의 왼쪽NEGATIVE INTEGERS

자에는 0 왼쪽이 없습니다. 하지만 온도계에는 있죠. 영하로 내려가니까요.

그래서 0 반대편에도 똑같은 간격으로 눈금을 찍고 −1, −2, −3, … 이라고 이름 붙입니다. 이게 음의 정수(negative integers)입니다.

정의

정수(integers) = 양의 정수 + 음의 정수 + 0

그래서 −9, 0, 10, −5 는 전부 정수입니다.

5. 같은 정수, 다른 쓰임APPLICATIONS

Lang이 여기서 중요한 구분을 합니다. 정수 자체는 추상적인 대상이고, 그걸 무엇에 쓰느냐는 별개라는 겁니다.

무엇을 재나원점 0은음수는
거리출발점반대 방향
온도0도영하
시간예수 탄생년기원전

세 번째가 재밌습니다. 이 약속대로면 −500 이라는 수는 기원전 500년이 됩니다. 같은 −500이 거리로 읽으면 "왼쪽 500칸", 온도로 읽으면 "영하 500도", 시간으로 읽으면 "기원전 500년"인 거죠.

6. 덧셈은 걷기다 ★ADDITION AS MOVEMENT

이 절에서 가장 중요한 한 줄입니다.

핵심

양수를 더한다 = 그만큼 오른쪽으로 걷는다

음수를 더한다 = 그만큼 왼쪽으로 걷는다

예를 들어 5 + 7 = 12. 5에 서 있다가 오른쪽으로 7칸 걸으면 12에 도착합니다. 온도계로 세워 놓으면 오른쪽 대신 위로가 되고요 — 5도에서 7도 올라가면 12도.

아래에서 직접 걸려 보세요.

두 번째 것을 보면 3 + (−5) = −2 입니다. 3에서 왼쪽으로 5칸 걸으면 0을 지나쳐서 −2까지 갑니다. 0은 벽이 아니라 그냥 지나가는 눈금일 뿐이에요.

7. 첫 번째 규칙 N1ADDING ZERO

N1
0 + a = a + 0 = a

모든 정수 a 에 대하여

걷기로 보면 한 문장입니다. 0을 더한다 = 0칸 걷는다 = 제자리. 안 움직였으니 당연히 원래 자리에 있죠.

8. 두 번째 규칙 N2

N2
a + (−a) = 0
−a + a = 0

이건 외우지 마세요. 그림 한 장이면 끝납니다.

  1. 3은 0에서 오른쪽으로 3칸 떨어진 지점
  2. −3은 0에서 왼쪽으로 3칸 떨어진 지점
  3. 즉 둘은 0을 사이에 두고 같은 거리, 반대편에 있습니다
  4. 그러니 3에서 왼쪽으로 3칸 걸으면 0에 안 떨어질 수가 없습니다

두 번째 것은 반대 방향에서 출발해도 마찬가지라는 걸 보여줍니다. −5 + 5 = 0.

이 성질 때문에 −a 를 a 의 덧셈 역원(additive inverse)이라고 부릅니다. "역원"은 서로를 0으로 되돌리는 짝이라는 뜻이에요.

9. Lang의 잔소리 — 이게 진짜 중요합니다

⚠ −a 는 음수가 아니다

−a 를 "negative a(음수 a)"라고 부르지 말고 "minus a(마이너스 a)" 라고 부르라고 Lang이 못박습니다.

왜냐면 −a 가 항상 음수인 게 아니거든요.

  1. a = 3 이면 −a = −3 → 음수 ✓
  2. 그런데 a = −3 이면? −a = −(−3) = 3 → 양수입니다

− 기호는 "이건 음수다"라는 표시가 아닙니다. "0 건너 반대편으로 가라"는 명령이에요.

이미 왼쪽에 있던 놈한테 "반대편으로 가"라고 하면 오른쪽으로 갑니다. 그래서 마이너스가 붙었는데 양수가 되는 겁니다.

3장 부등식에서 이걸 헷갈리면 반드시 틀립니다. 지금 확실히 잡고 가세요.

10. 확인 문제

Q1a = −7 일 때 −a 는?
−a = −(−7) = 7
−7은 0의 왼쪽 7칸입니다. 반대편으로 가라고 했으니 오른쪽 7칸, 즉 7. 양수입니다.
Q20은 자연수인가? Lang의 정의로 답하세요.
예, 자연수입니다. Lang은 자연수를 "양의 정수 + 0"으로 정의했습니다. 다른 책에서는 아닐 수 있다는 점만 기억하세요.
Q3온도가 4° 인데 9° 떨어졌습니다. 식으로 쓰고 답하세요.
4 + (−9) = −5
4에서 왼쪽(아래)으로 9칸. 0을 지나 5칸 더 가므로 영하 5도.

§2 덧셈의 규칙 Rules for Addition

이 절의 한 문장 — 규칙 두 개를 공짜로 받고, 그것만으로 나머지를 증명해낸다.

1. 교환법칙COMMUTATIVITY

교환법칙
a + b = b + a

더하는 순서를 바꿔도 결과는 같다

걷기로 확인해 봅시다. 3 + 5 와 5 + 3 은 중간에 멈춘 지점만 다릅니다.

첫 번째는 3에서 한 번 섰고, 두 번째는 5에서 한 번 섰어요. 하지만 총 걸은 칸 수는 둘 다 8칸입니다. 출발점이 같고 총 이동량이 같으면 도착점도 같을 수밖에 없죠.

음수가 섞여도 똑같습니다. −2 + 5 = 3 = 5 + (−2)

계단으로 보면 확실합니다. 지금 1층(0)에 서 있다고 하고요.

−2 + 55 + (−2)
1단계2칸 내려감
→ 지하 2층		5칸 올라감
→ 5층
2단계5칸 올라감
→ 3층		2칸 내려감
→ 3층
결과3층3층

내려갔다 올라가나, 올라갔다 내려가나 최종 높이는 같습니다. 순서는 과정일 뿐 결과를 바꾸지 못해요.

2. 결합법칙ASSOCIATIVITY

결합법칙
(a + b) + c = a + (b + c)

어느 둘을 먼저 묶어 계산해도 결과는 같다

괄호는 "이걸 먼저 계산해라" 는 표시입니다. 숫자로 확인해 볼게요.

(3 + 5) + 93 + (5 + 9)
① 3 + 5 = 8
② 8 + 9 = 17		 ① 5 + 9 = 14
② 3 + 14 = 17
둘 다 17

걷기로 보면 하는 일은 결국 하나입니다.

0 ─3칸→ 3 ─5칸→ 8 ─9칸→ 17

괄호가 바꾸는 건 "어디서 중간 합계를 냈느냐" 뿐이에요.

  1. (3+5)+9 → 앞 두 걸음을 먼저 묶어 "8칸"으로 만들고, 그 다음 9칸
  2. 3+(5+9) → 뒤 두 걸음을 먼저 묶어 "14칸"으로 만들고, 앞에 3칸

묶는 방법이 다를 뿐 걷는 총 길이는 17칸으로 같습니다.

3. 그래서 괄호를 뗄 수 있다 ★

결합법칙 덕분에 이렇게 써도 됩니다.

a + b + c

사소해 보이지만 이게 결합법칙의 진짜 존재 이유입니다. 잘 생각해 보세요.

  1. 덧셈은 원래 숫자 두 개에 대해서만 정의된 연산입니다. a + b, 이게 전부예요
  2. 그럼 a + b + c 는 무슨 뜻일까요? 정의된 적이 없는 표기입니다
  3. 읽는 방법이 두 가지입니다 — (a+b)+c 또는 a+(b+c)
  4. 결합법칙이 "둘 중 뭘로 읽어도 같다" 를 보장해주기 때문에, 비로소 괄호를 떼고 써도 안전해집니다

4. 여기서 책의 성격이 바뀝니다

읽는 방식을 바꿔야 하는 지점

Lang이 못박습니다 — 이 두 규칙은 증명하지 않는다. 대신 이것들로부터 다른 규칙들을 증명하겠다.

교환법칙과 결합법칙은 출발점(가정) 입니다. "이건 참이라고 받아들이고 시작하자"는 거예요.

지금까지 "온도계 보세요, 그림 보세요" 하던 책이 여기서부터 주어진 규칙에서 논리로 새 규칙을 뽑아내는 모드로 넘어갑니다. 이제 나올 N3·N4·N5가 이 책의 첫 증명들입니다.

5. N3 — 0을 만드는 짝은 하나뿐THE FIRST PROOF

N3
a + b = 0 이면   b = −a  이고  a = −b

말로 풀면: 어떤 수에 더해서 0이 되게 만드는 상대는 오직 하나, 그 수의 마이너스뿐이라는 뜻입니다.

증명을 한 줄씩 봅시다. 각 줄의 "왜?"를 먼저 스스로 답해보고 눌러보세요.

PROOF · N3
a + b = 0
출발점입니다. 이건 증명할 대상이 아니라 주어진 조건이에요. "만약 a + b = 0 이라면" 하고 가정하고 들어가는 겁니다.
−a + (a + b) = −a + 0
양변에 −a 를 더했습니다. 등식은 저울입니다. 왼쪽에 무언가를 얹으면 오른쪽에도 똑같이 얹어야 균형이 유지돼요. 여기서 하필 −a 를 고른 이유는, a 를 없애버리기 위해서입니다.
(−a + a) + b = −a
왼쪽은 결합법칙으로 묶는 방식을 바꿨습니다. −a + (a + b) 를 (−a + a) + b 로요.
오른쪽은 N1입니다. −a + 0 = −a. 0을 더해봤자 제자리니까요.
0 + b = −a
N2입니다. −a + a = 0. 노렸던 게 이거예요 — a 가 사라졌습니다.
b = −a
또 N1. 0 + b = b.
증명 끝. 같은 방식으로 양변에 −b 를 더하면 a = −b 도 나옵니다.

증명의 전략을 기억하세요. "없애고 싶은 놈의 마이너스를 양변에 더한다." 이 한 수가 앞으로 계속 나옵니다.

6. 뺄셈은 새 연산이 아니다a − b 라는 약속

표기 약속
a − b  는  a + (−b)  의 줄임말

이건 규칙이 아니라 약속입니다. 증명할 것도 없어요. 그냥 쓰기 귀찮으니 짧게 쓰자는 겁니다.

하지만 결과가 큽니다. 뺄셈이라는 별도의 연산은 존재하지 않습니다. 전부 덧셈이에요. "빼기"는 그냥 음수를 더하는 것이고, 걷기로는 왼쪽으로 가는 것입니다.

덕분에 교환법칙·결합법칙이 뺄셈에도 그대로 적용됩니다. 실제로 a − b + c 같은 식은 순서를 마음대로 바꿔 쓸 수 있어요.

a − b + c  =  a + c − b

왜냐면 a + (−b) + c 에서 −b 와 c 의 순서를 교환법칙으로 바꾼 것뿐이니까요.

7. N4 — 마이너스를 두 번 붙이면

N4
a = −(−a)

이건 N3의 특수한 경우로 바로 나옵니다.

  1. N2에서 a + (−a) = 0 을 알고 있습니다
  2. N3은 "x + y = 0 이면 x = −y" 라고 했습니다
  3. 여기에 x = a, y = −a 를 넣으면 → a = −(−a)

걷기로 보면 당연합니다. "반대편으로 가라"를 두 번 하면 제자리예요.

Lang은 마이너스를 계속 쌓아도 된다고 덧붙입니다.

3 = −(−3) = −(−(−(−3)))
−3 = −(−(−3))

규칙은 간단합니다. 마이너스 개수를 세세요. 짝수 개면 원래 값 a, 홀수 개면 −a. 반대편으로 갔다가 또 반대편으로 가면 제자리니까요.

8. N5 — 괄호 앞의 마이너스 ★

N5
−(a + b) = −a − b

실수가 가장 많이 나오는 지점입니다. 괄호 앞의 마이너스는 안에 있는 모든 항에 들어갑니다.

증명 전략을 먼저 이해해야 합니다. N3 덕분에 "x가 y의 마이너스다"를 보이려면 x + y = 0 임을 보이면 충분합니다. 그러니 이걸 보이면 돼요.

(a + b) + (−a − b) = 0
PROOF · N5
(a + b) + (−a − b)
보이려는 식의 왼쪽입니다. 이게 0이 되는지 계산해 나갑니다.
= a + b − a − b
결합법칙. 어차피 묶는 방식이 결과를 안 바꾸므로 괄호를 다 떼어버립니다.
= a − a + b − b
교환법칙. 순서를 바꿔 서로 없앨 짝끼리 모았습니다. b 와 −a 의 자리를 맞바꾼 거예요.
= 0 + 0
N2를 두 번. a − a = 0 이고 b − b = 0.
= 0
N1. 0에 0을 더해도 0.
증명 끝. 합이 0이 나왔으니 N3에 의해 −(a+b) = −a − b 입니다.

계산 예제를 보면서 음수가 안에 있을 때를 특히 조심하세요.

식풀어쓰면답
−(3 + 5)−3 − 5−8
−(−4 + 5)−(−4) − 5 = 4 − 5−1
−(3 − 7)−3 − (−7) = −3 + 74
⚠ 가장 흔한 실수

두 번째 줄에서 −(−4 + 5) 를 −4 − 5 = −9 라고 쓰는 실수입니다. 안에 있던 −4 에도 마이너스가 걸려서 +4 가 돼야 합니다. N4를 여기서 써야 해요.

9. 부호에 관한 두 사실

Lang이 "너무 당연해서 말할 필요도 없어 보이지만 그래도 명시하겠다"며 하나를 얹습니다.

가정 (증명 안 함)

a, b 가 양의 정수면 a + b 도 양의 정수다

예: 17과 45는 양수, 합인 62도 양수. 이건 증명 없이 받아들이는 가정입니다.

그런데 여기서 음수 쪽은 증명해냅니다.

PROOF · 음수 + 음수 = 음수
a = −n,  b = −m
표현을 바꾼 것뿐입니다. a 가 음수라면, 어떤 양수 n 에 마이너스를 붙인 꼴로 반드시 쓸 수 있습니다. 예: a = −7 이면 n = 7. 이렇게 두면 양수만 다루면 되니 위 가정을 쓸 수 있게 됩니다.
a + b = −n − m
그냥 대입했습니다.
= −(n + m)
N5를 거꾸로 쓴 것입니다. −(n+m) = −n − m 이었으니, 반대 방향으로 읽으면 이렇게 묶입니다.
∴ a + b 는 음수
위 가정에 의해 n 과 m 이 양수면 n + m 도 양수입니다. 그 양수 앞에 마이너스가 붙었으니 전체는 음수입니다.
증명 끝.

10. 방정식을 푸는 원리SOLVING FOR x

이제 실전입니다. a + b = c 라는 관계가 있으면 여기서 다른 관계들을 끌어낼 수 있습니다.

  1. a + b = c — 주어진 관계
  2. 양변에 −b 를 더한다 → a + b − b = c − b
  3. 왼쪽에서 b − b = 0 (N2) → a + 0 = c − b
  4. N1에 의해 → a = c − b

같은 방식으로 b = c − a 도 나옵니다. "이항"이라고 배웠던 게 사실은 이 과정이에요. 이항은 마법이 아니라 양변에 같은 수를 더한 결과입니다.

구체적인 예를 보죠.

예1x + 3 = 5
양변에 −3 을 더합니다.
x + 3 − 3 = 5 − 3
x + 0 = 2
x = 2
예24 − a = 3  — 미지수 앞에 마이너스가 있는 경우
이럴 땐 양변에 a 를 더해 마이너스부터 없앱니다.
4 − a + a = 3 + a
4 = 3 + a
이제 양변에서 3을 뺍니다.
1 = a  →  a = 1
미지수가 오른쪽으로 가도 상관없습니다. 등식은 좌우 대칭이니까요.
예3−2 − y = 5
양변에 y 를 더합니다.
−2 = 5 + y
양변에서 5를 뺍니다.
−7 = y  →  y = −7

11. 연습 문제

교재 §2 연습문제(13쪽)와 같은 유형입니다. 먼저 직접 풀어보세요.

Q1−(2 + 6) 을 계산하세요.
N5에 의해 −2 − 6 = −8
Q2−(−5 + 2) 를 계산하세요.
−(−5) − 2 = 5 − 2 = 3
안에 있던 −5 에도 마이너스가 걸린다는 걸 놓치지 마세요.
Q3−(4 − 9) 를 계산하세요.
−4 − (−9) = −4 + 9 = 5
검산: 괄호 안을 먼저 계산해도 −(−5) = 5 로 같습니다.
Q4−(a − b) = b − a 임을 보이세요.
a − b 는 a + (−b) 이므로, N5를 적용하면
−(a + (−b)) = −a + (−(−b))
N4에 의해 −(−b) = b 이므로
= −a + b
교환법칙으로 = b − a ∎
Q5−3 + x = 4 에서 x 를 구하세요.
양변에 3을 더합니다.
−3 + 3 + x = 4 + 3
x = 7
Q62 − x = 5 에서 x 를 구하세요.
양변에 x 를 더해 마이너스를 없앱니다.
2 = 5 + x
양변에서 5를 뺍니다.
−3 = x → x = −3
Q7(a + b) + (c + d) = (a + c) + (b + d) 가 성립하는 이유를 설명하세요.
결합법칙으로 괄호를 전부 떼면 양쪽 다 a + b + c + d 가 됩니다.
그 다음 교환법칙으로 b 와 c 의 순서를 바꾸면 오른쪽 형태가 나옵니다.
핵심: 결합법칙은 묶음을 자유롭게, 교환법칙은 순서를 자유롭게 해줍니다. 둘을 합치면 덧셈만 있는 식은 어떻게 재배열해도 됩니다.
