2.3 Comments (주석)

우리의 pun.c 프로그램에는 여전히 중요한 무언가가 빠져 있습니다: 바로 문서화(documentation)입니다. 모든 프로그램은 프로그램 이름, 작성 날짜, 작성자, 프로그램 목적 등의 식별 정보를 포함해야 합니다. C에서는 이 정보가 주석(comments)에 들어갑니다. 기호 /*는 주석의 시작을, 기호 */는 주석의 끝을 나타냅니다.

/* This is a comment */

주석은 프로그램의 거의 모든 곳에, 별도의 줄에 나타날 수도 있고 다른 프로그램 텍스트와 같은 줄에 나타날 수도 있습니다. 다음은 pun.c의 시작 부분에 주석을 추가했을 때의 모습입니다.

/* Name: pun.c */
/* Purpose: Prints a bad pun. */
/* Author: K. N. King */

#include <stdio.h>

int main(void)
{
    printf("To C, or not to C: that is the question.\n");
    return 0;
}

주석은 한 줄 이상에 걸쳐 확장될 수 있습니다. 컴파일러는 /* 기호를 본 후 */ 기호를 만날 때까지 그 뒤에 오는 모든 내용을 읽고(무시)합니다. 원한다면 일련의 짧은 주석들을 하나의 긴 주석으로 결합할 수도 있습니다.

/* Name: pun.c
   Purpose: Prints a bad pun.
   Author: K. N. King */

하지만 이런 주석은 주석이 어디서 끝나는지 보기 쉽지 않기 때문에 읽기 어려울 수 있습니다. */를 단독으로 한 줄에 배치하면 도움이 됩니다.

/* Name: pun.c
   Purpose: Prints a bad pun.
   Author: K. N. King
*/

더 나아가 주석을 돋보이게 만들기 위해 "상자(box)" 형태로 만들 수도 있습니다.

/****************************************
 * Name: pun.c                          *
 * Purpose: Prints a bad pun.           *
 * Author: K. N. King                   *
 ****************************************/

프로그래머들은 종종 상자 모양 주석의 세 면을 생략하여 단순화하기도 합니다.

/*
 * Name: pun.c
 * Purpose: Prints a bad pun.
 * Author: K. N. King
 */

짧은 주석은 다른 프로그램 코드와 같은 줄에 올 수 있습니다.

int main(void)    /* Beginning of main program */

이런 종류의 주석을 때때로 "날개 달린 주석(winged comment)"이라고 부릅니다.

⚠️ 경고: 주석을 닫는 것을 잊으면 컴파일러가 프로그램의 일부를 무시하게 될 수 있습니다. 다음 예제를 고려해 보세요. 
printf("My ");    /* forgot to close this comment...
printf("cat ");
printf("has ");    /* so it ends here */
printf("fleas");
첫 번째 주석을 닫는 것을 잊었기 때문에, 컴파일러는 중간에 있는 두 명령문을 무시하며, 예제는 My fleas를 출력하게 됩니다.

C99는 //(나란히 붙은 두 개의 슬래시)로 시작하는 두 번째 종류의 주석을 제공합니다.

// This is a comment

이 스타일의 주석은 줄 끝에서 자동으로 끝납니다. 한 줄 이상의 주석을 만들려면 예전 스타일(/* ... */)을 사용하거나, 각 주석 줄의 시작 부분에 //를 넣으면 됩니다.

// Name: pun.c
// Purpose: Prints a bad pun.
// Author: K. N. King

새로운 주석 스타일은 몇 가지 중요한 장점이 있습니다. 첫째, 주석이 줄 끝에서 자동으로 끝나기 때문에 닫히지 않은 주석이 실수로 프로그램의 일부를 삼킬 위험이 없습니다. 둘째, 여러 줄 주석은 각 줄 시작에 필요한 // 덕분에 더 잘 눈에 띕니다.

2.4 Variables and Assignment (변수와 할당)

2.1절의 프로그램처럼 단순한 프로그램은 거의 없습니다. 대부분의 프로그램은 출력을 생성하기 전에 일련의 계산을 수행해야 하며, 따라서 프로그램 실행 중에 데이터를 임시로 저장할 방법이 필요합니다. C에서는 대부분의 프로그래밍 언어와 마찬가지로 이러한 저장 위치를 변수(variables)라고 합니다.

Types (타입)

모든 변수에는 어떤 종류의 데이터를 담을 것인지 지정하는 타입(type)이 있어야 합니다. C에는 다양한 타입이 있습니다. 지금은 int와 float 두 가지만 제한적으로 살펴보겠습니다. 올바른 타입을 선택하는 것은 변수가 어떻게 저장되고 어떤 연산이 수행될 수 있는지에 영향을 미치므로 매우 중요합니다. 숫자 변수의 타입은 변수가 저장할 수 있는 가장 큰 수와 가장 작은 수를 결정하며, 소수점 이하 자릿수가 허용되는지도 결정합니다.

int(정수(integer)의 약자) 타입의 변수는 0, 1, 392, -2553과 같은 정수를 저장할 수 있습니다. 하지만 가능한 값의 범위는 제한적입니다. 가장 큰 int 값은 일반적으로 2,147,483,647이지만 32,767만큼 작을 수도 있습니다.

float(부동 소수점(floating-point)의 약자) 타입의 변수는 int 변수보다 훨씬 큰 숫자를 저장할 수 있습니다. 또한 float 변수는 379.125와 같이 소수점 이하 자릿수가 있는 숫자를 저장할 수 있습니다. 그러나 float 변수에는 단점이 있습니다. float 숫자에 대한 연산은 int 숫자에 대한 연산보다 느릴 수 있습니다. 가장 중요한 것은 float 변수의 값이 종종 저장된 숫자의 근사치일 뿐이라는 것입니다. float 변수에 0.1을 저장하면 나중에 반올림 오류로 인해 변수 값이 0.09999999999999987과 같이 나타날 수 있습니다.

Declarations (선언)

변수는 사용하기 전에 반드시 선언(declared)되어야 합니다. 즉, 컴파일러에게 변수에 대해 설명해야 합니다. 변수를 선언하려면 먼저 변수의 타입을 지정한 다음 이름을 지정합니다. 예를 들어 height와 profit 변수를 다음과 같이 선언할 수 있습니다.

int height;
float profit;

첫 번째 선언은 height가 정수 값을 저장할 수 있는 int 타입의 변수임을 나타냅니다. 두 번째 선언은 profit이 float 타입의 변수임을 나타냅니다.

여러 변수가 같은 타입을 가지고 있다면 선언을 결합할 수 있습니다.

int height, length, width, volume;
float profit, loss;

완전한 각 선언은 세미콜론으로 끝납니다.

우리의 첫 번째 main 템플릿에는 선언이 포함되지 않았습니다. main에 선언이 포함되어 있으면 명령문보다 먼저 와야 합니다.

int main(void)
{
    declarations (선언)
    statements (명령문)
}

9장에서 보겠지만, 이는 함수 일반과 블록(선언이 내장된 명령문)에도 해당됩니다. 스타일 측면에서 선언과 명령문 사이에 빈 줄을 남겨두는 것이 좋습니다.

C99에서는 선언이 명령문보다 먼저 올 필요가 없습니다. 예를 들어 main에 선언, 명령문, 또 다른 선언이 포함될 수 있습니다. 구형 컴파일러와의 호환성을 위해 이 책의 프로그램들은 이 규칙을 활용하지 않습니다. 그러나 C++ 및 Java 프로그램에서는 변수를 처음 필요로 할 때까지 선언하지 않는 것이 일반적이므로, C99 프로그램에서도 이 관행이 대중화될 것으로 예상할 수 있습니다.

Assignment (할당)

변수는 할당(assignment)을 통해 값을 부여받을 수 있습니다. 예를 들어 다음 명령문은

height = 8;
length = 12;
width = 10;

height, length, width에 값을 할당합니다. 숫자 8, 12, 10을 상수(constants)라고 합니다.

변수에 값을 할당하거나 어떤 방식으로든 사용하기 전에 먼저 선언해야 합니다. 따라서 다음과 같이 작성할 수는 있지만

int height;
height = 8;

다음과 같이 작성할 수는 없습니다.

height = 8;    /*** WRONG ***/
int height;

float 변수에 할당된 상수는 보통 소수점을 포함합니다. 예를 들어 profit이 float 변수라면 다음과 같이 작성할 수 있습니다.

profit = 2150.48;

소수점이 포함된 상수를 float 변수에 할당할 때는 상수 끝에 문자 f(또는 F)를 붙이는 것이 가장 좋습니다.

profit = 2150.48f;

f를 포함하지 않으면 컴파일러에서 경고가 발생할 수 있습니다.

int 변수에는 보통 int 타입의 값이 할당되고, float 변수에는 보통 float 타입의 값이 할당됩니다. 타입을 혼합하는 것(예: float 값을 int 변수에 할당)은 가능하지만 4.2절에서 보게 될 것처럼 항상 안전하지는 않습니다.

변수에 값이 할당되면 다른 변수의 값을 계산하는 데 사용할 수 있습니다.

height = 8;
length = 12;
width = 10;
volume = height * length * width;    /* volume is now 960 */

C에서 *는 곱셈 연산자를 나타내므로, 이 명령문은 height, length, width에 저장된 값을 곱한 다음 그 결과를 volume 변수에 할당합니다. 일반적으로 할당의 오른쪽은 상수, 변수 및 연산자를 포함하는 수식(또는 C 용어로 표현식(expression))일 수 있습니다.

Printing the Value of a Variable (변수 값 출력)

printf를 사용하여 변수의 현재 값을 표시할 수 있습니다. 예를 들어 h가 height 변수의 현재 값일 때 "Height: h"라는 메시지를 쓰려면 다음과 같이 printf를 호출합니다.

printf("Height: %d\n", height);

%d는 인쇄 중에 height의 값이 채워질 위치를 나타내는 자리 표시자(placeholder)입니다. \n이 %d 바로 뒤에 위치하여 printf가 height 값을 출력한 후 다음 줄로 이동하도록 합니다.

%d는 int 변수에만 작동합니다. float 변수를 출력하려면 %f를 대신 사용합니다. 기본적으로 %f는 소수점 이하 6자리까지 숫자를 표시합니다. 소수점 이하 p자리까지 강제로 표시하려면 %와 f 사이에 .p를 넣습니다. 예를 들어 "Profit: $2150.48" 줄을 출력하려면 다음과 같이 printf를 호출합니다.

printf("Profit: $%.2f\n", profit);

하나의 printf 호출로 출력할 수 있는 변수의 수에는 제한이 없습니다. height와 length 변수의 값을 모두 표시하려면 다음과 같이 호출할 수 있습니다.

printf("Height: %d Length: %d\n", height, length);

PROGRAM: Computing the Dimensional Weight of a Box (상자의 부피 무게 계산하기)

운송 회사들은 부피는 크지만 매우 가벼운 상자를 특히 싫어합니다. 트럭이나 비행기에서 귀중한 공간을 차지하기 때문입니다. 실제로 회사들은 종종 그러한 상자에 대해 추가 요금을 부과하며, 무게 대신 부피를 기준으로 요금을 책정합니다. 미국에서는 일반적인 방법으로 부피를 166(파운드당 허용되는 입방인치 수)으로 나눕니다. 이 숫자(상자의 "부피 무게(dimensional weight)")가 실제 무게를 초과하면 부피 무게를 기준으로 배송비가 책정됩니다.

당신이 운송 회사에 고용되어 상자의 부피 무게를 계산하는 프로그램을 작성한다고 가정해 봅시다. C가 처음이므로 먼저 \(12" \times 10" \times 8"\) 크기의 특정 상자의 부피 무게를 계산하는 프로그램을 작성하기로 결정합니다. C에서 나눗셈은 /로 표시되므로, 부피 무게를 계산하는 확실한 방법은 다음과 같습니다.

weight = volume / 166;

여기서 weight와 volume은 상자의 무게와 부피를 나타내는 정수 변수입니다. 안타깝게도 이 공식은 우리가 필요한 것과 정확히 일치하지 않습니다. C에서 한 정수를 다른 정수로 나누면 답이 "잘립니다(truncated)". 즉, 소수점 이하의 모든 숫자가 손실됩니다. \(12" \times 10" \times 8"\) 상자의 부피는 960 입방인치입니다. 166으로 나누면 5.783 대신 5가 나오므로, 사실상 다음 가장 낮은 파운드로 내림한 셈입니다. 운송 회사는 우리가 반올림(올림)하기를 기대합니다. 한 가지 해결책은 나누기 전에 부피에 165를 더하는 것입니다.

weight = (volume + 165) / 166;

부피가 166이면 331/166(또는 1)이 되고, 부피가 167이면 332/166(또는 2)이 됩니다. 이 방식으로 무게를 계산하면 다음과 같은 프로그램이 됩니다.

dweight.c
/* Computes the dimensional weight of a 12" x 10" x 8" box */

#include <stdio.h>

int main(void)
{
    int height, length, width, volume, weight;

    height = 8;
    length = 12;
    width = 10;
    volume = height * length * width;
    weight = (volume + 165) / 166;

    printf("Dimensions: %dx%d%d\n", length, width, height);
    printf("Volume (cubic inches): %d\n", volume);
    printf("Dimensional weight (pounds): %d\n", weight);

    return 0;
}

프로그램의 출력은 다음과 같습니다.

Dimensions: 12x10x8
Volume (cubic inches): 960
Dimensional weight (pounds): 6

Initialization (초기화)

일부 변수는 프로그램이 실행되기 시작할 때 자동으로 0으로 설정되지만, 대부분은 그렇지 않습니다. 기본값이 없고 프로그램에 의해 아직 값이 할당되지 않은 변수를 초기화되지 않은(uninitialized) 변수라고 합니다.

초기화되지 않은 변수의 값에 접근하려고 하면(예: printf를 사용하여 변수를 표시하거나 수식에 사용하는 경우) 2568, -30891 또는 이와 유사하게 이상한 숫자와 같은 예측할 수 없는 결과가 나올 수 있습니다. 일부 컴파일러에서는 프로그램 충돌과 같은 더 나쁜 동작이 발생할 수도 있습니다.

물론 할당을 사용하여 변수에 항상 초기값을 줄 수 있습니다. 하지만 더 쉬운 방법이 있습니다. 변수의 초기값을 선언에 넣는 것입니다. 예를 들어, height 변수를 선언하고 한 단계로 초기화할 수 있습니다.

int height = 8;

C 전문 용어로 값 8을 초기화자(initializer)라고 합니다.

같은 선언에서 여러 변수를 초기화할 수 있습니다.

int height = 8, length = 12, width = 10;

각 변수에는 고유한 초기화자가 필요합니다. 다음 예에서 초기화자 10은 width 변수에만 유효하며, height나 length에는 적용되지 않습니다(초기화되지 않은 상태로 남음).

int height, length, width = 10;

Printing Expressions (수식 출력)

printf는 변수에 저장된 숫자를 표시하는 것에 국한되지 않으며, 모든 숫자 수식의 값을 표시할 수 있습니다. 이 속성을 활용하면 프로그램을 단순화하고 변수 수를 줄일 수 있습니다. 예를 들어 다음 명령문은

volume = height * length * width;
printf("%d\n", volume);

다음과 같이 대체될 수 있습니다.

printf("%d\n", height * length * width);

printf가 수식을 인쇄하는 이 기능은 C의 일반적인 원칙 중 하나를 보여줍니다. "값이 필요한 곳이라면 어디든 같은 타입의 수식이면 무엇이든 올 수 있습니다."

📝 Section 2.3 - 2.4 Summary (써머리)

  • 주석(Comments)은 프로그램의 문서화를 위해 사용됩니다. /* ... */ (C89)와 // ... (C99) 두 가지 스타일이 있습니다.
  • 변수(Variables)는 데이터를 임시로 저장하는 공간이며, 사용 전에 반드시 타입(int, float 등)과 함께 선언(Declaration)되어야 합니다.
  • 할당(Assignment)은 = 연산자를 사용하여 변수에 값을 저장하는 것입니다. float 변수에는 상수 뒤에 f를 붙이는 것이 좋습니다.
  • 초기화(Initialization)는 선언과 동시에 값을 주는 것이며, 초기화하지 않은 변수는 예측할 수 없는 쓰레기 값을 가집니다.
  • printf에서 %d는 정수, %f는 실수를 출력하며, 수식을 직접 넣어 출력할 수도 있습니다.

💡 Chapter 2 Q&A (질의응답)

Q: C++나 다른 언어에서는 변수 선언을 중간에 해도 되던데, C99에서는 왜 허용되나요?
A: C89에서는 모든 선언이 블록의 시작 부분(명령문 이전)에 와야 했습니다. C99에서는 변수를 처음 사용하기 직전에 선언할 수 있도록 규칙이 완화되었습니다. 이는 코드를 더 읽기 쉽게 만들고 변수의 범위를 좁힐 수 있다는 장점이 있습니다.

Q: float 대신 double을 쓰면 더 정확하지 않나요?
A: 맞습니다. double은 float보다 더 많은 메모리를 사용하지만, 더 넓은 범위와 정밀도를 제공합니다. 임베디드 시스템에서는 메모리와 연산 속도를 아끼기 위해 float을 쓰기도 하지만, 정밀도가 중요한 과학 계산에서는 double을 주로 사용합니다.

Q: 주석을 너무 많이 달면 프로그램이 느려지나요?
A: 아닙니다. 주석은 컴파일 과정(전처리 단계)에서 모두 제거되므로 프로그램의 실행 속도나 크기에 전혀 영향을 주지 않습니다. 오히려 유지보수를 위해 충분한 주석을 다는 것이 좋습니다.
