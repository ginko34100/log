유리수

SERGE LANG · BASIC MATHEMATICS · CH.1 §5 · pp.26–42

§5 Rational Numbers

이 절의 한 문장 — 정수를 분수까지 넓히고, 그렇게 넓힌 세계조차 √2를 담지 못한다는 걸 증명한다.
먼저 · 이 절의 이야기 구조

§5는 두 부분으로 뚜렷하게 나뉩니다. 이걸 알고 읽으면 훨씬 편해요.

전반부(26–35쪽) — 분수를 다루는 기술. 십자곱, 약분, 기약분수, 통분, 덧셈, 곱셈, 거듭제곱. 대부분 이미 아는 내용입니다. Lang이 하는 일은 왜 그렇게 해도 되는지를 §2·§3의 규칙으로 뒷받침하는 겁니다.

후반부(35–37쪽) — 충격. 분수를 아무리 잘 다뤄도 √2는 못 만든다는 증명. 여기가 §5의 진짜 목적지이고, 3장 실수가 필요한 이유가 됩니다.

그리고 이 절에는 조용하지만 중요한 주제가 하나 더 흐릅니다. §2·§3에서 증명한 것들이 유리수에서도 그대로 통한다는 선언이에요. Lang이 두 번이나 강조합니다.

1. 유리수란 무엇인가DEFINITION

정의

유리수(rational number)란 평범한 분수, 즉 몫

mn  또는  m/n

을 말한다. 여기서 m, n 은 정수이고 n ≠ 0 이다.

Lang이 곧바로 강조합니다 — 0으로 나눌 수 없으므로 항상 n ≠ 0 인지 확인해야 한다.

예로 든 유리수들입니다.

14    23    34    57

유한소수도 유리수의 예가 됩니다.

1.4 = 1410     1.41 = 141100
내 설명 · 왜 하필 0만 안 되나

n = 0 을 금지하는 게 자의적인 규칙처럼 보이지만 이유가 있습니다.

mn 는 "n을 곱하면 m이 되는 수"라는 뜻입니다. 그런데 n = 0 이면? 0을 곱해서 m이 되는 수를 찾아야 하는데, §3에서 0a = 0 을 증명했죠. 0을 곱하면 무조건 0입니다.

그러니 m ≠ 0 이면 그런 수가 아예 없고, m = 0 이면 아무 수나 다 되어버립니다. 없거나 너무 많거나 — 어느 쪽도 "수 하나"가 아닙니다. 그래서 금지하는 거예요.

2. 수직선 위에 올리기ON THE LINE

정수 때와 똑같이 유리수도 직선 위에 표시할 수 있습니다.

  1. 12 은 0과 1 사이의 절반 지점에 놓입니다
  2. 23 은 0과 1 사이의 3분의 2 지점에 놓입니다
  3. 음의 유리수 −23 은 0의 반대편에, 0으로부터 거리 23 만큼 떨어진 곳에 놓입니다

§1에서 "덧셈은 걷기"라고 했던 그 직선이 그대로 쓰입니다. 눈금이 촘촘해졌을 뿐이에요.

3. 표현이 하나가 아니다NO UNIQUE REPRESENTATION

Lang이 짚는 중요한 사실입니다. 하나의 유리수를 두 정수의 몫으로 나타내는 방법은 유일하지 않습니다.

12 = 24

기하적으로 보면 이렇습니다. 0과 1 사이 선분을 4등분하고 그중 2조각을 취하면, 선분의 절반을 취한 것과 같습니다.

아래에서 두 분수를 직접 비교해 보세요.

⚠ 여기서 문제가 생깁니다

같은 수를 여러 꼴로 쓸 수 있다면, 두 분수가 같은 수인지 어떻게 판정하죠? 1751 과 2369 이 같은 수인가요?

이 물음에 답하기 위해 일반적인 규칙이 필요합니다. 그게 다음 항목입니다.

4. 십자곱 규칙 ★CROSS-MULTIPLYING

규칙 (증명 없이 가정)

m, n, r, s 를 정수라 하고 n ≠ 0, s ≠ 0 이라 하자. 그러면

mn = rs  일 필요충분조건은  ms = rn

"십자곱(cross-multiplying)"이라는 이름은 대각선으로 곱하는 그림에서 왔습니다.

m  ╲╱  r
n  ╱╲  s
m×s  =  r×n

Lang이 든 예를 그대로 보겠습니다.

주장십자곱 확인
12 = 241 · 4 = 2 · 2
37 = 9213 · 21 = 9 · 7 (양쪽 63)
−45 = 8−10(−4)(−10) = 8 · 5 (양쪽 40)

세 번째 줄이 보여주듯 십자곱은 음수에서도 그대로 작동합니다.

5. 정수도 유리수다

Lang은 정수 m 과 유리수 m1 을 구별하지 않겠다고 약속합니다.

m = m/1 = m1

이 약속에 따라 모든 정수는 유리수이기도 합니다. 예를 들어 3 = 3/1, −4 = −4/1.

내 설명 · 수 체계가 커지는 방식

이게 수학에서 계속 반복되는 패턴입니다. 새 세계를 만들 때 옛 세계를 통째로 안에 넣습니다.

정수 ⊂ 유리수 ⊂ 실수 ⊂ 복소수. 뒤로 갈수록 넓어지는데, 앞의 것을 버리지 않아요. 3은 정수이면서 동시에 유리수이고 실수이고 복소수입니다.

그래서 "정수에서 성립하던 규칙이 유리수에서도 성립하는가?"가 매번 중요한 질문이 됩니다. 이 절 뒤쪽에서 Lang이 정확히 그 답을 합니다.

Lang은 한쪽이 정수일 때의 특수한 경우도 짚습니다. 예를 들어

2n6 = 5  ⟺  2n = 30  ⟺  n = 302 = 15

이 셋은 n 에 관한 같은 관계를 다르게 쓴 것일 뿐입니다.

Lang의 각주(Remark) — 지금은 정수의 몫을 다루며 그 성질을 서술하는 중입니다. §6에서 곱셈의 역원을 다루는데, 거기서 십자곱 규칙이 역원의 성질로부터 실제로 증명될 수 있음을 보게 됩니다. 어떤 사람들은 그 증명이 십자곱이 "작동하는 이유"라고 봅니다. 하지만 어떤 맥락에서는 거꾸로 십자곱 규칙으로 곱셈의 역원을 정의하고 싶어 하죠. 그래서 여기서는 독립적으로 강조해 둔 것입니다.

6. 약분 규칙CANCELLATION RULE

약분 규칙

a 를 0이 아닌 정수라 하자. m, n 은 정수이고 n ≠ 0. 그러면

aman = mn

이번엔 가정이 아니라 증명합니다. 도구는 방금 받은 십자곱입니다.

PROOF · 약분 규칙
보일 것: (am)n = m(an)
십자곱 규칙을 적용한 것입니다. aman = mn 인지 판정하려면, 대각선끼리 곱한 (am)·n 과 m·(an) 이 같은지만 보면 됩니다.
등식 판정이 곱셈 확인으로 바뀌었습니다.
(am)n = m(an)
Lang의 말 그대로 — 결합법칙과 교환법칙에 의해 참입니다(§3).
실제로 (am)n = a·m·n 이고 m(an) = m·a·n = a·m·n. 순서와 묶음만 다를 뿐 같은 곱이에요.
증명 끝.

Lang이 든 예입니다. 음수로 약분해도 됩니다.

−45 = (−2)(−4)(−2)5 = 8−10

7. 마이너스는 어디에 붙여도 된다

음수가 섞인 몫을 다룰 때 유용한 관찰이라며 Lang이 짚습니다.

관찰
−mn = m−n

증명은 역시 십자곱입니다. (−m)(−n) = mn 임을 확인하면 되는데, 이건 §3의 N10에서 이미 알고 있습니다(음수 곱하기 음수는 양수).

나중에 −mn 까지 합쳐 이렇게 정리됩니다.

−mn = −mn = m−n

Lang의 표현대로, 마이너스 부호는 분수의 여러 자리를 옮겨 다녀도 값이 변하지 않습니다.

8. 공약수로 약분하기

약분 규칙은 §4에서 배운 나누어떨어짐 개념으로 이어집니다.

  1. d 가 양의 정수이고, m 과 n 이 둘 다 d 로 나누어떨어진다고 하자. 이때 d 를 m, n 의 공약수(common divisor)라 한다
  2. 그러면 어떤 정수 r, s 에 대해 m = dr, n = ds 로 쓸 수 있다
  3. 따라서 mn = drds = rs — 약분 규칙이 그대로 적용됩니다

Lang의 예입니다. 10과 15가 둘 다 5로 나누어떨어지므로:

1015 = 2 · 53 · 5 = 23

9. 기약분수와 정리 3LOWEST FORM · THEOREM 3

정의

양의 유리수란 mn 꼴로 쓸 수 있는 유리수다. 단 m, n 은 양의 정수.

양의 유리수 a 가

a = rs

로 쓰였고 r, s 가 양의 정수이며 r 과 s 의 공약수가 1뿐일 때, a 가 기약 형태(lowest form)로 표현되었다고 한다.

THEOREM 3

모든 양의 유리수는 기약분수 형태로 표현할 수 있다.

PROOF · THEOREM 3
a = m/n  (m, n 양의 정수)
주어진 양의 유리수를 일단 양의 정수의 몫으로 씁니다. 정의상 가능합니다.
공약수 중 가장 큰 것 d 가 존재한다
두 가지를 확인합니다.
① 공약수가 적어도 하나는 있다 — 1은 항상 공약수입니다(§4: 모든 정수는 1로 나누어떨어짐).
② 공약수가 무한정 커질 수 없다 — 어떤 공약수도 m 이나 n 을 넘지 못합니다.
개수가 유한하고 적어도 하나 있으니, 그중 가장 큰 것이 반드시 있습니다. 이걸 d 라 부릅니다.
m = dr,  n = ds  →  a = r/s
d 가 공약수이므로 그렇게 쓸 수 있고(§4 나눗셈 정의), 약분 규칙으로 drds = rs.
이제 남은 일은 r 과 s 의 공약수가 1뿐임을 보이는 것입니다.
e > 1 인 공약수가 있다고 가정
귀류법을 시작합니다. "1뿐이다"의 반대, 즉 1보다 큰 공약수 e 가 있다고 가정하고 모순을 찾습니다.
r = ex,  s = ey
공약수의 정의. x, y 는 양의 정수입니다.
m = dr = dex,  n = ds = dey
그냥 대입했습니다. 여기가 핵심 한 걸음입니다 — m 과 n 이 둘 다 de 라는 공통 인수를 갖게 되었어요.
∴ de 는 m, n 의 공약수이고 d 보다 크다
e > 1 이라고 가정했으므로 de > d 입니다.
그런데 d 는 가장 큰 공약수라고 했습니다. 자기보다 큰 공약수가 있을 수 없어요. 모순.
따라서 r 과 s 의 공약수는 1뿐입니다. 증명 끝.
내 설명 · 왜 "가장 큰" 공약수여야 하나

증명에서 아무 공약수나 뽑아 약분하면 안 됩니다. 반드시 최대여야 해요.

예를 들어 2436 에서 2로 약분하면 1218. 아직 6으로 더 약분됩니다. 기약이 아니죠.

최대공약수 12로 한 번에 약분해야 23 이 되고, 여기서 멈춥니다. "가장 크다"는 조건이 "더 이상 줄일 수 없다"를 보장하는 장치입니다.

증명의 마지막 모순도 정확히 이 지점을 찌릅니다. "더 약분된다면 d가 최대가 아니었다"는 거예요.

Lang이 바로 이어 붙이는 따름 예시가 있는데, 이게 뒤에서 결정적으로 쓰입니다.

★ 기억해둘 것

모든 양의 유리수는 mn 꼴로 쓸 수 있되, m 과 n 이 둘 다 짝수는 아니게 쓸 수 있다.

왜? 기약 형태로 쓰면 2가 m, n 을 동시에 나눌 수 없습니다(공약수가 1뿐이니까). 따라서 둘 중 적어도 하나는 홀수입니다.

이 한 줄이 뒤에 나올 정리 4의 급소가 됩니다.

아래에서 약분을 직접 해보세요.

10. 통분과 덧셈COMMON DENOMINATOR · ADDITION

두 유리수 mn 과 rs 를 공통분모 ns 위에 올릴 수 있습니다.

mn = msns     rs = nrns

Lang의 예 — 35 와 57 를 공통분모 5 · 7 = 35 위에 올리면:

35 = 3 · 735 = 2135     57 = 5 · 535 = 2535

먼저 분모가 같은 특수한 경우부터 봅니다.

35 + 85 = 115

Lang은 이게 유리수의 해석만으로도 당연하다고 말합니다. 어떤 것의 5분의 3을 갖고 있고 같은 것의 5분의 8을 더하면, 그것의 5분의 11을 얻습니다.

분모가 같을 때
mn + rn = m + rn

예: −58 + 28 = −38

일반 덧셈 공식
mn + rs = sm + nrsn

(n ≠ 0, s ≠ 0)

Lang의 예 세 개를 하나도 빼지 않고 보겠습니다.

식계산답
35 + 47 3·7 + 4·535 = 21 + 2035 4135
−52 + 37 (−5)·7 + 2·314 −2914
3−4 + 57 21 − 20−28 1−28

이 덧셈 규칙으로부터 곧바로 결론이 하나 나옵니다.

따름

양의 유리수의 합은 역시 양의 유리수다.

11. 0과 음수

n ≠ 0 인 임의의 정수 n 에 대해

0 = 0n

임을 십자곱으로 확인할 수 있습니다. 0 · 1 = 0 · n 이고 양쪽 다 0이니까요.

그리고 임의의 유리수 a 에 대해 0 + a = a + 0 = a 입니다. a = m/n 으로 쓰고 정수의 성질을 그대로 쓰면 됩니다.

정의 · 음의 유리수

m, n 이 양의 정수일 때

−mn = −mn = m−n

꼴로 쓸 수 있는 유리수를 음(negative)이라고 부른다.

예를 들어 3−5 = −35 = −35 는 음수입니다.

Lang은 음의 유리수의 합이 음수임은 스스로 확인해 보라고 남깁니다.

12. §2의 결과가 그대로 살아남는다 ★WHAT CARRIES OVER

가정 (증명 없이)

유리수의 덧셈은 교환법칙과 결합법칙을 만족한다.

정수 때와 똑같이 증명 없이 받습니다. 그리고 이 절에서 가장 중요한 선언이 이어집니다.

★ Lang의 선언

§2에서 우리는 교환법칙·결합법칙과 0 + a = a, a + (−a) = 0 만 써서 여러 성질을 증명했다.

따라서 그 성질들은 유리수에서도 그대로 유효하다. §2의 연습문제도 전부 유리수에서 유효하다.

내 설명 · 이게 왜 대단한 일인가

§2에서 증명한 걸 떠올려 보세요. N3, N4, N5.

그 증명들을 다시 읽어보면 "정수"라는 말을 한 번도 쓰지 않았습니다. 오직 네 가지 규칙(교환·결합·0+a=a·a+(−a)=0)만 썼어요.

그러니 그 네 규칙이 성립하는 세계라면 어디서든 같은 증명이 그대로 통합니다. 유리수든, 실수든, 아직 배우지 않은 무엇이든요.

이것이 수학이 "가정을 최소로 줄이려는" 진짜 이유입니다. 증명이 적은 재료로 되어 있을수록, 그 증명이 통하는 세계가 넓어집니다. §3에서 "가정은 빚"이라고 했는데, 그 빚을 줄인 대가를 여기서 받는 거예요.

Lang은 이 말을 앞으로 비슷한 상황마다 반복하겠다고 예고합니다. 실제로 §5 뒤쪽에서 곱셈에 대해 한 번 더 합니다.

예를 들어 §2의 N3이 그대로 살아 있으므로:

만약 a + b = 0 이면 b = −a

증명도 §2와 똑같습니다. 양변에 −a 를 더하면 됩니다. Lang의 말로 옮기면 — 어떤 유리수가 다른 유리수의 마이너스인지 확인하려면, 두 수의 합이 0인지만 보면 된다.

13. 곱셈MULTIPLICATION

곱셈 공식
mn · rs = mrns

곱의 분자는 분자들의 곱, 곱의 분모는 분모들의 곱

식계산답
35 · 783·75·82140

−45 · 7−3(−4)·75·(−3) = −28−152815

14. 거듭제곱

a = m/n 일 때, 곱셈 공식을 반복 적용하면:

a2 = m2n2     a3 = mn·mn·mn = m3n3
일반 규칙

임의의 양의 정수 k 에 대하여

(mn)k = mknk

예: (12)3 = 18    (35)4 = 81625

Lang의 예제 · 화학 물질

어떤 물질이 10분마다 절반으로 붕괴한다. 지금 20 g 이 있다면 50분 후 얼마가 남는가?

  1. 10분 후 → 12 · 20 g
  2. 20분 후 → 122 · 20 g
  3. 50분 후 → 125 · 20 = 2032 g

Lang은 이것도 정답이라고 말합니다. 기약 형태로 쓰고 싶으면 58 g 이 되고, 근사 소수로 바꿀 수도 있지만 여기서는 하지 않는다고요.

내 설명 · 이 유형의 골격

§3의 인구 문제와 똑같은 구조인데 배율이 1보다 작을 뿐입니다.

1단계 몇 번 변했나 = (전체 시간) ÷ (주기). 여기서는 50 ÷ 10 = 5번.
2단계 처음 값 × (배율)횟수. 여기서는 20 × (12)5.

연습문제 16~21번이 전부 이 골격입니다. "3분의 1이 사라진다"면 배율은 13 이 아니라 23 라는 것만 조심하세요. Lang도 문제에 주석을 달아 경고합니다.

15. √2 사냥 ★SEARCHING FOR A SQUARE ROOT OF 2

Lang이 질문을 던집니다. 제곱해서 2가 되는 양의 유리수가 있는가?

답은 처음엔 분명하지 않다고 말하며, 손으로 찾아 나섭니다.

  1. 12 = 1 은 2보다 작고, 22 = 4 는 2보다 큽니다
  2. 따라서 2의 양의 제곱근이 존재한다면 1과 2 사이에 있어야 합니다
  3. 1과 2의 한가운데인 1.5부터 시험합니다. (1.5)2 = 2.25 — 너무 큽니다

그래서 좀 더 체계적으로 갑니다. Lang의 표를 그대로 옮기면:

  2. 2의 제곱근에 점점 더 좋은 근사를 준다. 즉 제곱이 2에 점점 가까워지는 유리수들을 준다

이게 이상하지 않나요? 아무리 가까워져도 안 닿는다는 게요.

그런데 여기서 결정적인 함정이 있습니다. "계속 가까워지니까 언젠가는 닿겠지"는 증명이 아닙니다. 백만 자리까지 가도 "아직 못 찾았다"일 뿐, "없다"가 아니에요.

Lang의 표현이 재밌습니다. 이 절차는 "a bummer(맥 빠지는 일)" 라고요. 왜냐하면 다음 정리 때문입니다.

16. 정리 4 — 찾을 필요가 없었다 ★THEOREM 4

THEOREM 4

제곱해서 2가 되는 양의 유리수는 존재하지 않는다.

수학사에서 가장 유명한 증명 중 하나입니다. §4에서 만든 부품이 여기서 쓰입니다.

PROOF · THEOREM 4
그런 유리수가 존재한다고 가정하자
귀류법입니다. "없다"를 직접 보이는 건 어렵습니다. 그래서 "있다"고 가정하고 모순을 끌어냅니다.
기약 형태 m/n 으로 쓴다
정리 3 덕분에 가능합니다. 모든 양의 유리수는 기약분수로 쓸 수 있다고 방금 증명했죠.
특히 m 과 n 이 둘 다 짝수일 수는 없습니다. 앞의 ★ 표시한 그 사실입니다. 이게 마지막에 모순을 만드는 덫이에요.
(m/n)2 = 2  →  m2 = 2n2
거듭제곱 규칙으로 m2n2 = 2. 양변에 n2 을 곱하면(또는 십자곱) m2 = 2n2.
∴ m2 은 짝수
2n2 은 2 × (정수) 꼴입니다. §4의 짝수 정의 그대로예요.
∴ m 은 짝수
§4 정리 2의 따름정리입니다. Lang이 여기서 정확히 그걸 인용해요.
"m2 이 짝수면 m 도 짝수." §4에서 시시해 보였던 그 따름정리가 바로 여기 쓰입니다.
m = 2k  →  m2 = 4k2 = 2n2
m 이 짝수이므로 어떤 양의 정수 k 에 대해 m = 2k. 제곱하면 (2k)2 = 4k2. 그리고 이건 2n2 과 같습니다.
n2 = 2k2
4k2 = 2n2 의 양변에서 2를 약분했습니다. 2k2 = n2.
∴ n2 은 짝수 → n 도 짝수
앞과 똑같은 논법을 반복합니다. 2k2 은 짝수이고, 따름정리에 의해 n 도 짝수.
모순 — m, n 이 둘 다 짝수
기약 형태로 썼으므로 둘 다 짝수일 수는 없다고 했습니다. 그런데 둘 다 짝수라는 결론이 나왔어요.
따라서 처음 가정 (m/n)2 = 2 가 참일 수 없습니다.
증명 끝.
내 설명 · 이 증명의 급소는 "기약"이다

증명 전체에서 가장 영리한 한 수는 맨 앞에 있습니다. 기약 형태로 쓴 것.

왜 영리하냐면, "둘 다 짝수는 아니다"라는 덫을 미리 깔아둔 것이기 때문입니다. 그러고 나서 증명은 뚜벅뚜벅 걸어가 정확히 그 덫에 걸립니다.

만약 기약으로 안 썼다면? m, n 이 둘 다 짝수여도 아무 문제가 없습니다. 모순이 안 생겨요. 증명이 실패합니다.

부품 목록을 보세요. 이 증명은 §4·§5에서 만든 것들의 조립입니다.

정리 3(기약 형태) + §4 따름정리(m2 짝수 → m 짝수) + 거듭제곱 규칙 + 약분 규칙. 새로 만든 도구가 하나도 없습니다.

Lang이 §4에서 시시해 보이는 따름정리를 굳이 증명해둔 이유가 이거예요. 이 순간을 위해서였습니다.

정의

유리수가 아닌 수를 무리수(irrational)라고 한다.

정리 4로부터, 만약 a2 = 2 인 양수 a 가 존재한다면 그 a 는 반드시 무리수여야 합니다. Lang은 이 이야기를 실수를 다루는 다음 절(3장)에서 더 논의하겠다고 남깁니다.

⚠ "만약"에 주목하세요

정리 4가 말한 건 "유리수 중에는 없다" 뿐입니다. √2 라는 수가 존재하는지 자체는 아직 증명하지 않았습니다.

대각선 길이가 √2 인 정사각형은 분명히 그릴 수 있는데, 그 길이에 해당하는 수가 유리수 세계에는 없습니다. 수직선에 구멍이 뚫려 있는 셈이에요.

이 구멍을 메우려고 만드는 것이 실수이고, 그게 3장입니다. §5는 3장이 왜 필요한지를 증명한 절입니다.

17. 곱셈의 결과도 그대로 물려받는다

가정

임의의 유리수 a 에 대해 1a = a 이고 0a = 0 이다.
또한 곱셈은 결합적·교환적이며 덧셈에 대해 분배적이다.

덧셈 때와 같은 선언이 반복됩니다. §3에서 기본 성질만으로 증명한 것들은 유리수에서도 전부 유효합니다. 예를 들어

(a + b)2 = a2 + 2ab + b2

가 이제 유리수에서도 성립합니다. §3 끝의 연습문제도 전부 유리수에서 유효합니다.

Lang의 예제 세 개입니다.

EXAMPLE 1 · 3a − 1 = 7
3a = 7 + 1 = 8
양변에 1을 더했습니다. §2에서 배운 "양변에 같은 수 더하기"입니다.
a = 8/3

EXAMPLE 2 · 2(x − 3) = 7
2x − 6 = 7

x = 13/2

Lang은 다른 길도 보여줍니다. 분배법칙을 쓰지 않고 먼저 양변을 2로 나누면 x − 3 = 72, 따라서 x = 72 + 3.

1 = 4x − 3x = x
양변에 −3x 를 더했습니다. 왼쪽은 −7 + 8 = 1 만 남고, 오른쪽은 4x − 3x = x.
따라서 x = 1. 끝.
