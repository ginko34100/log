2.5 Reading Input (입력 읽기)

dweight.c 프로그램은 단 하나의 상자의 부피 무게만 계산하기 때문에 그다지 유용하지 않습니다. 프로그램을 개선하려면 사용자가 치수를 입력할 수 있도록 해야 합니다.

입력을 얻기 위해 우리는 printf의 C 라이브러리 대응물인 scanf 함수를 사용할 것입니다. printf의 f와 마찬가지로 scanf의 f도 "형식화된(formatted)"를 의미합니다. scanf와 printf 모두 입력 또는 출력 데이터의 모양을 지정하기 위해 형식 문자열(format string)을 사용해야 합니다. printf가 출력 데이터를 표시하는 방법을 알아야 하는 것처럼, scanf는 입력 데이터가 어떤 형태로 들어올지 알아야 합니다.

int 값을 읽으려면 다음과 같이 scanf를 사용합니다.

scanf("%d", &i);    /* reads an integer; stores into i */

"%d" 문자열은 scanf에게 정수를 나타내는 입력을 읽으라고 지시합니다. i는 scanf가 입력을 저장하기를 원하는 int 변수입니다. & 기호는 이 시점에서 설명하기 어렵습니다. 지금은 scanf를 사용할 때 보통(항상은 아니지만) 필요하다는 점만 알아두겠습니다.

float 값을 읽으려면 약간 다른 scanf 호출이 필요합니다.

scanf("%f", &x);    /* reads a float value; stores into x */

%f는 float 타입의 변수에서만 작동하므로 x가 float 변수라고 가정합니다. "%f" 문자열은 scanf에게 float 형식(숫자에 소수점이 포함될 수 있지만 반드시 그럴 필요는 없음)으로 입력 값을 찾도록 지시합니다.

PROGRAM: Computing the Dimensional Weight of a Box (Revisited) (상자의 부피 무게 계산하기 - 재방문)

다음은 사용자가 치수를 입력하는 부피 무게 프로그램의 개선된 버전입니다. 각 scanf 호출 바로 앞에 printf 호출이 온다는 점에 주목하세요. 이렇게 하면 사용자는 언제 입력을 입력해야 하고 어떤 입력을 입력해야 하는지 알 수 있습니다.

dweight2.c

/* Computes the dimensional weight of a box
   from input provided by the user */

#include <stdio.h>

int main(void)
{
    int height, length, width, volume, weight;

    printf("Enter height of box: ");
    scanf("%d", &height);
    printf("Enter length of box: ");
    scanf("%d", &length);
    printf("Enter width of box: ");
    scanf("%d", &width);
    volume = height * length * width;
    weight = (volume + 165) / 166;

    printf("Volume (cubic inches): %d\n", volume);
    printf("Dimensional weight (pounds): %d\n", weight);

    return 0;
}

프로그램의 출력은 다음과 같은 모양을 가집니다. (사용자가 입력한 내용은 밑줄이 그어져 있습니다.)

Enter height of box: 8
Enter length of box: 12
Enter width of box: 10
Volume (cubic inches): 960
Dimensional weight (pounds): 6

사용자에게 입력을 요청하는 메시지(prompt)는 보통 개행 문자(\n)로 끝나지 않아야 합니다. 왜냐하면 사용자가 프롬프트 자체와 같은 줄에서 입력을 입력하기를 원하기 때문입니다. 사용자가 Enter 키를 누르면 커서가 자동으로 다음 줄로 이동합니다. 프로그램이 현재 줄을 종료하기 위해 개행 문자를 표시할 필요가 없습니다.

dweight2.c 프로그램은 한 가지 문제점을 가지고 있습니다. 사용자가 숫자가 아닌 입력을 입력하면 올바르게 작동하지 않습니다. 3.2절에서 이 문제를 더 자세히 다룹니다.

PROGRAM: Converting from Fahrenheit to Celsius (화씨에서 섭씨로 변환)

다음 프로그램은 사용자에게 화씨 온도를 입력하라는 메시지를 표시한 다음, 그에 상응하는 섭씨 온도를 출력합니다. 프로그램의 출력은 다음과 같은 모양을 가집니다. (평소와 같이 사용자가 입력한 내용은 밑줄이 그어져 있습니다.)

Enter Fahrenheit temperature: 212
Celsius equivalent: 100.0

이 프로그램은 정수가 아닌 온도를 허용합니다. 그렇기 때문에 섭씨 온도가 100 대신 100.0으로 표시됩니다. 먼저 전체 프로그램을 살펴본 다음 어떻게 구성되었는지 살펴보겠습니다.

celsius.c

/* Converts a Fahrenheit temperature to Celsius */

#include <stdio.h>

#define FREEZING_PT 32.0f
#define SCALE_FACTOR (5.0f / 9.0f)

int main(void)
{
    float fahrenheit, celsius;

    printf("Enter Fahrenheit temperature: ");
    scanf("%f", &fahrenheit);
    celsius = (fahrenheit - FREEZING_PT) * SCALE_FACTOR;
    printf("Celsius equivalent: %.1f\n", celsius);

    return 0;
}

2.6 Defining Names for Constants (상수 이름 정의)

프로그램에 상수가 포함되어 있을 때, 종종 상수에 이름을 부여하는 것이 좋습니다. dweight.c와 dweight2.c 프로그램은 166이라는 상수에 의존하는데, 그 의미가 나중에 프로그램을 읽는 사람에게 전혀 명확하지 않을 수 있습니다. 매크로 정의(macro definition)라는 기능을 사용하여 이 상수의 이름을 지정할 수 있습니다.

#define INCHES_PER_POUND 166

#include와 마찬가지로 #define은 전처리 지시어이므로 줄 끝에 세미콜론이 없습니다.

프로그램이 컴파일될 때 전처리기는 매크로를 나타내는 값으로 각각의 매크로를 대체합니다. 예를 들어, 다음 명령문은

weight = (volume + INCHES_PER_POUND - 1) / INCHES_PER_POUND;

다음과 같이 바뀔 것입니다.

weight = (volume + 166 - 1) / 166;

처음부터 후자의 명령문을 작성한 것과 같은 효과를 줍니다.

매크로의 값은 수식이 될 수 있습니다.

#define RECIPROCAL_OF_PI (1.0f / 3.14159f)

연산자를 포함하는 경우 수식을 괄호로 묶어야 합니다.

매크로 이름에는 대문자만 사용했습니다. 이것은 대부분의 C 프로그래머가 따르는 관례일 뿐 언어의 요구 사항은 아닙니다. (하지만 C 프로그래머들은 수십 년 동안 이렇게 해왔습니다. 여러분이 처음으로 이탈하고 싶지는 않을 것입니다.)

이 프로그램에서 celsius.c는 FREEZING_PT와 SCALE_FACTOR 매크로를 정의합니다. SCALE_FACTOR를 (5 / 9) 대신 (5.0f / 9.0f)로 정의하는 것이 중요합니다. 왜냐하면 C는 두 정수를 나눌 때 결과를 잘라내기(truncate) 때문입니다. (5 / 9)의 값은 0이 되어 우리가 원하는 값이 아니게 됩니다.

printf 호출은 섭씨 온도를 씁니다.

printf("Celsius equivalent: %.1f\n", celsius);

섭씨를 소수점 이하 한 자리로 표시하기 위해 % .1f를 사용한 것에 주목하세요.

📝 Section 2.5 - 2.6 Summary (써머리)

  • scanf 함수는 사용자로부터 입력을 받을 때 사용하며, 입력받을 변수의 주소(&)를 전달해야 합니다.
  • 입력 프롬프트를 출력할 때는 사용자가 같은 줄에 입력할 수 있도록 개행 문자(\n)를 생략하는 것이 좋습니다.
  • #define을 사용하여 상수에 의미 있는 이름(매크로)을 부여할 수 있으며, 전처리 단계에서 값으로 치환됩니다.
  • 매크로 이름은 관례적으로 대문자를 사용하며, 수식이 들어갈 경우 괄호로 묶어야 안전합니다.
  • 정수끼리의 나눗셈은 소수점을 버리므로, 실수 결과를 얻으려면 5.0f / 9.0f처럼 실수형 상수를 사용해야 합니다.

🔥 형광칠한 핵심 내용 총정리 (Highlights)

지금까지 Section 2.5와 2.6에서 형광펜으로 강조한 가장 중요한 내용들을 한눈에 볼 수 있도록 연계하여 정리했습니다. 이 부분은 C 언어의 기초를 다지는 데 있어 반드시 기억해야 할 핵심입니다.

  • 1. 입력과 주소 연산자 (&):
    scanf를 사용할 때 변수 앞에 &를 붙이는 이유는 컴파일러에게 "이 변수가 저장된 메모리 주소"를 알려주기 위해서입니다. 컴퓨터는 변수의 이름만으로는 값을 어디에 저장해야 할지 모르기 때문에 주소를 통해 접근해야 합니다. (이 개념은 나중에 배울 '포인터'의 기초가 됩니다.)
  • 2. 입력 프롬프트와 개행 문자:
    입력 안내 문구를 출력할 때 \n을 붙이지 않아야 사용자가 안내 문구 바로 옆에 입력을 이어서 할 수 있습니다. 만약 \n을 붙이면 커서가 다음 줄로 넘어가 사용자 경험이 나빠집니다.
  • 3. 매크로(#define)의 역할과 대문자 관례:
    #define은 전처리기가 코드를 컴파일하기 전에 해당 이름을 값으로 '단순 치환'해 주는 역할을 합니다. 대문자를 사용하는 것은 언어의 강제 규칙이 아닌 C 프로그래머들의 오랜 약속(관례)으로, 일반 변수와 매크로를 시각적으로 구분해 줍니다.
  • 4. 정수 나눗셈의 함정 (가장 중요!):
    C 언어에서 정수(int)끼리 나누면 소수점 이하는 버려집니다. 따라서 5 / 9는 0이 됩니다. 실수 결과를 얻으려면 반드시 5.0f / 9.0f처럼 소수점이 있는 실수형 상수를 사용해야 합니다. 이 실수를 방지하기 위해 매크로 정의 시에도 괄호와 실수형 접미사(f)를 확실히 붙여야 합니다.
