짝수와 홀수, 나눗셈

SERGE LANG · BASIC MATHEMATICS · CH.1 §4 · pp.22–26

§4 Even and Odd Integers; Divisibility

이 절의 한 문장 — "모든 짝수"를 2n이라는 식 하나로 바꾸는 순간, 무한히 많은 수에 대한 증명이 가능해진다.
먼저 · 이 절이 진짜로 하는 일

제목만 보면 "짝수 홀수쯤이야" 싶습니다. 초등학교에서 배운 거니까요.

하지만 이 절의 목표는 짝수·홀수를 가르치는 게 아닙니다. 무한히 많은 수를 한 번에 다루는 기술을 처음 보여주는 거예요.

"모든 홀수의 제곱은 홀수다"를 증명하려면 어떻게 해야 할까요? 1, 3, 5, 7, … 을 하나씩 다 해볼 수는 없습니다. 무한하니까요.

그런데 홀수를 2n + 1 이라고 한 줄로 쓸 수 있다면, 그 한 줄만 제곱해보면 끝납니다. 이 절 전체가 이 발상 하나 위에 서 있습니다.

1. 두 종류로 나누기ODD AND EVEN

양의 정수 1, 2, 3, 4, 5, … 를 놓고 두 종류로 구분합니다.

정의

홀수(odd integers)

1, 3, 5, 7, 9, 11, 13, …

짝수(even integers)

2, 4, 6, 8, 10, 12, 14, …

Lang이 짚는 특징이 셋입니다.

  1. 홀수는 2씩 올라갑니다
  2. 짝수도 2씩 올라갑니다
  3. 차이는 출발점뿐입니다. 홀수는 1에서, 짝수는 2에서 시작합니다
내 설명 · 왜 이 셋을 굳이 말하나

당연해 보이지만 이게 다음 단계의 씨앗입니다.

"2씩 올라간다"는 말은 곧 2의 배수 구조가 깔려 있다는 뜻이고, "출발점만 다르다"는 말은 곧 2n 과 2n+1 로 쓸 수 있다는 뜻이거든요. Lang은 결론을 미리 말하지 않고 관찰만 던져둔 겁니다.

2. 식으로 바꾸기 ★ 이 절의 심장2n AND 2n+1

짝수의 다른 정의

짝수란, 어떤 양의 정수 n 에 대해 2n 꼴로 쓸 수 있는 양의 정수다

Lang이 든 예를 그대로 보면:

짝수2n 꼴n
22 · 11
42 · 22
62 · 33
82 · 44
홀수의 다른 정의 (1)

홀수란 짝수와 1만큼 차이나는 정수다. 따라서 어떤 양의 정수 m 에 대해 2m − 1 꼴로 쓸 수 있다

홀수2m − 1 꼴m
12 · 1 − 11
32 · 2 − 12
52 · 3 − 13
72 · 4 − 14
92 · 5 − 15
홀수의 다른 정의 (2) — 실제로 더 많이 씀

n 을 자연수로 허용하면, 즉 n = 0 을 허용하면 홀수를 2n + 1 꼴로도 쓸 수 있다

홀수2n + 1 꼴n
12 · 0 + 10
32 · 1 + 11
52 · 2 + 12
72 · 3 + 13
92 · 4 + 14
⚠ 여기서 §1이 되살아납니다

2n + 1 이 되려면 n = 0 이 허용돼야 하고, 그러려면 0이 자연수여야 합니다. §1에서 Lang이 자연수에 0을 넣어둔 게 여기서 쓰이는 거예요. 그래서 첫 줄이 1 = 2·0 + 1 로 시작할 수 있습니다.

2m − 1 쪽은 m 이 양의 정수(1부터)면 충분합니다. 두 표기의 조건이 다르다는 걸 놓치지 마세요.

내 설명 · 점으로 보면 한 장

수를 점 무더기라고 생각하고 둘씩 짝지어 보세요.

짝수 = 짝이 딱 맞아떨어짐. 남는 점이 없음 → 2n

홀수 = 짝을 다 지어도 하나가 남음 → 2n + 1

이 "남는 점 하나"가 이 절 전체의 주인공입니다. 아래에서 직접 짝지어 보세요.

3. 정리 1 — 더하면 어떻게 되나THEOREM 1

THEOREM 1

a, b 를 양의 정수라 하자.

① a 짝수, b 짝수 → a + b 짝수

② a 짝수, b 홀수 → a + b 홀수

③ a 홀수, b 짝수 → a + b 홀수

④ a 홀수, b 홀수 → a + b 짝수

Lang은 ②만 증명하고 나머지는 연습문제로 남깁니다. (연습문제 1번)

PROOF · ② 짝수 + 홀수 = 홀수
a = 2n,  b = 2k + 1
가정을 식으로 번역한 것입니다. a 가 짝수라 했으니 어떤 양의 정수 n 에 대해 2n. b 가 홀수라 했으니 어떤 자연수 k 에 대해 2k+1.
이 한 줄이 증명의 전부라고 해도 됩니다. 말을 식으로 바꾼 순간 계산이 가능해졌으니까요.
a + b = 2n + 2k + 1
그냥 대입했습니다. 특별한 기술 없음.
= 2(n + k) + 1
분배법칙을 거꾸로 썼습니다(§3). 2n + 2k = 2(n+k) 로 공통 인수 2를 묶었어요.
왜 하필 2로 묶나? "짝수/홀수"의 정의가 2를 기준으로 되어 있기 때문입니다. 답의 모양을 미리 알고 그쪽으로 맞춰가는 겁니다.
= 2m + 1  (m = n + k 로 두면)
n + k 를 m 이라는 새 이름으로 부른 것뿐입니다. 계산이 아니라 이름 붙이기예요.
왜 굳이? 2m + 1 이 되어야 홀수의 정의와 글자 그대로 같은 모양이 되기 때문입니다.
증명 끝. 따라서 a + b 는 홀수입니다.
내 설명 · 점으로 보면 즉시 보임

짝수 a = 짝이 딱 맞는 무더기. 홀수 b = 짝이 맞고 하나 남은 무더기.

둘을 합치면? 짝은 짝끼리 그대로 있고, 남은 하나는 여전히 하나입니다. 짝지어줄 상대가 없거든요. 그래서 홀수.

④가 더 재밌습니다. 홀수 + 홀수. 양쪽에서 하나씩 남는데, 그 둘이 서로 짝이 됩니다. 남는 게 없어지니 짝수예요.

아래에서 직접 합쳐보세요.

4. 정리 2 — 제곱하면 어떻게 되나THEOREM 2

THEOREM 2

a 를 양의 정수라 하자.

a 가 짝수면 a2 도 짝수다.

a 가 홀수면 a2 도 홀수다.

PROOF · 앞부분 — a가 짝수인 경우
a = 2n
짝수의 정의. 어떤 양의 정수 n 이 존재합니다.
a2 = 2n · 2n
거듭제곱의 정의(§3). 제곱은 자기 자신을 두 번 곱한 것.
= 2(2n2)
곱셈의 교환·결합법칙(§3). 2·n·2·n 을 2·(2·n·n) 으로 재배열했습니다. 여기서도 2를 앞으로 빼내는 게 목표예요.
= 2m  (m = 2n2)
이름 붙이기. m = 2n2 은 양의 정수입니다 — 정수끼리 곱했으니까요.
이 확인이 중요합니다. m 이 정수가 아니면 2m 은 짝수가 아니거든요.
앞부분 증명 끝.
PROOF · 뒷부분 — a가 홀수인 경우
a = 2n + 1
홀수의 정의. 여기서 n 은 자연수입니다(0 허용).
a2 = (2n + 1)2
대입.
= (2n)2 + 2(2n)(1) + 12
§3의 첫 번째 암기 공식입니다. (a+b)2 = a2 + 2ab + b2 에서 a = 2n, b = 1 로 둔 것.
§3에서 "반드시 외우라"고 했던 그 공식이 바로 다음 절에서 쓰입니다.
= 4n2 + 4n + 1
계산했습니다. (2n)2 = 4n2, 2(2n)(1) = 4n, 12 = 1.
= 2(2n2 + 2n) + 1
또 2로 묶기. 분배법칙을 거꾸로 써서 4n2 + 4n 에서 2를 뽑아냈습니다.
+1은 건드리지 않습니다. 그게 홀수 표시니까요.
= 2k + 1  (k = 2n2 + 2n)
이름 붙이기. k 는 정수입니다.
증명 끝. 따라서 a2 는 홀수입니다.
내 설명 · 증명의 리듬을 외우세요

세 증명이 전부 똑같은 네 박자였습니다.

  1. 번역 — "짝수다"를 2n 으로 바꾼다
  2. 계산 — 시키는 대로 더하거나 제곱한다
  3. 2로 묶기 — 분배법칙을 거꾸로 써서 2를 앞으로 뺀다
  4. 이름 붙이기 — 남은 덩어리에 새 문자를 주고, 그게 정수인지 확인한다

§4의 연습문제 1~7번은 전부 이 네 박자로 풀립니다. 숫자만 바뀔 뿐이에요.

5. 따름정리 — 뒤집어 읽기 ★COROLLARY

COROLLARY

a 를 양의 정수라 하자.

a2 이 짝수면 a 도 짝수다.

a2 이 홀수면 a 도 홀수다.

Lang은 이걸 "정리를 다시 표현한 것에 지나지 않는다"고 말합니다. 평범한 논리를 적용했을 뿐이라고요.

PROOF · 따름정리
a2 이 짝수라 하자
가정입니다. 여기서 a 가 짝수임을 보여야 합니다.
a 는 홀수일 수 없다
정리 2 때문입니다. 만약 a 가 홀수라면 a2 도 홀수여야 해요. 그런데 a2 은 짝수라고 가정했습니다. 모순.
∴ a 는 짝수
정수는 짝수 아니면 홀수, 둘 중 하나입니다. 홀수가 아니라면 짝수일 수밖에 없어요.
뒷부분도 같은 방식입니다. a2 이 홀수면 a 는 짝수일 수 없습니다(짝수의 제곱은 짝수니까). 따라서 홀수.
증명 끝.
내 설명 · 이게 논리적으로 무엇인가

지금 쓴 논리에 이름이 있습니다. 대우(contrapositive)입니다.

"A이면 B" 가 참이면 "B가 아니면 A도 아니다" 도 반드시 참입니다.

여기서는 "a 홀수면 a2 홀수" 를 뒤집어 "a2 홀수가 아니면(=짝수면) a 도 홀수가 아니다(=짝수다)" 로 쓴 겁니다.

주의할 것 — "A이면 B"가 참이라고 해서 "B이면 A"가 참인 건 아닙니다. 이건 역이고, 참일 수도 거짓일 수도 있어요. 대우와 역을 헷갈리면 증명이 통째로 무너집니다. Interlude §2에서 정식으로 다룹니다.

여기서 대우가 통한 결정적 이유는 "정수는 짝수 아니면 홀수" 라는 사실입니다. 제3의 가능성이 없어야 "홀수가 아니다 = 짝수다" 로 넘어갈 수 있어요.

★ 이 따름정리가 나중에 무엇에 쓰이나

지금은 시시해 보이지만, 이게 수학사에서 가장 유명한 증명의 핵심 부품입니다.

√2 가 유리수가 아님을 증명할 때 쓰입니다. 대략 이런 흐름이에요.

① √2 = m/n 이라고 가정 (더 이상 약분 안 되는 상태) → ② 양변 제곱하면 m2 = 2n2 → ③ 그럼 m2 이 짝수 → ④ 따름정리에 의해 m 도 짝수 → ⑤ 같은 논법으로 n 도 짝수 → ⑥ 둘 다 짝수면 약분이 되어야 하는데 안 된다고 했으니 모순

④ 자리에 정확히 이 따름정리가 들어갑니다. 3장에서 실제로 만나게 돼요.

6. 나눗셈으로 일반화DIVISIBILITY

Lang은 "짝수를 정의할 때 쓴 성질을 일반화할 수 있다"고 말하며 넘어갑니다.

정의

d 를 양의 정수, n 을 정수라 하자.

n = dk

를 만족하는 정수 k 가 존재하면,
d 가 n 을 나눈다(divides), 또는 n 이 d 로 나누어떨어진다고 한다.

이 정의로 보면 짝수란 2로 나누어떨어지는 양의 정수입니다. 짝수는 나눗셈의 특수한 경우였던 거예요.

Lang이 든 예를 하나도 빼지 않고 보겠습니다.

주장왜냐하면
9는 3으로 나누어떨어진다9 = 3 · 3
15는 3으로 나누어떨어진다15 = 3 · 5
−30은 5로 나누어떨어진다−30 = 5(−6)
모든 정수는 1로 나누어떨어진다n = 1 · n
모든 양의 정수는 자기 자신으로 나누어떨어진다n = n · 1
⚠ 세 번째 줄을 그냥 넘기지 마세요

−30 = 5(−6). 여기서 k = −6 으로 음수입니다.

정의를 다시 읽어보세요. d 는 양의 정수여야 하지만 k 는 그냥 정수입니다. 조건이 다릅니다. 그래서 음수도 나누어떨어질 수 있어요.

이 비대칭을 놓치면 나중에 정수론에서 계속 걸립니다.

내 설명 · 정의를 정확히 읽는 훈련

이 정의에서 "존재하면" 이라는 말이 핵심입니다. 나눗셈을 실제로 하지 않습니다.

"d 가 n 을 나눈다"는 곱셈으로만 정의돼 있어요. n 을 d 로 나눈 결과를 구하는 게 아니라, 곱해서 n 이 되는 정수 짝이 있느냐를 묻는 겁니다.

왜 이렇게 할까요? 나눗셈은 정수 세계를 벗어나기 때문입니다. 7 ÷ 2 는 정수가 아니죠. 하지만 곱셈은 정수 안에서 끝납니다. 정수 이야기를 정수 언어로만 하려는 것이 이 정의의 의도예요.

보너스 — 0은?

Lang은 언급하지 않지만 자연히 나오는 질문입니다. 0은 모든 양의 정수로 나누어떨어집니다. 0 = d · 0 이고 0은 정수니까요. d = 7 이든 d = 1000 이든 상관없습니다.

반대로 d = 0 은 애초에 금지돼 있습니다. 정의에서 d 를 양의 정수로 못박았으니까요.

나누어떨어짐을 점으로 보면 이렇습니다.

7. 합동 — 연습문제 24·25번CONGRUENCE MOD d

§4 연습문제 마지막에 완전히 새로운 개념이 정의 없이 툭 나옵니다. 겁먹지 않도록 미리 풀어둘게요.

정의 (연습문제 25번)

d 를 양의 정수, a, b 를 정수라 하자.

a ≡ b (mod d)

는 a − b 가 d 로 나누어떨어진다는 뜻이다.
"a 는 d 를 법으로 b 와 합동이다"라고 읽는다.

내 설명 · 시계로 보면 끝

시계가 곧 mod 12 세계입니다.

시계에서 15시는 3시와 같은 자리입니다. 왜? 15 − 3 = 12 이고 12는 12로 나누어떨어지니까요. 즉 15 ≡ 3 (mod 12).

합동은 "같다"가 아니라 "나머지가 같다"입니다. d 로 나눈 나머지가 같은 수들을 한 덩어리로 묶는 거예요.

mod 5 라면 정수 전체가 딱 5덩어리로 나뉩니다 — 나머지 0인 것들, 1인 것들, 2, 3, 4. 이게 24번 문제의 배경입니다.

24·25번이 요구하는 것은 이겁니다. 합동인 채로 더하고 곱해도 합동이 유지되는가? 답은 예이고, 증명은 §4에서 배운 네 박자로 그대로 됩니다. 아래 연습에 풀이를 넣어뒀습니다.

내 설명 · 연습문제 26번의 3k, 3k+1, 3k+2

26번은 2 대신 3으로 같은 일을 하라는 문제입니다.

2로 나누면 나머지가 0 또는 1 → 2n, 2n+1 두 종류.
3으로 나누면 나머지가 0, 1, 2 → 3k, 3k+1, 3k+2 세 종류.

이렇게 모든 정수를 빠짐없이 몇 종류로 나눠놓고 각 경우를 다 확인하는 방법을 경우 나누기라고 합니다. 종류가 유한하기만 하면, 무한한 정수 전체를 다룰 수 있어요.

8. 연습 문제교재 25–26쪽

교재 §4 연습문제 1~26번을 유형별로 다뤘습니다. 먼저 직접 풀어보세요.

1번 ①정리 1의 나머지 경우를 증명하세요. 먼저 짝수 + 짝수 = 짝수.
번역 a = 2n, b = 2k (n, k 양의 정수)
계산 a + b = 2n + 2k
2로 묶기 = 2(n + k)
이름 m = n + k 로 두면 a + b = 2m, m 은 양의 정수
따라서 a + b 는 짝수 ∎
1번 ③홀수 + 짝수 = 홀수.
a = 2n + 1, b = 2k
a + b = 2n + 1 + 2k = 2(n + k) + 1 = 2m + 1
따라서 홀수 ∎
사실 ②의 결과에 덧셈의 교환법칙을 쓰면 한 줄로도 끝납니다. a + b = b + a 이고 ②가 이미 "짝수+홀수=홀수"를 보였으니까요.
1번 ④홀수 + 홀수 = 짝수. — 가장 재밌는 경우
a = 2n + 1, b = 2k + 1
a + b = 2n + 1 + 2k + 1 = 2n + 2k + 2
= 2(n + k + 1)
m = n + k + 1 로 두면 a + b = 2m → 짝수 ∎
양쪽의 남은 1 두 개가 합쳐져 2가 되고, 그 2가 통째로 묶여 들어간 것입니다.
2번a 가 짝수이고 b 가 임의의 양의 정수면 ab 는 짝수임을 증명하세요.
a = 2n 이므로
ab = 2n · b = 2(nb)
m = nb 는 정수이므로 ab = 2m → 짝수 ∎
b가 짝수인지 홀수인지 전혀 묻지 않았다는 점에 주목하세요. 한쪽만 짝수면 곱은 무조건 짝수입니다.
3번a 가 짝수면 a3 도 짝수임을 증명하세요.
a = 2n
a3 = (2n)3 = 2n · 2n · 2n = 2(4n3)
m = 4n3 은 정수 → a3 = 2m → 짝수 ∎
4번a 가 홀수면 a3 도 홀수임을 증명하세요.
지름길: 정리 2에서 a2 은 홀수입니다. 그리고 7번(홀수×홀수=홀수)에 의해 a3 = a2 · a 도 홀수 ∎

직접 전개: a = 2n + 1
a3 = 8n3 + 12n2 + 6n + 1
= 2(4n3 + 6n2 + 3n) + 1 → 홀수 ∎
전개에는 §3 연습문제에서 본 (a+b)3 의 1-3-3-1 계수를 씁니다.
5·6번n 이 짝수면 (−1)n = 1, 홀수면 (−1)n = −1 임을 증명하세요.
5번 n = 2k 이므로
(−1)n = (−1)2k = ((−1)2)k  (§3의 N12)
(−1)2 = 1 이므로 = 1k = 1 ∎

6번 n = 2k + 1 이므로
(−1)n = (−1)2k · (−1)1  (§3의 N11)
= 1 · (−1) = −1 ∎
§3의 지수 법칙 두 개가 그대로 도구로 쓰였습니다.
7번m, n 이 홀수면 곱 mn 도 홀수임을 증명하세요.
m = 2a + 1, n = 2b + 1
mn = (2a+1)(2b+1) = 4ab + 2a + 2b + 1
= 2(2ab + a + b) + 1
k = 2ab + a + b 는 정수 → 홀수 ∎
8~15번다음 수를 나누는 2의 가장 큰 거듭제곱을 구하세요.
16, 24, 32, 20, 50, 64, 100, 36
2로 계속 나누어 홀수가 될 때까지 세면 됩니다.

16 = 24 → 24
24 = 23·3 → 23
32 = 25 → 25
20 = 22·5 → 22
50 = 2·25 → 21
64 = 26 → 26
100 = 22·25 → 22
36 = 22·9 → 22
요령: 나눈 결과가 홀수가 되는 순간 멈춥니다. 홀수는 더 이상 2로 안 나뉘니까요.
16~23번다음 수를 나누는 3의 가장 큰 거듭제곱을 구하세요.
30, 27, 63, 99, 60, 50, 42, 45
30 = 3·10 → 31
27 = 33 → 33
63 = 32·7 → 32
99 = 32·11 → 32
60 = 3·20 → 31
50 = 2·25 → 30 = 1 (3으로 안 나뉨)
42 = 3·14 → 31
45 = 32·5 → 32
50번을 주의하세요. 3으로 한 번도 안 나뉘면 답은 30 = 1 입니다. "없다"가 아니라 0제곱이에요.
24·25번a ≡ b (mod d) 이고 x ≡ y (mod d) 이면 a + x ≡ b + y (mod d) 임을 증명하세요.
번역 가정을 나눗셈 정의로 풉니다.
a − b = dk, x − y = dl (k, l 은 정수)

보일 것 (a + x) − (b + y) 가 d 로 나누어떨어짐

계산
(a + x) − (b + y) = (a − b) + (x − y)  (교환·결합법칙)
= dk + dl
= d(k + l)  (분배법칙 거꾸로)

k + l 은 정수이므로 d 로 나누어떨어짐 ∎
24·25번 (곱)같은 가정에서 ax ≡ by (mod d) 임을 증명하세요. — 조금 까다롭습니다
a − b = dk, x − y = dl

요령: ax − by 를 바로 묶으려 하면 안 됩니다. 중간에 없는 항을 하나 끼워 넣습니다.

ax − by = ax − bx + bx − by
(−bx 와 +bx 를 더했으니 값은 그대로 — §2 N2)
= x(a − b) + b(x − y)  (분배법칙 거꾸로, 두 번)
= x(dk) + b(dl)
= d(xk + bl)

xk + bl 은 정수이므로 d 로 나누어떨어짐 ∎
"0을 더해서 모양을 만든다"는 이 수법은 앞으로 계속 나옵니다. 기억해두세요.
26번모든 양의 정수가 3k, 3k+1, 3k+2 중 하나로 쓰인다고 하자. 양의 정수의 제곱이 3으로 나누어떨어지면 그 정수도 3으로 나누어떨어짐을 보이세요.
전략: 따름정리와 똑같이 대우로 갑니다. "a 가 3의 배수가 아니면 a2 도 3의 배수가 아니다"를 보이면 됩니다.

3의 배수가 아닌 경우는 두 가지뿐입니다.

경우 ① a = 3k + 1
a2 = 9k2 + 6k + 1 = 3(3k2 + 2k) + 1
→ 3으로 나눈 나머지가 1. 나누어떨어지지 않음

경우 ② a = 3k + 2
a2 = 9k2 + 12k + 4 = 3(3k2 + 4k + 1) + 1
→ 나머지가 1. 역시 나누어떨어지지 않음

두 경우 모두 a2 이 3의 배수가 아닙니다.
대우에 의해, a2 이 3의 배수면 a 도 3의 배수 ∎
이 결과는 √3 이 무리수임을 증명할 때 그대로 쓰입니다.
