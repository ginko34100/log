7.1 Integer Types (정수 타입)

C는 근본적으로 다른 두 가지 종류의 숫자 타입을 지원합니다: 정수 타입(integer types)과 부동 타입(floating types)입니다. 정수 타입의 값은 정수(whole numbers)이고, 부동 타입의 값은 소수 부분을 가질 수 있습니다. 정수 타입은 다시 부호 있는(signed) 정수와 부호 없는(unsigned) 정수의 두 범주로 나뉩니다.

Signed and Unsigned Integers (부호 있는 정수와 부호 없는 정수)

부호 있는 정수(signed integer)의 가장 왼쪽 비트(부호 비트, sign bit)는 숫자가 양수이거나 0이면 0이고, 음수이면 1입니다. 따라서 가장 큰 16비트 정수는 이진수 0111111111111111로 표현되며, 이는 32,767(2^15 - 1)의 값을 가집니다. 가장 큰 32비트 정수는 01111111111111111111111111111111이며, 이는 2,147,483,647(2^31 - 1)의 값을 가집니다. 부호 비트가 없는(가장 왼쪽 비트가 숫자의 크기의 일부로 간주되는) 정수는 부호 없는(unsigned) 정수라고 합니다. 가장 큰 16비트 부호 없는 정수는 65,535(2^16 - 1)이고, 가장 큰 32비트 부호 없는 정수는 4,294,967,295(2^32 - 1)입니다.

기본적으로 C에서 정수 변수는 부호가 있습니다(signed). 가장 왼쪽 비트는 부호를 위해 예약되어 있습니다. 변수에 부호 비트가 없음을 컴파일러에 알리려면 unsigned로 선언합니다. 부호 없는 숫자는 주로 시스템 프로그래밍과 저수준의 기계 종속적인 응용 프로그램에 유용합니다. 20장에서 부호 없는 숫자의 일반적인 응용 프로그램에 대해 논의할 것입니다. 그때까지는 일반적으로 부호 없는 숫자를 피할 것입니다.

C의 정수 타입은 다양한 크기로 제공됩니다. int 타입은 보통 32비트이지만 구형 CPU에서는 16비트일 수 있습니다. 일부 프로그램은 int 형태로 저장하기에는 너무 큰 숫자를 필요로 하므로 C는 긴 정수(long integers)도 제공합니다. 때로는 컴파일러에게 일반보다 적은 공간에 숫자를 저장하도록 지시하여 메모리를 절약해야 할 수도 있습니다. 이러한 숫자를 짧은 정수(short integer)라고 합니다.

우리의 요구를 정확히 충족하는 정수 타입을 구성하기 위해 변수가 long 또는 short, signed 또는 unsigned임을 지정할 수 있습니다. 지정자를 결합할 수도 있습니다(예: long unsigned int). 그러나 실제로 서로 다른 타입을 생성하는 것은 다음 여섯 가지 조합뿐입니다.

  • short int
  • unsigned short int
  • int
  • unsigned int
  • long int
  • unsigned long int

다른 조합은 이 여섯 가지 타입 중 하나의 동의어입니다(예: 정수는 항상 달리 지정하지 않는 한 부호가 있으므로 long signed int는 long int와 같습니다). 덧붙여, 지정자의 순서는 중요하지 않습니다. unsigned short int는 short unsigned int와 같습니다.

C를 사용하면 int라는 단어를 삭제하여 정수 타입의 이름을 축약할 수 있습니다. 예를 들어 unsigned short int는 unsigned short로 축약될 수 있고, long int는 단순히 long으로 축약될 수 있습니다. int를 생략하는 것은 C 프로그래머들 사이에서 널리 퍼진 관행이며, 일부 최신 C 기반 언어(Java 포함)는 실제로 프로그래머에게 short int 또는 long int 대신 short 또는 long을 작성하도록 요구합니다.

각 정수 타입이 나타내는 값의 범위는 기계마다 다릅니다. 그러나 모든 컴파일러가 따라야 하는 몇 가지 규칙이 있습니다. 첫째, C 표준은 short int, int, long int 각각이 특정 최소 범위의 값을 포함하도록 요구합니다. 둘째, 표준은 int가 short int보다 짧지 않고, long int가 int보다 짧지 않도록 요구합니다. 그러나 short int가 int와 동일한 범위의 값을 나타내는 것도 가능하며, int가 long int와 동일한 범위를 가질 수도 있습니다.

Integer Types in C99 (C99의 정수 타입)

C99는 매우 큰 정수에 대한 증가하는 요구와 64비트 산술을 지원하는 최신 프로세서의 능력 때문에 두 가지 추가 표준 정수 타입인 long long int와 unsigned long long int를 제공합니다. 두 long long 타입은 최소 64비트 너비여야 하므로, long long int 값의 범위는 일반적으로 -2^63 ~ 2^63 - 1이고, unsigned long long int의 범위는 보통 0 ~ 2^64 - 1입니다.

C99에서 short int, int, long int, long long int 타입(그리고 signed char 타입)은 표준 부호 있는 정수 타입(standard signed integer types)이라고 합니다. unsigned short int, unsigned int, unsigned long int, unsigned long long int 타입(그리고 unsigned char 타입과 _Bool 타입)은 표준 부호 없는 정수 타입(standard unsigned integer types)이라고 합니다.

표준 정수 타입 외에도 C99 표준은 구현 정의 확장 정수 타입(implementation-defined extended integer types)을 허용합니다. 예를 들어 컴파일러는 부호 있는 128비트 정수 타입과 부호 없는 128비트 정수 타입을 제공할 수 있습니다.

Integer Constants (정수 상수)

이제 상수, 즉 읽거나 쓰거나 계산된 숫자가 아니라 프로그램 텍스트에 나타나는 숫자로 관심을 돌려보겠습니다. C를 사용하면 정수 상수를 10진수(10진법), 8진수(8진법) 또는 16진수(16진법)로 작성할 수 있습니다.

8진수 및 16진수(Octal and Hexadecimal Numbers):
8진수는 0부터 7까지의 숫자만 사용하여 작성됩니다. 8진수의 각 위치는 8의 거듭제곱을 나타냅니다. 따라서 8진수 237은 10진수 2*8^2 + 3*8^1 + 7*8^0 = 128 + 24 + 7 = 159를 나타냅니다.

16진수(hex)는 0부터 9까지의 숫자와 10부터 15까지를 나타내는 A부터 F까지의 문자를 사용하여 작성됩니다. 16진수의 각 위치는 16의 거듭제곱을 나타냅니다. 16진수 1AF는 10진수 값 1*16^2 + 10*16^1 + 15*16^0 = 256 + 160 + 15 = 431을 가집니다.

  • 10진수 상수는 0에서 9 사이의 숫자를 포함하지만 0으로 시작해서는 안 됩니다. (예: 15, 255, 32767)
  • 8진수 상수는 0에서 7 사이의 숫자만 포함하며 0으로 시작해야 합니다. (예: 017, 0377, 077777)
  • 16진수 상수는 0에서 9 사이의 숫자와 a에서 f 사이의 문자를 포함하며 항상 0x로 시작합니다. (예: 0xf, 0xff, 0x7fff)

16진수 상수의 문자는 대문자 또는 소문자일 수 있습니다. 8진수와 16진수는 숫자를 작성하는 대체 방법일 뿐이며 숫자가 실제로 저장되는 방식에는 영향을 미치지 않습니다. (정수는 표현하는 데 사용한 표기법에 관계없이 항상 이진수로 저장됩니다.)

10진수 정수 상수의 타입은 일반적으로 int입니다. 그러나 상수 값이 int로 저장하기에 너무 크면 상수는 long int 타입을 가집니다. 8진수나 16진수 상수의 타입을 결정하는 규칙은 약간 다릅니다. 컴파일러는 상수를 표현할 수 있는 타입을 찾을 때까지 int, unsigned int, long int, unsigned long int 타입을 살펴봅니다.

컴파일러가 상수를 긴 정수로 처리하도록 강제하려면 상수 뒤에 문자 L(또는 l)을 붙입니다. 상수가 부호 없음을 나타내려면 상수 뒤에 문자 U(또는 u)를 붙입니다. L과 U를 함께 사용하여 상수가 long이면서 unsigned임을 나타낼 수 있습니다.

Integer Constants in C99 (C99의 정수 상수)

C99에서 LL 또는 ll로 끝나는 정수 상수는 long long int 타입을 가집니다. LL 또는 ll 앞이나 뒤에 문자 U(또는 u)를 추가하면 unsigned long long int 타입의 상수를 나타냅니다. C99에서 접미사가 없는 10진수 상수의 타입은 해당 상수 값을 나타낼 수 있는 int, long int, long long int 타입 중 "가장 작은" 타입입니다.

Integer Overflow (정수 오버플로)

정수에 대해 산술 연산을 수행할 때 결과가 너무 커서 표현할 수 없을 가능성이 있습니다. 산술 연산의 결과가 int로 표현할 수 없을 때(너무 많은 비트가 필요하기 때문에) 오버플로(overflow)가 발생했다고 합니다. 부호 있는 정수에 대한 연산 중 오버플로가 발생하면 프로그램의 동작은 정의되지 않습니다(undefined). 대부분의 경우 연산 결과가 잘못될 뿐이지만 프로그램이 충돌하거나 다른 바람직하지 않은 동작을 보일 수도 있습니다. 부호 없는 정수에 대한 연산 중 오버플로가 발생하면 결과는 정의됩니다. 즉, 올바른 답에 2^n을 나눈 나머지(모듈로)를 얻습니다.

Reading and Writing Integers (정수 읽기 및 쓰기)

프로그램이 int 변수 오버플로로 인해 작동하지 않는다고 가정해 봅시다. 가장 먼저 떠오르는 생각은 변수 타입을 int에서 long int로 변경하는 것입니다. 그러나 변경 사항이 프로그램의 나머지 부분에 어떤 영향을 미칠지 확인해야 합니다. 특히 printf나 scanf 호출에서 변수가 사용되는지 확인해야 합니다. %d 변환은 int 타입에만 작동하므로 형식 문자열을 변경해야 합니다.

부호 없는(unsigned), 짧은(short), 긴(long) 정수를 읽고 쓰려면 몇 가지 새로운 변환 지정 사양이 필요합니다.

  • 부호 없는 정수(unsigned): 변환 지정 사양에서 d 대신 u, o 또는 x를 사용합니다. u는 10진수, o는 8진수, x는 16진수를 나타냅니다. (예: %u, %o, %x)
  • 짧은 정수(short): d, o, u 또는 x 앞에 문자 h를 붙입니다. (예: %hd)
  • 긴 정수(long): d, o, u 또는 x 앞에 문자 l("one"이 아닌 "ell")을 붙입니다. (예: %ld)
  • long long 정수(C99): d, o, u 또는 x 앞에 문자 ll을 붙입니다. (예: %lld)

PROGRAM: Summing a Series of Numbers (Revisited) (일련의 숫자 합계 계산하기 - 재방문)

6.1절에서 사용자가 입력한 일련의 정수의 합계를 계산하는 프로그램을 작성했습니다. 이 프로그램의 한 가지 문제는 합계(또는 입력 숫자 중 하나)가 int 변수에 허용되는 최대값을 초과할 수 있다는 것입니다.

이 문제를 해결하기 위해 변수를 long으로 변경해 보겠습니다.

sum2.c

/* Sums a series of numbers (using long variables) */

#include <stdio.h>

int main(void)
{
    long n, sum = 0;

    printf("This program sums a series of integers.\n");
    printf("Enter integers (0 to terminate): ");

    scanf("%ld", &n);
    while (n != 0) {
        sum += n;
        scanf("%ld", &n);
    }
    printf("The sum is: %ld\n", sum);

    return 0;
}

변경 사항은 매우 간단했습니다. n과 sum을 int 대신 long 변수로 선언한 다음, scanf 및 printf의 변환 지정 사양을 %d 대신 %ld로 변경했습니다.

7.2 Floating Types (부동 타입)

정수 타입이 모든 응용 프로그램에 적합한 것은 아닙니다. 때로는 소수점 뒤에 숫자가 있는 숫자나 매우 크거나 작은 숫자를 저장할 수 있는 변수가 필요합니다. 이러한 숫자는 부동 소수점 형식(floating-point format)으로 저장됩니다(소수점이 "떠다니기(floats)" 때문에 그렇게 불립니다). C는 서로 다른 부동 소수점 형식에 해당하는 세 가지 부동 타입을 제공합니다.

  • float: 단정밀도(single-precision) 부동 소수점
  • double: 배정밀도(double-precision) 부동 소수점
  • long double: 확장 정밀도(extended-precision) 부동 소수점

float는 정밀도가 중요하지 않은 경우(예: 온도를 소수점 한 자리까지 계산)에 적합합니다. double은 더 높은 정밀도를 제공하며 대부분의 프로그램에 충분합니다. 궁극의 정밀도를 제공하는 long double은 거의 사용되지 않습니다.

The IEEE Floating-Point Standard (IEEE 부동 소수점 표준)

IEEE 표준 754는 전기전자공학자협회(Institute of Electrical and Electronics Engineers)에서 개발한 부동 소수점 숫자에 대한 두 가지 기본 형식인 단정밀도(32비트)와 배정밀도(64비트)를 제공합니다. 숫자는 과학적 표기법의 한 형태로 저장되며, 각 숫자는 부호(sign), 지수(exponent), 그리고 소수(fraction)의 세 부분을 가집니다. 지수에 예약된 비트 수는 숫자가 얼마나 크거나 작을 수 있는지를 결정하고, 소수의 비트 수는 정밀도를 결정합니다. 단정밀도 형식에서 지수는 8비트이고 소수는 23비트를 차지합니다. 결과적으로 단정밀도 숫자의 최대값은 약 3.40 × 10^38이고 정밀도는 약 6자리 10진수입니다.

IEEE 표준은 또한 단일 확장 정밀도(single extended precision)와 이중 확장 정밀도(double extended precision)라는 두 가지 다른 형식을 설명합니다. 표준은 이러한 형식의 비트 수를 지정하지 않지만 단일 확장 타입은 최소 43비트, 이중 확장 타입은 최소 79비트를 차지하도록 요구합니다.

표 7.4는 IEEE 표준에 따라 구현될 때 부동 타입의 특성을 보여줍니다. (long double 타입은 기계마다 길이가 다르므로 표에 표시되지 않습니다. 가장 일반적인 크기는 80비트와 128비트입니다.)

타입가장 작은 양수 값가장 큰 값정밀도
float1.17549 × 10^-383.40282 × 10^386자리
double2.22507 × 10^-3081.79769 × 10^30815자리

표 7.4 IEEE 표준에 따른 부동 타입의 특성

IEEE 표준을 따르지 않는 컴퓨터에서는 표 7.4가 유효하지 않습니다. 실제로 일부 컴퓨터에서는 float가 double과 동일한 값 집합을 가질 수도 있고, double이 long double과 동일한 값을 가질 수도 있습니다. 부동 타입의 특성을 정의하는 매크로는 <float.h> 헤더에서 찾을 수 있습니다.

Floating Constants (부동 소수점 상수)

부동 소수점 상수는 다양한 방식으로 작성할 수 있습니다. 예를 들어, 다음 상수들은 모두 숫자 57.0을 작성하는 유효한 방법입니다.

57.0  57.  57.0e0  57E0  5.7e1  5.7e+1  .57e2  570.e-1

부동 소수점 상수는 소수점 및/또는 지수를 포함해야 합니다. 지수는 숫자에 곱할 10의 거듭제곱을 나타냅니다. 지수가 있는 경우 문자 E(또는 e)가 앞에 와야 합니다. 선택적 + 또는 - 부호가 E(또는 e) 뒤에 올 수 있습니다.

기본적으로 부동 소수점 상수는 배정밀도 숫자로 저장됩니다. 즉, C 컴파일러가 프로그램에서 상수 57.0을 발견하면 숫자가 double 변수와 동일한 형식으로 메모리에 저장되도록 배열합니다. 이 규칙은 double 값이 필요할 때 자동으로 float로 변환되기 때문에 일반적으로 문제를 일으키지 않습니다.

때로는 컴파일러가 부동 소수점 상수를 float 또는 long double 형식으로 저장하도록 강제해야 할 수도 있습니다. 단정밀도만을 원한다는 것을 나타내려면 상수 끝에 문자 F(또는 f)를 붙입니다(예: 57.0F). 상수를 long double 형식으로 저장해야 함을 나타내려면 끝에 문자 L(또는 l)을 붙입니다(57.0L).

Reading and Writing Floating-Point Numbers (부동 소수점 숫자 읽기 및 쓰기)

이미 논의한 바와 같이 변환 지정 사양 %e, %f, %g는 단정밀도 부동 소수점 숫자를 읽고 쓰는 데 사용됩니다. double 및 long double 타입의 값에는 약간 다른 변환이 필요합니다.

  • double 값 읽기: e, f 또는 g 앞에 문자 l을 붙입니다. (예: scanf("%lf", &d);) 참고: scanf 형식 문자열에서만 l을 사용하고, printf 문자열에서는 사용하지 마세요. printf 형식 문자열에서는 e, f, g 변환을 사용하여 float 또는 double 값을 쓸 수 있습니다.
  • long double 값 읽기/쓰기: e, f 또는 g 앞에 문자 L을 붙입니다. (예: scanf("%Lf", &ld); printf("%Lf", ld);)

7.3 Character Types (문자 타입)

남아 있는 유일한 기본 타입은 char, 즉 문자 타입입니다. char 타입의 값은 서로 다른 컴퓨터가 서로 다른 기본 문자 세트를 가질 수 있기 때문에 컴퓨터마다 다를 수 있습니다.

Character Sets (문자 세트)

오늘날 가장 인기 있는 문자 세트는 ASCII(American Standard Code for Information Interchange)로, 128개의 문자를 나타낼 수 있는 7비트 코드입니다. ASCII에서 숫자 0부터 9는 코드 0110000~0111001로 표현되고, 대문자 A부터 Z는 1000001~1011010으로 표현됩니다. ASCII는 종종 서유럽 및 많은 아프리카 언어에 필요한 문자를 제공하는 256자 코드인 Latin-1로 확장됩니다.

char 타입의 변수에는 단일 문자를 할당할 수 있습니다.

char ch;
ch = 'a';  /* lower-case a */
ch = 'A';  /* upper-case A */
ch = '0';  /* zero */
ch = ' ';  /* space */

문자 상수는 큰따옴표가 아닌 작은따옴표로 묶입니다.

Operations on Characters (문자에 대한 연산)

한 가지 사실 때문에 C에서 문자로 작업하는 것은 간단합니다. C는 문자를 작은 정수로 취급합니다. 결국 문자는 이진수로 인코딩되며, 이러한 이진 코드를 정수로 보는 것은 그리 많은 상상력을 필요로 하지 않습니다. 예를 들어 ASCII에서 문자 코드는 0000000에서 1111111까지이며, 이를 0에서 127까지의 정수로 생각할 수 있습니다. 문자 'a'는 97, 'A'는 65, '0'은 48, ' '는 32의 값을 가집니다. C에서 문자와 정수 사이의 연결은 너무 강해서 문자 상수는 실제로 char 타입이 아닌 int 타입을 가집니다.

문자가 계산에 나타나면 C는 단순히 정수 값을 사용합니다. 다음 예를 고려해 보세요(ASCII 문자 세트 가정).

char ch;
int i;

i = 'a';        /* i is now 97 */
ch = 65;        /* ch is now 'A' */
ch = ch + 1;    /* ch is now 'B' */
ch++;           /* ch is now 'C' */

문자는 숫자처럼 비교할 수 있습니다. 다음 if 문은 ch에 소문자가 포함되어 있는지 확인하고, 포함되어 있으면 ch를 대문자로 변환합니다.

if ('a' <= ch && ch <= 'z')
    ch = ch - 'a' + 'A';

'a' <= ch와 같은 비교는 관련된 문자의 정수 값을 사용하여 수행됩니다. 이러한 값은 사용 중인 문자 세트에 따라 다르므로 <, <=, >, >=를 사용하여 문자를 비교하는 프로그램은 이식성이 없을 수 있습니다.

Signed and Unsigned Characters (부호 있는 문자와 부호 없는 문자)

C는 문자를 정수로 사용할 수 있도록 하기 때문에 char 타입이 정수 타입처럼 부호 있는 버전과 부호 없는 버전으로 존재한다는 것은 놀라운 일이 아닙니다. 부호 있는 문자는 일반적으로 -128에서 127 사이의 값을 가지며, 부호 없는 문자는 0에서 255 사이의 값을 가집니다.

C 표준은 일반 char가 부호 있는 타입인지 부호 없는 타입인지 지정하지 않습니다. 일부 컴파일러는 부호 있는 타입으로 취급하고 다른 컴파일러는 부호 없는 타입으로 취급합니다. 대부분의 경우 char가 부호가 있는지 없는지는 중요하지 않습니다. 그러나 때때로, 특히 문자 변수를 사용하여 작은 정수를 저장하는 경우에는 중요합니다. 이러한 이유로 C는 char를 수정하기 위해 signed 및 unsigned라는 단어의 사용을 허용합니다.

signed char sch;
unsigned char uch;

이식성 팁: char가 기본적으로 부호가 있거나 없다고 가정하지 마세요. 중요한 경우 char 대신 signed char 또는 unsigned char를 사용하세요.

Arithmetic Types (산술 타입)

정수 타입과 부동 타입을 총칭하여 산술 타입(arithmetic types)이라고 합니다. 다음은 C89의 산술 타입 요약입니다.

  • 정수 타입(Integral types): char, 부호 있는 정수 타입(signed char, short int, int, long int), 부호 없는 정수 타입(unsigned char, unsigned short int, unsigned int, unsigned long int), 열거형 타입
  • 부동 타입(Floating types): float, double, long double

C99는 더 복잡한 계층 구조를 가집니다. (정수 타입, 부동 타입, 복소수 타입 등 추가)

Escape Sequences (이스케이프 시퀀스)

문자 상수는 보통 작은따옴표로 묶인 하나의 문자입니다. 그러나 줄 바꿈 문자를 포함한 특정 특수 문자는 보이지 않거나(비인쇄) 키보드에서 입력할 수 없기 때문에 이런 방식으로 작성할 수 없습니다. 기본 문자 세트의 모든 문자를 프로그램이 처리할 수 있도록 C는 이스케이프 시퀀스(escape sequence)라는 특수 표기법을 제공합니다.

표 7.5는 완전한 문자 이스케이프 세트를 제공합니다.

표 7.5 문자 이스케이프

문자 이스케이프는 모든 비인쇄 ASCII 문자를 포함하지 않으며 기본 128 ASCII 문자 이외의 문자를 나타내는 데는 쓸모가 없습니다. 숫자 이스케이프(numeric escapes)는 이 문제에 대한 해결책입니다.

  • 8진수 이스케이프 시퀀스: \ 뒤에 최대 3자리의 8진수가 옵니다. (예: \33 또는 \033)
  • 16진수 이스케이프 시퀀스: \x 뒤에 16진수가 옵니다. (예: \x1b 또는 \x1B)

Character-Handling Functions (문자 처리 함수)

이전에 소문자를 대문자로 변환하는 if 문을 작성하는 방법을 보았습니다. 이것은 최선의 방법이 아닙니다. 더 빠르고 이식성이 뛰어난 방법은 C의 toupper 라이브러리 함수를 호출하는 것입니다.

ch = toupper(ch);    /* converts ch to upper case */

toupper가 호출되면 인수(이 경우 ch)가 소문자인지 확인합니다. 그렇다면 해당하는 대문자를 반환합니다. 그렇지 않으면 toupper는 인수의 값을 반환합니다. toupper를 호출하는 프로그램은 상단에 #include <ctype.h> 지시어가 있어야 합니다.

Reading and Writing Characters using scanf and printf (scanf와 printf를 사용하여 문자 읽기 및 쓰기)

%c 변환 지정 사양을 사용하면 scanf와 printf가 단일 문자를 읽고 쓸 수 있습니다.

char ch;
scanf("%c", &ch);    /* reads a single character */
printf("%c", ch);    /* writes a single character */

scanf는 문자를 읽기 전에 공백 문자를 건너뛰지 않습니다. 읽지 않은 다음 문자가 공백이면 scanf가 반환된 후 변수 ch에 공백이 포함됩니다. scanf가 문자를 읽기 전에 공백을 건너뛰도록 하려면 형식 문자열에서 %c 바로 앞에 공백을 넣으세요.

scanf(" %c", &ch);    /* skips white space, then reads ch */

Reading and Writing Characters using getchar and putchar (getchar와 putchar를 사용하여 문자 읽기 및 쓰기)

C는 단일 문자를 읽고 쓰는 다른 방법을 제공합니다. 특히 scanf와 printf를 호출하는 대신 getchar 및 putchar 함수를 사용할 수 있습니다. putchar는 단일 문자를 씁니다. getchar가 호출될 때마다 하나의 문자를 읽고 반환합니다. 이 문자를 저장하려면 변수에 저장하기 위해 할당을 사용해야 합니다.

ch = getchar();    /* reads a character and stores it in ch */

getchar는 실제로 char 값이 아닌 int 값을 반환합니다. 결과적으로 getchar가 읽은 문자를 저장하는 데 사용될 변수는 char 대신 int 타입을 가지는 것이 드문 일이 아닙니다. scanf와 마찬가지로 getchar는 읽을 때 공백 문자를 건너뛰지 않습니다.

scanf와 printf 대신 getchar와 putchar를 사용하면 프로그램이 실행될 때 시간을 절약할 수 있습니다. getchar와 putchar는 두 가지 이유로 빠릅니다. 첫째, 다양한 형식으로 여러 종류의 데이터를 읽고 쓰도록 설계된 scanf와 printf보다 훨씬 간단합니다. 둘째, getchar와 putchar는 추가 속도를 위해 매크로로 구현되는 경우가 많습니다.

7.4 Type Conversion (타입 변환)

컴퓨터는 산술 연산을 수행할 때 일반적으로 피연산자가 동일한 크기(동일한 비트 수)여야 하고 동일한 방식으로 저장되어야 합니다. 16비트 정수와 32비트 정수를 직접 더할 수는 없습니다. 반면 C는 기본 타입을 수식에서 혼합할 수 있도록 허용합니다. 정수, 부동 소수점 숫자, 심지어 문자까지 단일 수식에서 결합할 수 있습니다. 그런 다음 C 컴파일러는 하드웨어가 수식을 평가할 수 있도록 일부 피연산자를 다른 타입으로 변환하는 명령어를 생성해야 할 수 있습니다.

컴파일러가 프로그래머의 개입 없이 자동으로 이러한 변환을 처리하기 때문에 암시적 변환(implicit conversions)이라고 합니다. C는 또한 프로그래머가 캐스트 연산자를 사용하여 명시적 변환(explicit conversions)을 수행할 수 있도록 합니다.

The Usual Arithmetic Conversions (일반적인 산술 변환)

일반적인 산술 변환은 산술, 관계 및 동등 연산자를 포함한 대부분의 이항 연산자의 피연산자에 적용됩니다. 일반적인 산술 변환의 기본 전략은 두 값을 모두 안전하게 수용할 수 있는 "가장 좁은(narrowest)" 타입으로 피연산자를 변환하는 것입니다. (대략적으로 말하면, 한 타입이 다른 타입보다 저장하는 데 바이트가 적게 필요하면 더 좁습니다.)

일반적인 산술 변환을 수행하는 규칙은 두 가지 경우로 나눌 수 있습니다.

  • 피연산자 중 하나의 타입이 부동 타입인 경우: 더 좁은 타입의 피연산자를 더 넓은 부동 타입(long double > double > float)으로 승격(promotion)합니다.
  • 피연산자 타입이 부동 타입이 아닌 경우: 먼저 두 피연산자에 정수 승격(integral promotion)을 수행합니다(문자나 짧은 정수가 int로 변환됨). 그런 다음 더 좁은 타입의 피연산자를 더 넓은 정수 타입(unsigned long int > long int > unsigned int > int)으로 승격합니다.
⚠️ 경고: 부호 있는 피연산자와 부호 없는 피연산자가 결합되면 부호 있는 피연산자가 부호 없는 값으로 변환됩니다.
변환에는 n + 1의 배수를 더하거나 빼는 것이 포함되며, 여기서 n은 부호 없는 타입의 가장 큰 표현 가능한 값입니다. 이 규칙은 모호한 프로그래밍 오류를 유발할 수 있습니다. 예를 들어, int 변수 i의 값이 -10이고 unsigned int 변수 u의 값이 10이라고 가정해 봅시다. < 연산자를 사용하여 i와 u를 비교하면 결과가 1(참)일 것으로 예상할 수 있습니다. 그러나 비교 전에 i가 unsigned int로 변환됩니다. 음수는 부호 없는 정수로 표현할 수 없기 때문에 변환된 값은 -10이 아닙니다. 대신 값 4,294,967,296이 추가되어 변환된 값이 4,294,967,286이 됩니다. 따라서 i < u 비교는 0을 생성합니다. 이러한 함정 때문에 부호 없는 정수를 가능한 한 적게 사용하고, 특히 부호 있는 정수와 혼합하지 않는 것이 가장 좋습니다.

Conversion During Assignment (할당 중 변환)

일반적인 산술 변환은 할당에 적용되지 않습니다. 대신 C는 할당 오른쪽의 수식이 왼쪽 변수의 타입으로 변환되는 간단한 규칙을 따릅니다. 변수 타입이 수식만큼 "넓으면" 문제 없이 작동합니다. 그러나 부동 소수점 숫자를 정수 변수에 할당하면 숫자의 소수 부분이 삭제됩니다. 또한 값이 변수 타입의 범위를 벗어나면 더 좁은 타입의 변수에 값을 할당하면 의미 없는 결과(또는 그 이상)가 발생합니다. 컴파일러나 `lint`와 같은 도구에서 경고를 표시할 수 있습니다.

Implicit Conversions in C99 (C99의 암시적 변환)

C99의 암시적 변환 규칙은 주로 C99에 추가 타입(_Bool, long long 타입, 확장 정수 타입, 복소수 타입)이 있기 때문에 C89의 규칙과 다소 다릅니다. (복잡한 규칙은 생략하고 핵심만 설명) 모든 산술 타입은 _Bool 타입으로 변환될 수 있습니다. 변환 결과는 원래 값이 0이면 0이고, 그렇지 않으면 1입니다.

Casting (캐스팅)

C의 암묵적 변환이 편리하지만 때로는 타입 변환을 더 세밀하게 제어해야 합니다. 이를 위해 C는 캐스트(cast)를 제공합니다. 캐스트 수식은 (type-name) expression 형태를 가집니다.

다음 예제는 캐스트 수식을 사용하여 float 값의 소수 부분을 계산하는 방법을 보여줍니다.

float f, frac_part;
frac_part = f - (int) f;

캐스트 수식 (int) f는 f의 값을 int 타입으로 변환한 결과를 나타냅니다. 캐스트는 때때로 오버플로를 피하기 위해 필요합니다. (예: i = (long) j * j;에서 j * j가 int 범위를 넘어설 때)

7.5 Type Definitions (타입 정의)

5.2절에서 부울 타입으로 사용할 수 있는 매크로를 만들기 위해 #define 지시어를 사용했습니다. 그러나 타입 정의(type definition)라는 기능을 사용하여 부울 타입을 설정하는 더 좋은 방법이 있습니다.

typedef int Bool;

정의되는 타입의 이름이 마지막에 온다는 점에 유의하세요. typedef를 사용하여 Bool을 정의하면 컴파일러가 인식하는 타입 이름 목록에 Bool이 추가됩니다.

Advantages of Type Definitions (타입 정의의 장점)

타입 정의는 프로그램을 더 이해하기 쉽게 만들 수 있습니다. 예를 들어 cash_in과 cash_out 변수가 달러 금액을 저장하는 데 사용된다고 가정해 봅시다. Dollars를 typedef float Dollars;로 선언하고 Dollars cash_in, cash_out;으로 작성하는 것이 단순히 float cash_in, cash_out;으로 작성하는 것보다 더 유익합니다. 또한 나중에 Dollars를 double로 정의하기로 결정하더라도 타입 정의만 변경하면 되므로 프로그램을 더 쉽게 수정할 수 있습니다.

Type Definitions and Portability (타입 정의와 이식성)

타입 정의는 이식성 있는 프로그램을 작성하기 위한 중요한 도구입니다. 프로그램을 한 컴퓨터에서 다른 컴퓨터로 옮길 때의 문제 중 하나는 타입이 기계마다 다른 범위를 가질 수 있다는 것입니다. 이식성 팁: 더 큰 이식성을 위해 typedef를 사용하여 정수 타입에 대한 새로운 이름을 정의하는 것을 고려하세요. 예를 들어 0~50,000 범위의 값을 저장해야 하는 경우 int 대신 long을 사용할 수 있지만 int가 더 빠르고 공간을 적게 차지할 수 있습니다. typedef int Quantity;로 정의한 다음 다른 기계로 옮길 때 typedef long Quantity;로 변경할 수 있습니다.

7.6 The sizeof Operator (sizeof 연산자)

sizeof 연산자를 사용하면 프로그램이 특정 타입의 값을 저장하는 데 필요한 메모리 양을 결정할 수 있습니다. sizeof expression 또는 sizeof (type-name) 수식의 값은 type-name에 속하는 값을 저장하는 데 필요한 바이트 수를 나타내는 부호 없는 정수입니다.

sizeof (char)는 항상 1이지만 다른 타입의 크기는 다를 수 있습니다. 32비트 기계에서 sizeof (int)는 일반적으로 4입니다. sizeof는 컴파일러 자체가 일반적으로 sizeof 수식의 값을 결정할 수 있기 때문에 다소 특이한 연산자입니다. sizeof는 상수, 변수 및 일반 수식에 적용할 수 있습니다.

💡 Chapter 7 Q&A (질의응답)

Q: 7.1절에서 %o와 %x가 부호 없는 정수를 8진수와 16진수로 쓰는 데 사용된다고 했습니다. 일반 (부호 있는) 정수를 8진수나 16진수로 쓰려면 어떻게 해야 하나요?
A: 값이 음수가 아닌 한 %o 및 %x를 사용하여 부호 있는 정수를 인쇄할 수 있습니다. printf는 부호 있는 정수를 부호 없는 것처럼 취급합니다. 부호 비트가 0이면 문제가 없습니다. 부호 비트가 1이면 printf는 예상치 못하게 큰 숫자를 인쇄합니다. 음수를 8진수나 16진수로 인쇄하는 직접적인 방법은 없습니다.

Q: 부동 소수점 상수가 float 형식이 아닌 double 형식으로 저장되는 이유는 무엇인가요?
A: 역사적인 이유로 C는 double 타입을 선호합니다. float은 2등 시민으로 취급됩니다. C는 원래 모든 부동 소수점 산술이 배정밀도로 수행되도록 요구했습니다. (C89와 C99에는 그러한 요구 사항이 없습니다.)

Q: double 값을 읽을 때는 %lf를 사용하고 인쇄할 때는 %f를 사용하는 이유는 무엇인가요?
A: scanf와 printf는 가변 길이 인수 목록을 가진 함수입니다. 이러한 함수가 호출되면 컴파일러는 float 인수가 자동으로 double 타입으로 변환되도록 합니다. 결과적으로 printf는 float와 double 인수를 구별할 수 없습니다. 이것이 printf 호출에서 %f가 float와 double 인수 모두에 작동하는 이유입니다. 반면 scanf는 변수에 대한 포인터를 전달받습니다. %f는 scanf에게 float 값을 저장하도록 지시하고 %lf는 double 값을 저장하도록 지시합니다. 여기서 float와 double의 구별은 매우 중요합니다. 잘못된 변환 사양이 주어지면 scanf는 아마도 잘못된 바이트 수를 저장할 것입니다.

Q: char를 어떻게 발음해야 하나요?
A: 보편적으로 받아들여지는 발음은 없습니다. 어떤 사람들은 "character"의 첫 음절처럼 발음하고, 다른 사람들은 "char"(숯을 굽다)처럼 발음합니다.

Q: 문자 변수가 부호 있는지 없는지가 언제 중요한가요?
A: 변수에 7비트 문자만 저장한다면 부호 비트가 0이기 때문에 중요하지 않습니다. 그러나 8비트 문자를 저장할 계획이라면 변수가 unsigned char 타입이기를 원할 것입니다.

Q: 새로운 줄 문자가 어떻게 ASCII 라인 피드 문자일 수 있나요? 사용자가 Enter 키를 누르면 프로그램이 이를 캐리지 리턴 문자 또는 캐리지 리턴과 라인 피드로 읽지 않나요?
A: 아닙니다. C의 UNIX 유산의 일부로서 항상 줄의 끝을 단일 라인 피드 문자로 간주합니다. C 라이브러리는 사용자의 키 누름을 라인 피드 문자로 변환하는 작업을 처리합니다.

Q: getchar가 더 빠르다면 왜 개별 문자를 읽기 위해 scanf를 사용하려 할까요?
A: getchar만큼 빠르지는 않지만 scanf 함수가 더 유연합니다. " %c" 형식 문자열은 scanf가 다음 입력 문자를 읽도록 하고, " %c"는 다음 비공백 문자를 읽도록 합니다. 또한 scanf는 다른 종류의 데이터와 섞여 있는 문자를 읽는 데 능숙합니다.

📝 Chapter 7 Summary (써머리)

  • C의 정수 타입은 크기(short, int, long, long long)와 부호(signed, unsigned)에 따라 다양합니다.
  • 부동 타입(float, double, long double)은 소수점을 포함하는 숫자를 표현하며, IEEE 754 표준을 주로 따릅니다.
  • char 타입은 문자를 저장하며, 내부적으로는 작은 정수로 취급됩니다. 부호 있는/없는 문자를 명시할 수 있습니다.
  • 타입 변환(자동/명시적)은 데이터 손실이나 오버플로를 방지하기 위해 주의해야 합니다.
  • typedef를 사용하면 타입에 의미 있는 이름을 부여하여 가독성과 이식성을 높일 수 있습니다.
  • sizeof 연산자는 특정 타입이 메모리에서 차지하는 바이트 크기를 알려줍니다.

  1. 다음 정수 상수들의 10진수 값을 구하세요.
    (a) 077
    (b) 0x77
    (c) 0XABC
    정답:
    (a) 8진수 77 = 7*8 + 7 = 63
    (b) 16진수 77 = 7*16 + 7 = 119
    (c) 16진수 ABC = 10*16^2 + 11*16 + 12 = 2560 + 176 + 12 = 2748
  2. 다음 중 C에서 유효하지 않은 상수는 무엇이며, 왜 그런가요?
    (a) 010E2
    (b) 32.1E+5
    (c) 0790
    (d) 100_000
    (e) 3.978e-2
    정답:
    (c)와 (d)가 유효하지 않습니다.
    (c) 0790: 0으로 시작하므로 8진수인데, 8진수에는 8과 9가 올 수 없습니다.
    (d) 100_000: 숫자에 밑줄(_)을 포함할 수 없습니다. (C++14나 Java 등에서는 가능하지만 C는 안 됩니다.)
  3. 다음 중 C에서 유효하지 않은 타입은 무엇인가요?
    (a) short unsigned int
    (b) short float
    (c) long double
    (d) unsigned long
    정답: (b) short float
    (이유: C에는 short float 타입이 존재하지 않습니다.)
  4. char 타입의 변수 c가 있을 때, 다음 중 불법인 문장은 무엇인가요?
    (a) i += c; (i는 int형)
    (b) c = 2 * c - 1;
    (c) putchar(c);
    (d) printf(c);
    정답: (d)
    (이유: printf의 첫 번째 인자는 문자열(char *)이어야 합니다. c는 char이므로 오류가 발생합니다.)
  5. 다음 중 C에서 가장 작은 정수 타입부터 큰 순서로 올바르게 나열된 것은 무엇인가요? (일반적인 32비트 환경 기준)
    (a) char < short < int < long
    (b) char < int < short < long
    (c) short < char < int < long
    정답: (a)
    (일반적으로 char(1바이트) < short(2바이트) ≤ int(4바이트) ≤ long(4 또는 8바이트) 순서입니다.)
  6. 다음 수식들의 타입과 값을 구하세요. (단, c는 char형으로 '1'의 값을, s는 short형으로 2의 값을, i는 int형으로 -3의 값을 가짐)
    (a) c * i
    (b) s + m (단, m은 long형으로 5의 값)
    (c) f / c (단, f는 float형으로 6.5의 값)
    정답:
    (a) 타입: int, 값: 49 * -3 = -147 (문자 '1'의 ASCII 코드는 49)
    (b) 타입: long, 값: 2 + 5 = 7
    (c) 타입: float, 값: 6.5 / 49 ≈ 0.132653

🔥 형광칠한 핵심 내용 총정리 (Highlights)

Chapter 7에서 형광펜으로 강조한 가장 중요한 내용들을 한눈에 볼 수 있도록 연계하여 정리했습니다. 이 부분은 C 언어의 데이터 타입과 메모리 구조를 이해하는 데 있어 가장 핵심적인 규칙입니다.

  • 1. 정수 타입의 부호와 오버플로:
    기본적으로 정수는 부호가 있습니다(signed). 부호 없는 정수(unsigned)를 사용할 때는 범위와 오버플로 동작(모듈로 연산)이 다르다는 점을 명심해야 합니다. 특히 부호 있는 정수 오버플로는 '정의되지 않은 동작'을 유발하므로 주의해야 합니다.
  • 2. 실수 타입의 정밀도와 저장 방식:
    float는 6자리, double은 15자리의 정밀도를 가집니다. 실수 상수는 기본적으로 double로 저장되며, float로 저장하려면 상수 뒤에 f를 붙여야 합니다. 또한 scanf로 double을 읽을 때는 %lf를 사용하고 printf로 쓸 때는 %f를 사용하는 이유(가변 인자 승격)를 기억하세요.
  • 3. char 타입의 이중성:
    C에서 char는 문자를 나타내지만, 내부적으로는 작은 정수(ASCII 코드)로 취급됩니다. 따라서 산술 연산이 가능합니다. 또한 char가 기본적으로 부호가 있는지 없는지는 컴파일러마다 다르므로, 8비트 문자를 다룰 때는 unsigned char를 명시하는 것이 안전합니다.
  • 4. 타입 변환 시 주의점 (부호 있는 정수 vs 부호 없는 정수):
    부호 있는 정수와 부호 없는 정수를 함께 연산하면, 부호 있는 정수가 부호 없는 정수로 변환됩니다. 이때 음수는 매우 큰 양수로 해석되어 예상치 못한 논리 오류를 유발할 수 있습니다. 가능하면 부호 없는 정수를 피하거나, 명시적으로 캐스팅(casting)하여 의도를 명확히 해야 합니다.
